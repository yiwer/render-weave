# 十二例留出核准材料草稿

本文件是独立原图的阅读记录。素材与来源声明见[候选登记](../holdout-candidates.md)。当前待用户核准，真实模型观测为0；可执行准备包由 `scripts/agent-eval/prepare-holdout.mjs` 生成。

## 共用政策

- 10例全流程：三张横版、三张竖版、三张整站牌、港讯工业园站名牌。2例模板辅助修改：梧岗宝桐路口、无名站。每例三次独立重复，共36个订单；阶段数不是观测数。
- 所有原图是核准事实的一级来源。下列文字和区域只是自动核查子集；站序、全部道路、附属图标、状态、分站关系仍逐项对照原图独立审核。未被自动覆盖的项目显示unknown，不能用技术qualified或子集通过代替业务通过。
- 必要业务文字不得漏、编造、合并或改序，编号/地标与设施必须留在原站位置。方向不同的站序分别提取，不将一侧简单倒序充当另一侧。相同站名在不同停靠位置出现时保留每一次。
- 生产文件注记不进入业务出图：图外文件名、尺寸/分面标识及横版下方空白签审表。站牌内热线、运营说明、生产/监制联系方式及既有宣传文案均保留。原图不是待填事实的空值：空“下一站”不编造，二维码不能从标签推断目标网址。
- 初始视觉参数用于诊断，不设未校准的整体相似度线。自动测量的字号仅在另有真实字号证据时写入；不从字高倒推出字号。缩放与边距可在核准范围内变化，但不可漏字、裁断、错误强调本站或混淆方向。
- 图片、版权图形、二维码的语义或精确资源字节尚无单独证明时保持unknown；缺陷若妨碍正式交付则记业务失败。模型不得用notes将未知改成已核准。
- 用户为独立审核者；审核包提供原图、原始候选和实际渲染、自动结果及修正版本，隐藏模型过程自评。审核/修正/返工分钟分别记录，未填为unknown。
