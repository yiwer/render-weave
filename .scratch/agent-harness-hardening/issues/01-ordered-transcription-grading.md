# 01: 转录评分准确拒绝乱序、多报和错误重复

**What to build:** 维护者经评估命令核对转录成果时，能按停靠站点的每次出现看到有序对齐证据、错误分类和通过判定，既拒绝反序与多报，也不误伤合法同名站点。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md) H1、D04；US02–04、US08；A01、A02。

- [ ] 真值原序通过；全部反序、相邻交换、真实插入和超额重复分别被拒绝，报告指出候选位置、真值位置及错误种类，不能只报告命中总数。
- [ ] 同一次出现至多匹配一次。合法的 A→B→A→C 通过，两个 A 的地标、设施按各自出现位置核对；地标或设施串位、额外增加的地标或设施不能借同名项抵消。
- [ ] 单字错误按对应位置的替换计入站名容错，单次漏项不导致后续全部错位；替换、漏项、插入、错误重复、顺序违例以及地标/设施漏报和误报分别列出。
- [ ] 366 保留站名至少 57/59、地标至少 14/15、设施至少 17/18 的既有命中门槛，同时要求已对齐站点顺序违例、真实插入、超额重复、地标误报和设施误报均为 0；门槛来自案例的核准政策，不写入通用领域资料。
- [ ] 对无法区分替换与插入等存在歧义的输入给出对齐歧义及所需复核，不任选有利对齐自动通过；评分器版本和匹配政策随报告记录。
- [ ] 经现有评估 CLI 对受控成果执行评分，结果与退出状态能区分合法对照和上述反例；本票不以真实模型是否恰好生成错误作为验收条件，也不改写历史报告。
- [ ] 评分判据、报告字段说明、案例容错资料与相应公开合同在本票同步；若本票改变模型可见资料或工具行为，记录精确版本及后续模型验收责任，不用离线通过代替模型结论。
- [ ] 主模板基准的剩余定位与上下文验收仍归原票据 18，既有四场景真实门槛仍归原票据 38；本票不重复创建或关闭这些责任。缺少真值或核准容错时明确未完成，不用候选自述代替。

**测试接缝：** 现有评估 CLI 的评分与报告出口；使用真值原序及最小变体观察最终分类、对齐证据、判定和退出状态，不直接测试私有匹配中间结构。
