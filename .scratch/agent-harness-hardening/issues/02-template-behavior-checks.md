# 02: 换数据和参数后核查模板的实际业务行为

**What to build:** 维护者能通过实际出图和评估报告确认模板在六类输入变化后仍满足独立业务事实，并同时核对模板修改的目标完成与非目标保留。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md) H1、D05；US05–06；A03 的六类反事实及修改范围验证。

- [ ] 每个校准案例预先固定输入变化、独立预期和允许联动范围，至少覆盖字段换值、列表增删/同名、模板参数、可选信息、长文本/尺寸、图片资源六类；预期不能从被测候选或模型说明反推。
- [ ] 字段换值后检查实际呈现文字；写死示例值的合法模板即使无严重渲染问题也被拒绝，正常绑定的对照通过。
- [ ] 列表增删及合法同名项变化后检查实际实例数、出现顺序和相应内容；固定数量、漏掉末项或误合并同名项的反例被拒绝。
- [ ] 模板参数变化后检查目标状态和内容；可选信息有值与缺值时检查显示、隐藏及预先允许的排布联动，无效参数或仍占据不该占的位置的反例被拒绝。
- [ ] 长文本与目标尺寸边界按案例政策检查实际可见内容和允许适配；图片资源替换检查核准内容，不能只以资源名称或整图哈希改变证明结果正确。
- [ ] 修改任务同时报告要求涉及的目标是否完成、非目标是否保留和越界差异；合法布局联动需事先声明，不能事后扩大允许范围来解释失败。
- [ ] 从公开渲染结果到评估报告保留输入、事实与输出证据的关联；严重问题为零、内部变量变化或图片不同均不能单独计为业务通过。缺独立事实或无法可靠测量的维度明确未核查，不自动获得完整通过。
- [ ] 案例政策、评估输出说明及本票涉及的合同、资料同步更新；通过合法对照与反例的离线公开入口验证。本票不新增 DSL 语法，不重复原票据 18 的主模板基准检查、33 的内容覆盖或 34 的完整样式验收；真实模型门槛按统一冻结计划另留证。

**测试接缝：** 现有公开渲染入口和评估 CLI；给定合法模板及受控反例，观察实际文字、实例、顺序、状态、可见性与修改范围的报告，不以内部变量或函数调用次数断言完成。
