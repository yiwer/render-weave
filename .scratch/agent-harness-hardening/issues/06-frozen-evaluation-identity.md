# 06: 评估续跑拒绝混合条件，重新评分保留原始结论

**What to build:** 固定评估的预登记身份，留存每次派发的实际输入，使合法续跑、条件变更和重新评分都有可核对的外部行为。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md) D06、D07、D16；US33–35、US37–38、US48、US63；A12；A14 的受控状态汇总与退出码子项。

真实四场景运行仍归原 38，本票不以取得真实模型门槛为关闭条件。

- [ ] 实验开始前固定执行器、请求模型与推理配置、端点身份、时间/轮数及停滞预算、构建、工具合同、提示词生成规则、静态资料/输入、评分器、配置、真值、参考和资源摘要；端点身份不含凭据。
- [ ] 每次派发前保存实际提示词、提供的资料和上游成果/检查点身份，响应后追加可获得的实际服务模型；这些证据不倒填为预登记条件。合法串联或接续的动态提示词变化不被误拒；无法固定的供应商修订及实际模型变化明确显示。
- [ ] 相同实验标识续跑时，改变任一预登记条件均在模型派发前拒绝并列出差异；原实验与成果保持不变，改变条件只能创建新实验。
- [ ] 相同身份只补计划内 invalid 或 not-run 单元；已有有效成功和有效失败均不被覆盖或重新派发，不能通过重复运行替换失败直到成功。
- [ ] 报告列全计划与 pass、fail、invalid、not-run，并单列执行完整性。要求达线的门槛中，有任一有效失败则 fail；无失败但缺次数则 incomplete；齐全达线才 pass。受控的 fail+invalid、pass+invalid、pass+pass 经命令行分别产生失败、未完成、通过结论及对应退出码。
- [ ] 重新评分产生关联原实验、原尝试与新评分器身份的新报告，注明评分时间；原报告及其身份不变。缺少旧身份的信息如实标明，不补造历史条件。
- [ ] 普通续跑可改变并行数，但每段调度条件完整留存；用于质量/成本配对比较的运行能够核对预先固定的调度条件，不能将不同调度的结果伪装成同条件。
- [ ] 同步本票涉及的命令用法、报告格式和兼容说明；旧报告继续可读，不能把无法证明相同身份的旧记录并入新实验。使用受控执行器从公开评估入口验证以上行为，未引入真实模型验收依赖。

**测试接缝：** 公开评估命令的派发结果、退出码、实验清单和报告文件；以受控执行器验证是否发生外部派发，不断言私有比较结构。重新评分读取已保存成果，不调用模型。
