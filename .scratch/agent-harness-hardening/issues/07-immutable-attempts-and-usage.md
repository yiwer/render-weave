**What to build:** 让每次模型执行都有不可覆盖的证据，并在重试、额度停止和恢复后准确报告已知用量与未知部分。

订单与人工投入汇总归 15；本票提供完整尝试依据，不等待真实模型大门槛才能关闭。

- [x] 每次启动分配唯一尝试标识并保存所属实验/单元、输入、日志、候选、结束或停止原因、结果和已知用量；重试另建记录，不删除或覆盖前一次尝试。
- [x] 上游瞬时错误沿用有限重试，既有成功阶段与已应用工作区保留；重试次数、原因和每次结果均可追溯，最终成功不掩盖此前失败。
- [x] 硬额度耗尽停止派发未开始单元并留出续跑依据，不自动等待、切换模型或绕过限制；普通限流和瞬时错误保持各自分类，计划内未开始的单元仍显示 not-run。
- [x] 运行器重启或重复续跑先核对已有完成记录；已完成有效观测不重新派发，已经计入的尝试不重复计量；无效单元补跑仍保留此前全部尝试。
- [x] 分别报告输入、输出、缓存读/写、输出内 thinking、工具调用及各尝试耗时；thinking 不再次加到输出总量，失败与重试的已知用量同样纳入。
- [x] 无 usage 的崩溃或中断明确记未知，报告给出已知小计和未知尝试数，不把未知当 0，不将已知小计标为完整总成本。
- [x] 并行任务分别报告实际总墙钟与各轮耗时求和，并能沿尝试标识核对原始记录；受控已知用量覆盖暂时错误后成功、quota、无 usage 中断、并行与重启，汇总无遗漏、无重复。
- [x] 同步涉及的报告、尝试记录及兼容说明；旧记录缺失的用量保持未知，新旧格式的可读性和来源关系可核查。以上通过公开编排入口与受控执行器验收，不要求调用真实模型。

**测试接缝：** 公开评估命令/编排入口产生的尝试成果、报告、退出码和续跑行为；受控执行器给出已知用量与停止结果，恢复通过重新启动同一公开命令验证。

- `scripts/agent-eval/attempts.ts` 为每次派发保存独立 `attempts/<UUID>/round/` 原件；启动记录固定实验、阶段、任务输入与拥有者，完成封存包含全部原件哈希、耗时和错误。`definition/` 等原阶段目录仅为可重建视图，`.attempt.json` 指回原件；模拟审核与应用不会改写已封存尝试。旧记录只保留可证的最后成果，不补造已丢失的重试历史。
- `scripts/agent-eval/eval.ts` 在单元短锁中恢复、重核是否需要派发并预留新尝试，执行器在锁外运行；并发首次派发只允许一个拥有者。已有有效观测跳过，旧拥有者存活、跨宿主或退出状态未知时拒绝继续评估；死亡确认后保留原件与已知用量，缺完整终检或实验封存的旧尝试不能成为有效观测。瞬时错误有限重试，硬额度停止新单元，已成功阶段及应用工作区保留。
- 完成记录先以 `completed.seal.json` 独占发布完整值及摘要，再独占写兼容的 `completed.json`。在两步之间退出仍可读取封存；两份存在时必须匹配，修改耗时、错误等完成元数据会拒绝重评分。摘要只用于内容完整性，不声称能认证恶意重算哈希。
- 报告枚举完整计划内所有尝试，汇总输入、输出、输出内 thinking、缓存读写、工具调用、转存及轮次耗时；未知值单列 `unknownByMetric`/`unknownUsageAttempts`，已知小计不冒充完整成本。完整与中断轮次共用日志计数，残缺行不抹去此前完整事件。`timing` 分开实际会话区间并集、已知墙钟与尝试耗时之和，中断会话和无法证明的结束时间保持未知。
- `scripts/agent-eval/run.ts` 将实验封存定位到 Launcher 实际输出，重复续跑不重复计量；重评分与分段报告另存，旧报告字节保持不变。`scripts/agent-eval/identity.ts` 保留实际尝试及审核串联的身份检查；含 pending 的合法数据定义审核后仍可派发数据集。
