# 07: 重试和恢复保留每次尝试与真实用量

**What to build:** 让每次模型执行都有不可覆盖的证据，并在重试、额度停止和恢复后准确报告已知用量与未知部分。

**Blocked by:** 06

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md) D07、D14、D16；US36、US38、US55–56、US63；A13 的尝试留存、恢复去重和原始用量子项。

订单与人工投入汇总归 15；本票提供完整尝试依据，不等待真实模型大门槛才能关闭。

- [ ] 每次启动分配唯一尝试标识并保存所属实验/单元、输入、日志、候选、结束或停止原因、结果和已知用量；重试另建记录，不删除或覆盖前一次尝试。
- [ ] 上游瞬时错误沿用有限重试，既有成功阶段与已应用工作区保留；重试次数、原因和每次结果均可追溯，最终成功不掩盖此前失败。
- [ ] 硬额度耗尽停止派发未开始单元并留出续跑依据，不自动等待、切换模型或绕过限制；普通限流和瞬时错误保持各自分类，计划内未开始的单元仍显示 not-run。
- [ ] 运行器重启或重复续跑先核对已有完成记录；已完成有效观测不重新派发，已经计入的尝试不重复计量；无效单元补跑仍保留此前全部尝试。
- [ ] 分别报告输入、输出、缓存读/写、输出内 thinking、工具调用及各尝试耗时；thinking 不再次加到输出总量，失败与重试的已知用量同样纳入。
- [ ] 无 usage 的崩溃或中断明确记未知，报告给出已知小计和未知尝试数，不把未知当 0，不将已知小计标为完整总成本。
- [ ] 并行任务分别报告实际总墙钟与各轮耗时求和，并能沿尝试标识核对原始记录；受控已知用量覆盖暂时错误后成功、quota、无 usage 中断、并行与重启，汇总无遗漏、无重复。
- [ ] 同步涉及的报告、尝试记录及兼容说明；旧记录缺失的用量保持未知，新旧格式的可读性和来源关系可核查。以上通过公开编排入口与受控执行器验收，不要求调用真实模型。

**测试接缝：** 公开评估命令/编排入口产生的尝试成果、报告、退出码和续跑行为；受控执行器给出已知用量与停止结果，恢复通过重新启动同一公开命令验证。
