# 10: 整轮超时或取消后有界退出并保留可恢复结果

**What to build:** 为整个 Agent 轮次提供可执行的时间与轮数边界，统一取消、超时和失败保存，并确保耗时终检也能停止。

**Blocked by:** 09

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md)；D10（时间、取消、停止分类和用量边界）；US25–29、US63；A09；A20（本票合同、资料及兼容子项）。遵守 ADR-0024；已有硬额度停止和受阻草稿行为作为回归。

本票不新增无法实时执行的费用承诺；停滞判定归 12，全部尝试的实验成本汇总归相应评估票。

- [ ] 开始前明确显示时间与轮数限制，保留各任务现有默认轮数；整轮墙钟默认 60 分钟并接受显式正值，非法配置在启动执行器前拒绝。计时从执行器启动前开始，输入校验与准备先完成。
- [ ] 短预算分别覆盖模型等待、工具等待及执行器结束后的耗时终检；终检与渲染处于可强制终止边界。即使同步计算不让宿主普通定时回调执行，也能在预算、保存宽限与合理调度余量内结束。
- [ ] 用户取消或预算到达后停止本轮新请求，终止本轮执行器、代理和耗时检查；同时运行另一合法轮次及无关工具，验证其不受影响，不以按名称终止所有相同进程实现取消。
- [ ] 停止后最多给予 30 秒本地保存宽限，保留已提交完整检查点及可恢复状态；宽限耗尽仍不能完成收尾时明确未完成，不无限等待，不将半写候选标为完整。
- [ ] 超时、用户取消、明确硬额度、执行器失败和宿主恢复分别保留原因；普通 429/5xx 不误归硬额度，沿用既有错误与重试语义。各停止路径可读取诊断和已有候选，不能把停止自动转为批准。
- [ ] 当前适配器无法执行的硬 token/费用配置在启动前明确拒绝；不将结束后才返回的统计称为实时硬限制，不承诺远端已开始生成即时停止计费。
- [ ] 本轮已获得的用量及停止原因保留，缺失用量记为未知，不填零；失败或取消不能抹掉此前已知用量。全实验汇总继续使用独立尝试证据，不在本票重建另一套计量口径。
- [ ] 停止后从已有完整检查点接续能够开新轮次，旧停止原因与原成果不被改写；无检查点时明确只能查看诊断。正常预算内完成和原有轮数用尽行为均有合法对照。
- [ ] 同步预算/取消选项、停止结果合同、资料与兼容说明；预算值及本轮生效值可供实验身份记录，已有配置和正常运行回归通过，涉及行为变化按约定升版。

**测试接缝：** 从公开 Agent CLI 配置短预算，使用整个假执行器或渲染边界安排模型等待、工具等待、终检阻塞与错误；通过取消信号、退出时间范围、另一个存活轮次、检查点和公开记录验证。时间断言允许操作系统调度余量，不比较精确毫秒。真实模型最终证据归统一验收活动，本票以可控有界执行验收关闭。必要预重构先保持现有测试通过，不重写执行器工具调用循环。
