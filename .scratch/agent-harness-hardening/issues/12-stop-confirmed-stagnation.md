# 12: 有证据的机械停滞及时停止，正常确认仍可交回

**What to build:** 根据完整检查和核准必修问题识别无进展循环，复用有界停止与保存，同时排除正常复检、分页和证据不足的情形。

**Blocked by:** 10

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md)；D10（停滞）；US30、US63；A10；A20（本票合同、资料及兼容子项）。遵守 ADR-0024。

本票不依赖 11 的较好候选选择；停滞直接依据完整检查的核准必修问题和进展事实，不按模型自评或总分判定。

- [ ] 停滞计数只针对尚未正式交回、仍有非空核准必修问题且获得完整修复机会的任务；用于判定的完整候选、基准、检查结果和机会依据可追溯，不能只凭调用次数停止。
- [ ] 同一基准和候选在完整修复机会后连续两次完成检查仍无变化时，能够触发明确停滞原因；用必要问题仍在的真实检查结果验收，不把两次紧邻的正常确认当作修复机会。
- [ ] 连续两次完整修改/复测周期中，必修问题均无改善且没有其他已核准进展时，能够触发停滞；有可证明改善或其他已核准进展的合法对照继续执行，不能把候选哈希改变本身当作进展。
- [ ] 宿主终检、交回自检、分页、诊断复读和合法重复确认均不计入停滞；正确候选初检及交回复检后可以正式交回，完成条件已满足时进入交回流程，不因空问题集合重复而停止。
- [ ] 正在写入、仅零散写入尚未完整检查、基准改变或检查证据不足时不计停滞；不能把半写造成的暂时异常当成完整修复失败。无可信比较依据的任务继续依赖时间和轮数边界。
- [ ] 触发后通过 10 的统一停止与有界保存路径结束，保留已提交完整检查点、停滞原因及比较依据；只影响本轮，随后可按已有接续入口开新轮次，不能生成批准或应用成功。
- [ ] 阈值可配置，非法配置在启动前拒绝；本轮实际阈值明确记录并可纳入实验身份。正常确认的排除规则不因调小阈值而失效，模型备注不能自行扩大或缩小核准必修范围。
- [ ] 同步停滞结果合同、配置与 Agent 资料、记录兼容规则；旧轮次缺少可信停滞证据时不倒推停止原因，正常交回、轮数限制、取消及超时回归通过，行为变化按约定升版。

**测试接缝：** 从公开 Agent CLI 运行受控假执行器，经真实 MCP 检查制造同候选重复、两次无进展周期、改善、分页和交回复检；观察退出原因、完整检查证据、检查点及正式成果，覆盖无可信基准时的预算兜底。测试不以私有计数器值代替行为。真实模型最终证据归统一验收活动，本票不重复完整真实门槛。必要预重构先保持现有测试通过，不另建进度评分框架。
