- [x] 停滞计数只针对尚未正式交回、仍有非空核准必修问题且获得完整修复机会的任务；用于判定的完整候选、基准、检查结果和机会依据可追溯，不能只凭调用次数停止。

- [x] 连续两次完整修改/复测周期中，必修问题均无改善且没有其他已核准进展时，能够触发停滞；有可证明改善或其他已核准进展的合法对照继续执行，不能把候选哈希改变本身当作进展。
- [x] 宿主终检、交回自检、分页、诊断复读和合法重复确认均不计入停滞；正确候选初检及交回复检后可以正式交回，完成条件已满足时进入交回流程，不因空问题集合重复而停止。
- [x] 正在写入、仅零散写入尚未完整检查、基准改变或检查证据不足时不计停滞；不能把半写造成的暂时异常当成完整修复失败。无可信比较依据的任务继续依赖时间和轮数边界。
- [x] 触发后通过 10 的统一停止与有界保存路径结束，保留已提交完整检查点、停滞原因及比较依据；只影响本轮，随后可按已有接续入口开新轮次，不能生成批准或应用成功。
- [x] 阈值可配置，非法配置在启动前拒绝；本轮实际阈值明确记录并可纳入实验身份。正常确认的排除规则不因调小阈值而失效，模型备注不能自行扩大或缩小核准必修范围。
- [x] 同步停滞结果合同、配置与 Agent 资料、记录兼容规则；旧轮次缺少可信停滞证据时不倒推停止原因，正常交回、轮数限制、取消及超时回归通过，行为变化按约定升版。
