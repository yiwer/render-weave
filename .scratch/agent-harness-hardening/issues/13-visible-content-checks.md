# 13: 已不可见的内容不能冒充视觉覆盖完成

**What to build:** 审核人和执行 Agent 经现有参考比较与成果检查，能发现首期承诺范围内的完全不可见内容，正确区分可测异常与未知维度，并取得与候选内容身份绑定的证据。

**Blocked by:** 03

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md) H5、D12；US01、US07、US51–54；A16。

- [ ] 在无复杂变换的轴对齐对象范围内，实际识别被画板完全裁掉、累计透明度为零、被后绘制且累计不透明的实心矩形完全遮挡的内容，报告对象位置和可核对依据；不能把承诺范围的全部反例退回未知。
- [ ] 遮挡判定尊重实际绘制顺序、父级透明度和裁切区域；相同矩形位于目标之前、父级半透明或裁切未覆盖目标的对照，不得被报告为完全遮挡。
- [ ] 空心或仅描边矩形、图片透明孔洞及文字的包围框不作为实心覆盖区域；对应反例不会因包围框相交而误报完全遮挡。
- [ ] 部分遮挡、其他遮挡形状、复杂裁切/变换、混合透明度、低对比和感知可读性按维度保持未知，不新增未经校准的整体相似度或通用对比度放行阈值。
- [ ] 正确图片与错误图片使用核准资源内容或参考形成独立对照；资源名称相同、能够解码或成功渲染均不能独立证明内容正确。缺核准图片事实时明确未核查。
- [ ] 同一合法输入分别在有基准、无基准、尺度不符、匹配歧义和参考被改动时得到对应状态；缺证据和无效基准不能产生全图通过，参考被改动明确拒绝。
- [ ] 现有 MCP 比较、交回检查和宿主终检针对同一检查内容身份得到一致的可测异常与未知范围；候选、数据、请求或相关资源改变后，旧报告不能充当当前证据。
- [ ] 技术合格、内容核查和已测视觉维度分别显示；未知不进入已通过分子，必要范围存在未知时不宣称整体通过。实例位置与源模板位置仍可用于定位，结果继续遵守分页和总输出预算。
- [ ] 在本票同步变更工具合同、视觉能力说明、Agent 参考及相应公开入口回归；不把新增局部测量写成原票据 34 的全样式/状态验收已完成。材料缺失明确未完成，真实模型对这些反馈的使用另按冻结计划验收。

**测试接缝：** 现有公开渲染/参考比较、成果校验与真实 MCP 协议；以支持范围的可见/不可见成对样例及未知范围对照，观察返回结论、证据、定位和预算，不依赖私有绘制结构。
