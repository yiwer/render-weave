# 15: 按完整订单核算尝试成本与人工投入

**What to build:** 将任务轮次、全部尝试、审核修正和正式交付关联成可核对的订单报告，并提供不泄露凭据与业务素材的分享摘要。

**Blocked by:** 05、07、09

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md) D14、D16；US46、US55–57、US62–63；A13 的订单汇总子项；A17 的原始成果/人工补救记录能力；A20 的真人走查时间记录能力。

它交付后续试验与真人走查所需的记录能力，不代替留出执行或最终走查。

- [ ] 报告关联订单、任务轮次、尝试、候选、检查报告、审核和提交/出图结果；接续、失败重试、恢复和重复查询不会将同一尝试或同一提交重复计入。
- [ ] 保留 Agent 原始成果与人工修正后成果的独立结论及关联，人工补救不能改写原始质量或被算为 Agent 首次成功；审核、修正、返工分钟分别记录，未记录时间明确未知。
- [ ] 成本纳入该订单全部成功、失败、中断和重试尝试；已知用量、未知尝试数、总墙钟、各轮耗时求和分别显示，沿原始尝试能复核汇总，thinking 不重复计数。
- [ ] 质量与交付口径分开：invalid 可排除于模型有效观测分母，但继续出现在交付可用性与成本记录中；报告明确计划、尝试和订单三个计数层次。
- [ ] 预先说明订单统计范围；单位成功订单成本以该范围内成功应用并完成所需正式出图的订单计分母，分子包括范围内所有订单（含最终未成功订单）的尝试与人工投入。没有成功订单时标为未定义，不能借用技术合格数量；单笔订单成本另列。
- [ ] 仅在完整用量与提供方计价版本可获得时估算金额并注明口径；否则展示原始用量及未知部分，不猜测订阅金额或远端停止计费时点。
- [ ] 可分享摘要保留必要关联标识、身份和诊断，去除凭据、原图敏感内容及不必要本机路径；完整业务材料留在访问受控的轮次记录中，分享摘要不能被当作完整复现包。
- [ ] 通过公开流程构造成功交付、审核拒绝后修正、恢复后成功、无成功订单、缺用量和缺人工时间的对照，确认报告与实际状态一致；后续真实走查只填充这些既有能力，不承担补实现。
- [ ] 同步本票涉及的记录、报告、操作说明和兼容规则；旧订单缺失字段保持未知，不补造历史人工时间或用量，所需合同变化随本票处理。

**测试接缝：** 公开 Agent 运行/接续、审核、应用、正式渲染及报告/分享入口；使用受控执行器与公开人工时间记录操作观察成果，不断言内部聚合容器。
