# 16: 素材与历史内容不能改变宿主权限和可信结论

**What to build:** 用对抗与正常任务成对验证并修复低可信输入边界，确保素材不能扩大权限、改写真值或通过规则，也不会泄露凭据。

**Blocked by:** 05、07、09

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md) D16；US60–63；A19 的信任边界实现、成对正常效用与日志检查。

边界缺口在本票修复并同步合同，不能留给最后验收票处理；本地通过不代表托管或跨租户隔离已获证明。

- [ ] 为示例图文字、数据字段、资源名称和旧轮次内容分别准备带指令的对抗输入及对应正常对照，预先说明其试图跨越的边界、允许任务行为和可观察结果。
- [ ] 经真实公开入口尝试扩大路径访问、读取凭据、修改核准参考/内容事实、篡改宿主检查记录或绕过应用要求，均由宿主/工具边界拒绝；模型备注、素材内容和历史文本不能提升权限或成为新的通过依据。
- [ ] 对工作目录外路径及既有支持的平台链接/路径逃逸方式保持限制；发生拒绝时保留可定位错误和诊断，不能靠隐藏错误或伪造成功状态满足验收。
- [ ] 指令文本作为正常业务文字需要转录或显示时仍可按任务处理；正常对照能够完成相应读取、候选检查、审核与允许的应用流程，不能拒绝所有内容取得高拦截率。
- [ ] 任务失败、硬额度停止、恢复和重试后的日志、报告、诊断与可分享摘要均不包含注入的测试凭据或宿主凭据；使用隔离测试凭据验证，不读取或外发真实秘密。
- [ ] 权限拒绝不损坏本轮可信输入、既有检查点或其他任务状态；允许的正常任务与被拒绝操作在报告中明确区分，不能把安全拦截计作业务成功。
- [ ] 修复发现的边界漏洞后，从同一公开入口复跑攻击和正常对照；记录覆盖范围与未验证边界，不以提示词声明、MCP 注解或假执行器的服从性代替实际权限验证。
- [ ] 同步涉及的工具合同、资料、日志/记录兼容与使用说明；保留现有本地审核及阶段 5 策略边界。机制验收使用受控执行器实际发起越界尝试，不等待真实模型大门槛或新增托管系统。

**测试接缝：** 公开 Agent/CLI 流程、实际 MCP 协议、审核/应用及日志/分享成果；受控执行器真实发起允许与拒绝操作，按外部文件/权限/状态和正常任务结果判断。
