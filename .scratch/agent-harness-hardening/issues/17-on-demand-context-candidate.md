# 17: 按需资料策略形成可验证候选并自动检查资料指针

**What to build:** 维护者可以在校准场景中选择保留强制约束的按需资料候选，确认资料和工具引用可达，并生成与现有全量阅读策略可公平配对的输入；默认策略暂不改变。

**Blocked by:** 14

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md) H6、D15–D16；US58–59；A18 的资料策略候选、自动指针检查和配对输入准备子项。配对实跑与收益判定归票据 18。

- [ ] 保留现有全量资料策略作为对照，新增可显式选择的按需策略候选；命名、单位、作用域、成果交回、能力与信任边界等强制约束仍在入口可见，默认和既有 effort 决定不变。
- [ ] 按需候选以简短资料目录引导按任务阶段读取循环/子模板、文本适配、状态与变量等现有参考；只使用公开 DSL 参考工具已经可达的资料，不增加新的 DSL 语法或另一份规则权威。
- [ ] 局部问题按代码或目标聚类，返回必要上下文、实例/源模板位置和续取入口；截断必须明确，不能因压缩资料丢掉必修约束、未知范围或后续页问题。
- [ ] 自动检查候选资料目录、DSL 参考、工具合同和共享样例之间的指针与可达性，结果列出通过项、遗留错误及其责任；原数据定义示例的错误指向仍归原票据 20，不在本票重复修复，也不要求原 20 整票关闭后才能验证候选。
- [ ] 对原票据 20 的已知遗留错误明确记为未解决，按需候选可通过已可达的正确公开参考验证其路径；检查报告不得因已知责任归属而把错误标成通过。其他新增或由本候选引入的失效指针必须在本票消除。
- [ ] 只使用票据 14 的校准场景及其他明确属于校准用途的输入验证资料获取、缺失/无效参考、分页和错误修复引导；不读取留出结果来调整策略，材料不足明确未完成。
- [ ] 为两个策略保存可冻结的策略身份、实际资料范围和配对输入，确保后续可固定模型、预算、样本和调度条件比较。当前只用假执行器与公开工具验证可执行性，不运行配对真实模型、不宣称降低成本或提高成功率；实跑、质量守卫和是否改变默认由票据 18 决定。
- [ ] 候选策略说明、资料目录、相关工具合同及校准操作指引在本票同步；旧全量资料路径仍可用，候选失效能得到明确错误。同步内容与遗留问题随版本记录，不能留待最后整体验收补说明。

**测试接缝：** 现有评估/Agent 入口的策略选择与实际资料成果，辅以公开 DSL 参考和 MCP 结果；以校准样例和假执行器观察参考可达、约束保留、分页、错误状态与策略身份。真实配对实验不在本票。
