# 18: 用配对试验决定是否采用按需资料策略

**What to build:** 在校准集上公平比较全量资料与按需资料，完整报告质量和成本，并据预登记规则决定默认策略。

**Blocked by:** 02、12、15、16、17

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md) D15、D16；US58–59、US63；A18 的实际校准集配对试验、收益判断与默认策略决定。

17 负责资料候选与一致性能力，本票负责真实配对实验；不使用留出集调参，不替代后续固定候选的模型门槛。

- [ ] 派发前登记校准案例、两组资料策略、计划重复次数、各案例预算、主收益指标、最低有用改善、关键质量守卫和缺失观测处置；这些是试验政策，不冒称已经业务校准。
- [ ] 除预登记的资料策略差异外，两组使用相同模型、共同构建基础、输入、可信基准、预算、判据及调度条件；分别保存实验与尝试身份，记录可获得的实际服务模型和无法固定条件。
- [ ] 从公开任务路径完成全部预登记配对，保留每次成功、失败、中断及成本；不只保留最优重复，不以不同样例或人工补救替换失败。额度或素材导致计划缺失时明确未完成，不自动等待或绕过额度。
- [ ] 比较原始成果达线情况、关键错误/越界修改、停止原因、全部尝试用量、实际墙钟和人工审核/修正分钟；未知用量独立列出，不能因为某组缺计量而宣布其更省。
- [ ] 只有主收益达到预登记最低改善且所有质量守卫通过，才采用候选为默认；净收益不足、质量退步或证据不能支持改善时保留现有默认。完整负结果及明确保留决定可以关闭本票。
- [ ] 若采用默认策略，在本票完成相应默认行为、资料与说明调整，并保存采用前后条件；若未采用，候选仍明确为试验资料。保持既有 effort 决定，不擅自切换模型或改为 low。
- [ ] 校准数据与留出案例按模板家族隔离，原图、裁切或退化版不得跨入留出用途；根据本次结果调整过的案例继续作为校准/回归，不宣称独立泛化收益。
- [ ] 同步本票触及的资料、工具/记录兼容及结果说明；报告完整保留负结果和限制。默认决定及全部行为改动必须在 20 的候选冻结之前完成，本票的比较结果不直接充当后续正式验收通过记录。

**测试接缝：** 公开 Agent/CLI 全流程及公开评估报告；真实模型比较实际成果、全部尝试成本与人工记录，配对政策在运行前固定，不以读取次数或私有上下文结构判断质量。
