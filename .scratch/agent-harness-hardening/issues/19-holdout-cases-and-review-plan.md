**What to build:** 准备可供后续四个分层执行票使用的独立案例、可信真值、三次重复计划和审核程序，本票不派发模型。

**Blocked by:** 14、15

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md) D13、D14、D16；US44–48、US57、US63；A17 的案例准备、冻结计划、独立审核及污染记录子项。

22–25 各自执行一个分层的九个单元并保存结果；本票只交付准备成果，不用模型运行填补准备缺口。

- [ ] 冻结横版线路牌、竖版线路牌、整站牌、双语站名牌四个分层，各三个业务案例，共十二例；至少八例走素材到正式出图全流程，其余覆盖模板辅助修改。每例明确任务流程、独立参考和允许修改范围，采用用户核准的[候选清单](../holdout-candidates.md)。
- [ ] 每例预登记三次重复，共三十六个计划单元；一个单元是一例完整流程的一次重复，不能把提取、审核和模板阶段分别算成多个单元。按分层形成 22–25 可直接引用的九单元清单。
- [ ] 按模板家族与校准/资料策略试验隔离；原图、裁切、退化版在同组，记录来源及已知使用史。同一家族多个案例保留但不增加独立家族数；已用于调优或无法证明独立性的家族标为回归，独立泛化保持未知，不自动替换用户素材。记录英文实际覆盖字段，不推论英文线路全流程或价签能力。
- [ ] 由操作者核准每例必要业务事实、视觉区域/状态、模板规则、关键错误、容错与未知范围；固定素材、基准及配置身份。被测 Agent 不得选择真值或改通过政策，不能从候选反推预期答案。
- [ ] 预登记每例预算、重复政策、停止/缺失结果处理和与后续冻结候选绑定的步骤；案例清单提前冻结不等于最终运行构建已知，派发前须绑定 20 的确切候选，不能倒填或拼接不同身份结果。
- [ ] 准备独立审核程序和可用记录方式：审核者不看生成过程自评，逐例核对原始成果、内容/样式/状态、自动结论、人工修正、应用与正式出图；记录审核/修正分钟，争议有留存和解决规则。
- [ ] 定义关键错误误通过及逐项证据，区分技术合格、业务质量、unknown、运行失败和人工补救；报告模板能够按四个分层列全计划与尝试，集运行完整不能宣称客户自助成功率达标。
- [ ] 建立首次结果、后续调优和事后重评分的污染记录：查看后用于调整资料/策略/模型/规则的集降为校准/回归；评分修复可另存事后分析，但不算新独立样本，下一次独立泛化需换未参与调整的家族。
- [ ] 从公开评估/审核入口离线确认清单、基准、预算与记录可读取，准备成果可分别交给 22–25；本票只准备案例、计划与审核材料，不改运行时、工具合同或通用记录能力。格式无法表达需求时退回 14/15 修复，并由 20 重新核对候选身份。任何真实模型派发与三十六次结果均不属于本票关闭条件。

**测试接缝：** 公开评估计划/基准检查与独立审核记录入口，观察可读取清单、校验问题和记录成果；以离线核查和人工核准完成准备，不调用模型、不以构造私有对象代替可执行计划。
