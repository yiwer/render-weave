# 21: 固定候选完成中英文四类任务的可信反馈纠偏

**What to build:** 维护者看到模型在固定候选上实际利用可信基准纠正缺陷，获得中英文四类任务各两次有效观测，而非只证明工具被调用。

**Blocked by:** 20

**Status:** ready-for-agent

**Trace:** [父规格](../spec.md)；US40–43、US49–50、US54；A15 的真实模型部分；D13。14 负责离线编排与案例准备，本票不重复实现。

- [ ] 派发前登记中文/英文各数据定义提取、数据集提取、模板辅助设计、模板辅助修改四类任务，共 8 种场景、16 个有效观测单元；沿 14 的缺陷、预算、修改范围和独立事实，不在看到结果后换题。
- [ ] 全部单元使用 20 的同一候选身份；提取任务显式载入可信内容事实，模板任务显式载入可信区域。至少一个模板场景超过 20 个区域，并实际处理后续页必修问题。
- [ ] 每个单元保留原始成果、可信反馈、修正成果和最终检查；核准问题得到修正，授权范围外内容保留，未知内容仍明确未知，末次有效反馈与宿主终检指向相同内容身份。
- [ ] 每个计划内有效观测均满足场景条件才判通过；有效失败保留为失败，不覆盖重跑直到成功。仅缺有效观测且没有有效失败时标未完成；额度不足保存记录并停止，不自动轮询或换模型。
- [ ] 记录所有尝试的用量、耗时、停止原因和已知/未知成本；真实失败与基础设施无效分开，不用假执行器或工具受控测试替代真实纠偏证据。
- [ ] 历史证据只在身份和验收条件逐项匹配时复用。派发前列明与[原票 38](../../agent-template-authoring/issues/38-retest-after-quota-recovery.md)共享单元的案例、重复序号、预算、身份和唯一执行票：新增共享单元由本票派发，原 38 仅引用它并独立执行其他四场景/审核工作。每个不可变观测只能占一个重复槽位，不能被两票重复派发或计作两次观测。
- [ ] 汇总 8 种场景、16 单元的完整计划、结果与局限；独立样式/状态业务审核仍在原 34/38 留证，四场景回归的关闭结论仍在原 38。
- [ ] 若实际反馈暴露实现缺陷，回到责任票修复并生成新候选后重判证据有效性；不得在验收轮次内改通过阈值或可信答案。

**测试接缝：** 固定候选的公开评估 CLI → 真实 Agent → 公开 MCP 检查/比较 → 宿主终检。仅使用计划内真实调用，不运行无关模型探索。
