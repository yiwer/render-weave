# 01: 数据定义与数据集有 DSL 1.0 参考、Schema 与兼容承诺

**What to build:** DSL 使用者能读到数据定义 DSL 与数据集文档的完整参考，并用 JSON Schema 在编辑器中校验；兼容策略写成 ADR。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** 第三阶段 PRD；用户故事 25–29；验收 A01、A02、A03。

- [ ] 人读参考（`docs/dsl/`）覆盖 `renderweave-schema/1` 的全部写法与数据集文档格式：字段类型、约束、引用、列表、命名规则、编译产物要点与已知限制。
- [ ] `schemas/` 发布数据定义与数据集文档的 JSON Schema 2020-12。
- [ ] 一致性测试：
  - 仓库内全部有效的数据定义与数据集语料都通过 Schema；
  - 未知键、错类型、错枚举、缺必填的变异样本，被 Schema 与解析器同时拒绝。
- [ ] Schema 通过而引擎拒绝的语义检查有类别清单，例如约束冲突、引用不存在、版本号与发布不符；每类至少一个测试。
- [ ] Agent 参考迁到 `agent/reference/`，与人读参考同源，示例在测试中校验为 0 问题。示例改用第三个领域（例如会议胸牌），既不是线路牌，也不是票据 09 验收用的商品价签，避免向 Agent 泄露验收答案（M222）。
- [ ] 写 ADR：DSL 1.0 兼容策略，包括 1.x 只做加法、继续拒绝未知键、升到 `/2` 的条件与迁移说明。
- [ ] 现有测试全部通过，共享样例不改动。

**测试接缝：** Schema 与解析器的一致性测试，语料取自仓库现有文档，另加变异样本；不为解析器内部函数单独写测试。
