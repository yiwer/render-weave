# 03: Agent 经 renderweave mcp 使用只读工具

**What to build:** Agent 或任何 MCP 客户端经 `renderweave mcp`（stdio）使用读取、校验、草稿预览、元素检查、局部放大、资源列表与 DSL 参考工具；工具合同稳定且只读。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** 第三阶段 PRD；用户故事 19–24、34；验收 A04。

- [ ] `renderweave mcp` 以本轮工作目录与只读的工作区快照启动，实现 MCP 初始化、工具列表与工具调用。
- [ ] 读取工具：工作区文档的列表与内容、资源列表。
- [ ] 校验工具：数据定义（按顺序在内存中发布）、数据集、模板静态检查；问题都带位置。
- [ ] 草稿预览：支持已保存模板、用工作副本替代（M50）、内联数据集；返回图片内容块与问题清单。模式固定为草稿，DPI 有上限。
- [ ] 元素检查：按元素路径返回布局摘要，包括位置、尺寸、字号、压缩比与是否溢出。
- [ ] 局部放大：按像素区域裁切工作目录内的图片并放大，同时返回原图尺寸。
- [ ] DSL 参考工具：返回 `agent/reference/` 与 `schemas/` 的内容。
- [ ] 合同测试：
  - 工具清单与输入 Schema 的快照；
  - 每个工具的正常与异常输入；
  - 越界路径被拒绝；
  - 不存在写入、发布、删除与正式出图的途径；
  - 工作副本预览不改动已保存模板。
- [ ] 验证脚本 `scripts/m190/` 改用本服务，M190 的 loop 步骤（埋点标记）复测通过。

**测试接缝：** 用 JSON-RPC 客户端直接驱动 `renderweave mcp`，不经模型；断言工具输出，并确认文件系统没有变化。
