# 05: 审核数据定义候选并发布为静态数据定义

**What to build:** 代建工程师在本地审核页对照示例图审核数据定义候选，逐项处理待确认项；审核通过后，用 `renderweave agent apply` 发布为静态数据定义。

**Blocked by:** 04

**Status:** ready-for-agent

**Trace:** 第三阶段 PRD；用户故事 7–9、11–13；验收 A07、A08。

- [ ] 审核页由本地命令打开，包括：
  - 示例图，可局部放大；
  - 字段清单：名称、类型、约束、对应图上哪一部分；
  - 编译产物摘要；
  - 待确认项与 Agent 的说明。
- [ ] 待确认项逐项处理：采纳候选、改值或标为空；其余值整体确认一次（M47）。审核结果保存为 `review.json`，可以关闭后重开继续。
- [ ] `apply` 只接受审核通过的轮次，经发布入口发布为下一个版本（M18）；审核时改过的内容以审核结果为准。
- [ ] 以下情况拒绝应用，列出差异，并要求明确选择覆盖或重做（M51）：
  - 工作区中的同名数据定义已发布了新版本；
  - 工作区指纹已变化。
- [ ] 未审核、审核未通过以及应用失败时，工作区保持不变。

**测试接缝：** 公开 CLI 与审核结果文件。审核页以接口级测试为主，另在浏览器里手动走查一遍，并截图存档。
