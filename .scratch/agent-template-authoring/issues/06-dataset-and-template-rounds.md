## Answer

2026-10-15 已完成。

**成果**（说明见 [docs/agent-tasks.md](../../../docs/agent-tasks.md)，决定见 M228）

- **发起**：
  - `agent run --task 数据集提取 --definition 名称[@版本]`：基于已发布的数据定义，只写名称时取最新版本；
  - `agent run --task 模板辅助设计 --dataset <id> --request <出图请求>`：基于已保存的数据集，数据定义取它选定的那一份；
  - 两者都要 `--workspace`；缺前提时提示先做哪一步。
  - 出图请求规范化后存进轮次目录的 `request.json`，Agent 改不到；数据集提取可选给，用工作区已有的模板预览。
  - 提示词在 `agent/tasks/dataset-extraction.md`、`template-design.md`，不含具体业务；模板辅助设计的轮数上限为 80。
- **位置的写法**（`src/agent/locations.ts`）：
  - 数据集写字段路径，列表序号从 1 开始，与问题清单一致；
  - 模板写元素路径，可以省略模板名；被调模板里的元素写在被调模板的文件下。
- **成果校验**（`src/agent/candidates.ts`，审核与应用共用）：
  - 候选数据集与模板先按 `schemas/` 中的 JSON Schema 做前置校验（`src/dsl-schema.ts`），再经引擎校验与静态检查；
  - 数据集与模板只新建，id 与名称不能与工作区重复；
  - 数据集先填上待确认项的候选值再校验；落在待确认位置上的问题记为 `deferred`，留给审核；
  - 模板辅助设计时，出图请求的主模板必须在候选中；
  - 图上位置对不上时只记提示，不影响结论。
- **审核**：
  - 预览（`src/agent/preview.ts`）由 RenderWeave 以草稿模式重新渲染，DPI 按示例图的像素宽度折算，按输入哈希缓存在 `previews/`；
  - 审核页把示例图与预览上下对照，两图都可放大，缩放与滚动可以联动；
  - 数据集有逐值清单，模板有元素清单、基准与参数；
  - 数据集中未处理的待确认项先用候选值；待确认项处理完才能通过，所以处理完之前不会写入数据集（M46）；
  - 模板辅助设计时，预览的严重问题阻止通过。
- **应用**：
  - 数据集与模板保存为 `dataset-<名称>.json`、`template-<名称>.json`；
  - 写入前在当前工作区上重新校验；
  - 工作区已有同 id 的数据集或同名模板时，即使 `--overwrite` 也拒绝；
  - 其余冲突与失败的处理同 05。

**不依赖模型的测试**（`test/agent-dataset-template.test.ts` 10 项）

- **发起**：
  - 任务顺序与 12 种输入错误；
  - 轮次记录所基于的数据定义、数据集与出图请求；
  - 出图请求的规范化；提示词、DSL 参考与开放的工具。
- **数据集**：
  - Schema 前置校验；id 重复、选定的定义不对、约束不满足；
  - 待确认位置上的问题留给审核；位置不存在时结构不合格；种类不对。
- **数据集的审核**：
  - 逐值清单；
  - 预览与按同样输入直接渲染的结果逐字节一致，且不是 Agent 草稿目录里的图；
  - 处理后预览随之更新；
  - 待确认项没处理完时不能通过，也不能应用（M46）。
- **数据集的应用与出图**：写入审核后的数据集，经 `deliverBatch` 正式出图，可以完整读取出图记录。
- **模板**：
  - Schema 前置校验；主模板不在候选中、元素不存在、与工作区重名、被调模板不存在；
  - 元素路径可以省略模板名，穿进被调模板的图上位置只记提示。
- **模板的审核**：
  - 元素清单；
  - 预览逐字节一致；改动或删去元素后预览随之更新；
  - 画板尺寸范围装不下出图请求时，预览报严重问题，不能通过。
- **模板的应用与出图**：保存模板后正式出图；工作区出现同名模板时，即使覆盖也拒绝，工作区不变。
- **审核页服务**：提供预览图，拒绝不合规的文件名。
- **能否变红已验证**：临时让以下四处失效，相应用例都失败，之后已恢复：
  - 预览叠加候选模板；
  - 待确认位置的问题延后；
  - 模板重名检查；
  - Schema 前置校验。
