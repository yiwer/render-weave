# 07: 带反馈的下一轮与模板辅助修改

**What to build:** 代建工程师可以带着反馈发起下一轮，也可以对已保存的模板提出修改要求，拿到工作副本、结构化差异与修改前后的预览，审核后应用。

**Blocked by:** 06

**Status:** ready-for-agent

**Trace:** 第三阶段 PRD；用户故事 14、15；验收 A09。

- [ ] `--from <上一轮> --feedback <文件>`：下一轮拿到素材、上一轮成果（含审核时的修改）与反馈（M58）。每轮一个独立目录，轮次链可查。
- [ ] 模板辅助修改：输入为已保存的模板与修改要求，要求可以带元素路径；成果为工作副本（M49）与结构化差异。
- [ ] 审核页显示修改前后的预览，两者都由 RenderWeave 渲染（M50、M52），同时显示差异。
- [ ] 应用前比对工作副本所基于的保存内容。模板已被他人保存时显示差异，由人选择覆盖或重做（M51）。
- [ ] 以用户在 M215 验收时指出的两类问题（地标位置、道路名分布）作为修改要求，一轮内修正，并通过对应检查。

**测试接缝：** 同 05；差异与预览以接口输出断言。
