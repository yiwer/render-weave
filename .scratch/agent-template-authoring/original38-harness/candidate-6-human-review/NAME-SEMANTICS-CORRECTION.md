# M358：站名圈号语义更正与验收影响

2026-10-26，用户明确更正：“继续补充：其实① ② 不是地标，而是站名的一部分而已，数据源是错误的”。[原话与迁移清单](review-02-name-semantics.json)单独保存，不修改旧观测。

## 判断

这是业务事实与数据建模基准错误。完整站名应包含其圈号后缀，例如 `田贝②`；不能存成 `name: 田贝` 加 `landmark: res:landmark-2`，也不能评分前删除圈号。①和②不同的站名必须保持可区分。排版、本站和已过站状态应作用于完整站名，是否需要局部样式由真实参考决定，不以图片字段伪造语义。

M77的原判断被M358更正。原四8/8记录仍是旧配置下的实际执行事实，但依赖“圈号是地标”的数据定义约定、转录真值及版面门槛，不能作为更正后的业务验收通过证据。既有原始报告、候选、实际成果、审核包和归档保留原字节；原38完整门槛条目重新待验，视觉问题继续保留。
