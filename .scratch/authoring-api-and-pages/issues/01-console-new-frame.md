# 01: 控制台换成标题栏模块下拉的新框架，出图各页迁入后行为不变

**What to build:** 出图控制台的新框架：标题栏模块下拉、快捷键与状态栏，第 29 版原型色板；现有九个页面迁入，左栏留给 Agent 但先不显示。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [P1 PRD](../spec.md)「控制台新框架」；用户故事 28；验收 A01、A11；M208、M341。

- [ ] 标题栏：品牌、模块下拉（数据定义、模板、数据集、出图、资源、用量、管理），按角色只列能进的模块；`Ctrl+1`… 切换模块。
- [ ] `Ctrl+K` 打开模块与常用动作的列表（新建数据集、从 Excel 导入、上传资源等），不搜对象。
- [ ] 状态栏：连接状态、当前租户、本月剩余额度、进行中的批次数。
- [ ] 左栏位置留出，P2 接入 Agent 前不显示；窄窗口下右侧模块占满宽度，没有横向滚动。
- [ ] 视觉按原型第 29 版：正文 `#22150F`、次文字 `#5B4334`、弱提示 `#7F6A59`、细线 `#D9C8B0`、页面底 `#FDFBF6`、强调与主按钮 `#8E3B24`；调和橙 `#F17D13` 只用在标志、进度条、选中页签下划线这类不承载文字的位置；正文与背景的对比度不低于 4.5。
- [ ] 一页一事：不拼统计卡片与侧栏卡片堆叠，用细分隔线代替框，状态用圆点加文字。
- [ ] 数据集、Excel 导入、批次、出图记录、资源、用量、管理七类页面迁入新框架，行为与接口调用不变；路由兼容旧链接。
- [ ] 现有控制台浏览器用例全部通过，只改选择器，不改断言。

**测试接缝：** 控制台浏览器用例（Docker 后端那组）；页面只调开放 API，不加新端点。
