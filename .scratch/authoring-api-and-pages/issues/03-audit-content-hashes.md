# 03: 审计记下每次代建写入的前后内容哈希与差异摘要，可按主体筛选并导出

**What to build:** 审计表加前后内容哈希、差异摘要、轮次与理由；审计接口与管理页按主体种类筛选、导出 CSV。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [P1 PRD](../spec.md)「审计」；用户故事 26；验收 A08、A10；ADR-0022、M261、M263。

- [ ] 迁移给 `audit_events` 加可空列：前内容哈希、后内容哈希、差异摘要（增删改计数，加至多 50 个路径）、轮次、理由；旧行保持空。
- [ ] 写审计的辅助函数接受这些字段；指回旧修订填前后修订的内容哈希，推送提交在差异摘要里列出改动的文档与各自的前后哈希（至多 50 份）。
- [ ] 审计接口回答新字段，按主体种类（成员、API 密钥、代建工程师、平台管理员、系统）与时间筛选；OpenAPI 只加可选字段与参数。
- [ ] 管理页的审计日志显示内容哈希与差异摘要，可按主体筛选，筛选结果导出为 CSV。
- [ ] 跨租户的操作照旧标出；别的租户的审计行在 Docker 后端被行级安全挡住。

**测试接缝：** 开放 API：做一次推送与一次指回，再从审计接口读回断言字段；导出 CSV 经接口断言。
