# 05: 发布数据定义草案前看到字段级差异与数据集影响，发布后可以用旧版另发回退

**What to build:** 草案的发布预检与发布：差异、失配的数据集份数、仍绑定旧版的模板；发布成对写入原文与编译产物；回退是从旧版另起草案再发布。

**Blocked by:** 02、04

**Status:** ready-for-agent

**Trace:** [P1 PRD](../spec.md)「发布静态数据定义」；用户故事 8、9、10、11、29；验收 A04、A10；ADR-0008、ADR-0022、M278。

- [ ] 发布预检（只读）：与基于版本的字段级差异（`diffDefinition`）；绑定基于版本的数据集逐份按新编译产物校验，回答失配份数与前 20 份的问题摘要；超过 1,000 份只校验前 1,000 份并标为"未全部核对"；仍绑定旧版本的模板列表。
- [ ] 发布带草案的预期 SHA-256；用 `publishStaticSchema` 得到下一版本，在一个事务里写入原文与编译产物，然后删除草案。
- [ ] 发布产物与本地 `renderweave publish` 对同一份数据定义的结果逐字节相同。
- [ ] 严重问题拒绝发布，问题码与本地发布相同；版本号已被并发的发布占用时答 409。
- [ ] 回退：从旧版本另起草案再发布，得到内容与旧版相同的新版本；旧版本保持不变。
- [ ] 发布与预检进权限矩阵（`authoring.publish`）；审计记前后内容哈希与差异摘要。

**测试接缝：** 开放 API；发布产物与本地 `publish` 输出比字节；预检用 M402 样例与构造的失配数据集。
