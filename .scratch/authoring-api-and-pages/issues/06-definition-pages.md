# 06: 客户管理员在数据定义列表、详情与发布记录三页上改结构并发布

**What to build:** 数据定义的三张页面：列表、详情（字段表原地展开编辑、手动添加字段、校验、编译预览）与发布记录（差异、影响、发布与回退）。

**Blocked by:** 01、05

**Status:** ready-for-agent

**Trace:** [P1 PRD](../spec.md)「数据定义草案」「发布静态数据定义」；用户故事 1–12、27；验收 A11；M299；原型画板 06、07、08。

- [ ] 列表：每个名称的当前版本、草案状态、引用数；新建数据定义；右键一行有打开、在新标签页打开、查看发布记录、导出编译产物 JSON Schema、复制引用、从这一版另起草案。
- [ ] 详情：字段表列显示名称、字段名称、类型、约束、必填与"谁在用"；选中一行原地展开编辑；手动添加字段覆盖全部九种字段类型；随时校验，问题定位到字段；预览编译产物。
- [ ] 改字段名称或删字段时提示会影响的绑定与模板。
- [ ] 发布：先显示字段级差异与预检结果，再发布为下一版本；失配数据集与未全部核对的情况写清楚。
- [ ] 发布记录：谁在何时发布了哪一版、改动摘要、内容哈希；以某一版另发新版本。
- [ ] 客户操作员只读；"从示例图提取""从数据集提取"两个入口在 P2 接入前不显示。
- [ ] 浏览器用例走通"另起草案 → 加必填字段 → 看差异与影响 → 发布 → 以旧版另发"。

**测试接缝：** 控制台浏览器用例（Docker 后端那组）；页面只调开放 API。
