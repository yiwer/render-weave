# 07: 经开放 API 暂存模板工作副本、预览并定位元素，再保存为新修订或指回旧修订

**What to build:** 服务端的模板工作副本（每个模板至多一份，记基准修订）、工作副本的草稿预览与元素定位、复制为新模板、带基准核对的保存模板，以及向客户管理员开放的指回旧修订。

**Blocked by:** 03

**Status:** ready-for-agent

**Trace:** [P1 PRD](../spec.md)「模板工作副本」；用户故事 19、21、22、23、29；验收 A05、A10；ADR-0021、ADR-0022、M265、M267。

- [ ] 暂存：整份替换，带预期 SHA-256，记基准修订；暂存不影响当前修订，出图照旧读当前修订；可以丢弃工作副本。
- [ ] 草稿预览可以指定用工作副本，与已保存模板走同一套检查与限制（`measureRender`、按租户的并发与频率）；问题与本地渲染相同。
- [ ] 预览回答带每个元素实例的源模板与在模板文档里的位置，对循环容器与子模板调用都正确；渲染入口把这项作为可选输出公开，从 `src/index.ts` 导出类型。
- [ ] 复制为新模板：新名称，内容与基准数据定义取当前修订，成为没有基准修订的工作副本，保存时记修订 1。
- [ ] 保存模板：基准修订等于当前修订才保存，否则答 409 带 `revisionDiff` 两边差异；显式 `overwrite` 才覆盖；模板静态检查有严重问题时拒绝；按 M265 记修订，当前修订指向它，删除工作副本；修订记下来源（推送或网页）与主体。
- [ ] 指回旧修订开放给有 `authoring.publish` 的客户管理员。
- [ ] 客户端点与代建端点共用一份实现；全部进权限矩阵与跨租户端点清单；每次写入记审计，带前后内容哈希与差异摘要；新表启用行级安全；OpenAPI 快照只有加法。
- [ ] `GLOSSARY.md`「模板修订」补上网页保存这一来源；决定记 M 编号。

**测试接缝：** 开放 API；元素定位另经引擎渲染入口测，输入用 M402 模板（循环与子模板）；预览问题与本地 `render` 比对。
