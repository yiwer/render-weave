# 08: 客户管理员在模板设计页点选元素，用属性面板、参数、结构与规则做小改

**What to build:** 模板设计页：草稿预览上点选元素，属性面板按 DSL 的 JSON Schema 生成并写回工作副本，另有参数、结构、规则三页；暂存、切换样例数据集与模式、缩放、右键菜单。

**Blocked by:** 01、07

**Status:** ready-for-agent

**Trace:** [P1 PRD](../spec.md)「属性面板、参数、结构与规则」；用户故事 13–19、27；验收 A06、A11；M205、M299；原型画板 10。

- [ ] 预览上点选元素：按布局摘要的元素框命中，按元素定位打开模板文档里的位置；选中框与元素路径显示在图上。
- [ ] 属性面板按 `schemas/template.schema.json` 里该元素类型的属性生成：位置尺寸、文字、图片、颜色、绑定、条件显示、状态样式、适配；只能填数，不做自由拖拽。
- [ ] 参数页：对外参数与内部参数的显示名称、类型、约束与缺省值。
- [ ] 结构页：元素树（容器、循环容器、子模板调用），与预览选中双向同步；子模板调用可打开子模板的设计页。
- [ ] 规则页：所选元素相关的检查项、缩字组、字形压缩下限与缩字下限。
- [ ] 每次改动重渲染草稿预览并刷新问题清单；页面内可撤销、重做；"保存"暂存工作副本，并显示未保存的改动数。
- [ ] 工具栏：选择、平移；切换样例数据集（含压测数据）、草稿与正式模式、缩放。
- [ ] 右键菜单：复制元素路径、在结构中定位、打开绑定的字段。"让 Agent 修改""留评论"在 P2、P4 接入前不显示。
- [ ] 每种元素至少一项属性改动的浏览器用例：写回后通过 `checkDslDocument`，预览随之变化。

**测试接缝：** 控制台浏览器用例（Docker 后端那组）；属性面板的生成规则另有单元测试，只经"给元素类型与文档、得到可编辑项与写回结果"这一入口。
