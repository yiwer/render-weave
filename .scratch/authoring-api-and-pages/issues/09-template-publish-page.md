# 09: 保存模板修订前看到结构化差异与前后对比，随时指回旧修订

**What to build:** 发布模板修订页：结构化差异、同一份样例数据集改前改后的对比图、修订历史与指回；基准不符时显示两边差异，确认后才覆盖。

**Blocked by:** 01、07

**Status:** ready-for-agent

**Trace:** [P1 PRD](../spec.md)「发布模板修订页」；用户故事 20、21、23；验收 A05、A11；M265、M299；原型画板 12。

- [ ] 结构化差异按元素路径列出改动，标出新增、删除与修改的属性。
- [ ] 改前改后对比：当前修订与工作副本用同一份样例数据集各渲染一张，可以换样例数据集。
- [ ] 保存为新修订；基准修订已变时显示两边差异，明确选择覆盖才保存。
- [ ] 修订历史：修订号、主体、时间、来源（推送或网页）；指回任一旧修订，指回前确认。
- [ ] 保存与指回之后的提示写明审计已记下主体与前后内容哈希。
- [ ] 多份数据集的改动影响一段在 P3 接入前不显示。
- [ ] 浏览器用例走通"改字号 → 看差异与对比 → 保存 → 指回上一修订"。

**测试接缝：** 控制台浏览器用例（Docker 后端那组）；页面只调开放 API。
