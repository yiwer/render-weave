# 12: 平台管理员在控制台看服务健康、管理租户、套餐、成员账号与代建令牌

**What to build:** 平台管理员登录控制台后的平台管理页，全部用已有的 `/v1/platform/*` 端点，缺的只读汇总用加法补。

**Blocked by:** 01

**Status:** ready-for-agent

**Trace:** [P1 PRD](../spec.md)「平台管理页」；用户故事 33、34；验收 A10、A11；M247、M261、M274；原型画板 20。

- [ ] 平台管理员登录后只进平台管理，模块下拉里没有租户内的模块。
- [ ] 服务健康一行：就绪、worker 报到数与构建、队列积压。
- [ ] 租户列表：套餐、本月出图、本月 Agent token、成员数、状态；展开一行可改套餐（每月出图、单张最大像素、并发，M274）与建成员账号，初始密码只显示一次。Agent token 只显示用量；按额度拦截是 P4（M242）。
- [ ] 开通租户；签发与吊销代建令牌，令牌只显示一次。
- [ ] 补的汇总端点只给平台管理员，进权限矩阵；OpenAPI 只有加法。
- [ ] 页面上写明对客户租户的每次操作都记进该租户的审计。

**测试接缝：** 开放 API（新增的汇总端点）；控制台浏览器用例走通"开通租户 → 设套餐 → 建客户管理员"。
