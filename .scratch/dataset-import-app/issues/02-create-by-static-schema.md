# 02：按静态数据定义创建数据集

**What to build:** 用户直接选择静态数据定义的确切版本创建数据集，模板只在预览和出图时按需选择。

**Blocked by:** 01

**Status:** ready-for-agent

**Trace:** M374；[接入方案](../../../docs/excel-agent-app-integration.md)第 1 项。

- [ ] 数据集页可以选静态数据定义新建；不存在任何模板时仍可完成填写与保存。
- [ ] 静态数据定义详情提供创建数据集入口，带入当前查看的确切版本；历史版本不会被替换成最新版。
- [ ] 模板带入的新建入口仍可用，模板与定义不匹配时明确拒绝，不默默换定义。
- [ ] 已有数据集无兼容模板时仍可编辑、保存；有兼容模板时预览/出图保持原行为。
- [ ] 原有 Excel 导入行为和 `/v1/excel-imports` 合同不变；名称能与后续智能导入区分。
- [ ] 不提前展示不能执行的“智能导入”按钮；功能完成后再由 P2 接入。

**测试接缝：** 控制台浏览器流程覆盖无模板非公交定义、新建/保存/重开、历史版本与模板入口；既有数据集和标准表导入 API 回归。无需模型调用。
