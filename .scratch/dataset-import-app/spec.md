# 按静态数据定义创建与智能导入数据集

用户在确认接入方案后要求构建模块及具体页面（M375）。按现有数据集权限，提供不依赖模板的新建入口、上传与后台执行、来源和批注审核、整组保存。复用现有 Tool Runner 与正式 Excel 检查/审核能力，任务类型 `dataset-extraction`。

验收：无模板且非公交定义可创建；精确版本贯穿流程；刷新恢复任务；批注/VML 和字段来源可核对；修改原因留存；重复提交幂等、末项冲突整组回滚、跨租户不可访问；运行中取消、过期租约不自动重跑；真实 Claude 小样通过。

实施范围是默认关闭的内部应用模块，不将模型渠道、完整生产隔离、通用 Agent 多任务/SSE、原有 P0/P1 评估门槛和 115 网页业务验收标为通过。操作与部署见 [说明](../../docs/dataset-import.md)。
