# DSL 1.x 平面设计能力演进（P1 / P2）

2026-10-19。DSL 1.0（`renderweave-template/1`）已完成横竖版公交线路牌、会议胸牌与超市价签的端到端验证。面向更通用的平面设计图（多栏标签、价签、正反面站牌、自适应宽窄画板、多字号竖排）时，需要在遵守 ADR-0004（单步具名运算，不引入文本表达式）与 ADR-0016（`renderweave-template/1` 只做向后兼容加法）的前提下，补齐 P1（派生与列表布局）与 P2（自适应矢量图形、字距与竖排混排、单色图标重染）能力。P0（缩字下限放宽、多行段落换行与文本装饰线）由其他设备并行推进，不在本规格范围内。

## 范围与验收映射

| 验收编号 | 维度 | 通过条件 |
|---|---|---|
| A01 | 向后兼容 | 现有全部有效语料、M402 共享样例、已有 golden 与布局快照在不改动文档的情况下保持字节与行为一致（ADR-0016） |
| A02 | DSL 参考与 Schema 同进同退 | 新增语法同步写入 JSON Schema、人读参考与 Agent 参考；一致性测试覆盖正向语料与结构变异，Schema 与引擎解析器判断一致 |
| A03 | 派生变量扩充（P1） | 支持数值乘、除、取模，按分隔符拆取文本片段 `splitPart`，以及条件分支中的 `all` / `any` 复合条件；越界、除零与精度超限按约定处理 |
| A04 | 循环与流式换行（P1） | 循环容器支持 `reverse`、`slice` 与纵向 `mergeBy`/`spanBy`；堆叠布局与循环容器支持 `wrap` 自动折行/折列及 `crossGap` |
| A05 | 矢量图形缩放（P2） | 路径、多边形与线条支持可选 `viewBox` 与缩放适配方式，随元素框实际尺寸伸缩；未声明 `viewBox` 时保持 M94 原坐标不拉伸 |
| A06 | 字距与竖排混排（P2） | 文本支持固定字间距 `letterSpacing` 与横排 `tightenSpacing`；竖排文本支持文本片段独立字体/字号及 CJK 竖排标点旋转 |
| A07 | 图片单色重染（P2） | 图片元素支持可选 `tint` 颜色属性（含变量绑定与状态样式覆盖），保留原图透明度并重染为目标颜色 |
| A08 | Agent 评估门槛 | 涉及 `agent/reference/template.md` 的改动，单票通过 `npm test` 双端参考一致性检查，整批票据完成后统一复跑一次 `npx tsx scripts/agent-eval/run.ts`（Haiku 5.5）连续两次达线并执行 key 扫描 |
