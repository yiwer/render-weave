# 01: 二维码从文本绑定到可扫码图片

**What to build:** 通过公开渲染入口和现有 CLI，将固定文本、数据字段或模板参数生成二维码；同时交付可读图片、尺寸摘要及可定位的失败诊断。

**Blocked by:** None (can start immediately)

**Status:** resolved

**Trace:** 第二阶段 PRD；用户故事 1、2、3、4、5、11、12、13、14、48；验收 A01、A02、A04。

- [x] 定稿二维码 DSL 与独立样例，固定文本、文本字段和文本参数均可使用；支持 L/M/Q/H、缺省 M，中文、数字与 URL 文本保持原文。
- [x] 选定并锁定编码依赖，记录许可证及选择依据；从最终 PNG/JPEG 使用独立解码实现读回原文，覆盖 120/300 DPI，不以内部矩阵比对代替验收。
- [x] 确定宽高、方形模块、整数像素、最小 2 px 和必要留白共同参与布局；摘要包含码种、实际码区、留白与模块像素尺寸。
- [x] 前景/背景支持颜色绑定，缺省黑白；拒绝透明或同色。条件显示、状态样式、循环实例及 90°旋转可以实际出图并准确定位。
- [x] 空内容、类型不符、容量超限与空间不足返回稳定问题码；草稿只标错误位置、不画伪有效码，正式不出图，两种模式诊断一致。
- [x] 旧模板和 M402 原始样例不变，公开入口测试、CLI 示例、语法说明与少量画面回归随能力同时交付。

**测试接缝：** 优先通过本票涉及的公开渲染、资源管理、交付或重放入口观察外部行为，CLI 验证参数、退出码与文件成果；不测试私有中间结构。需要的小范围预重构先做并保持已有测试通过，再完成本票行为。
