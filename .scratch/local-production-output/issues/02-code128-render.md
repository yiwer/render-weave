# 02: 资产编号生成 CODE128 条形码

**What to build:** 模板直接把资产编号生成 CODE128 条形码，可选择显示下方文字；操作者通过现有 CLI 得到可扫码成品或明确失败原因。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Trace:** 第二阶段 PRD；用户故事 6、8、9、10、11、12、13、14、48；验收 A01、A03、A04。

- [ ] 定稿条形码 DSL，格式固定为 CODE128；内容支持固定文本、文本字段与参数，接受可打印 ASCII，保留前导零，拒绝自动数值转换。
- [ ] 最终 PNG/JPEG 在 120/300 DPI 的合格尺寸下由独立解码实现读回原始编号；锁定依赖并记录许可证及选择依据。
- [ ] 编码条与必要留白放入确定尺寸，最窄模块为至少 2 px 的整数；尺寸不足报严重问题，摘要能解释实际码区和模块尺寸。
- [ ] 下方文字开关、显式资源字体及缺字处理完整可用；文字占独立空间，不能侵占码区或留白。
- [ ] 颜色绑定、条件显示、状态样式、循环实例路径和 90°旋转有外部行为验证；空值、非法字符、透明/同色和尺寸不足按草稿/正式规则处理。
- [ ] 交付公开入口测试、可执行 CLI 样例和文档，现有模板保持兼容；本票不以二维码票提供共享内部模块为前提。

**测试接缝：** 优先通过本票涉及的公开渲染、资源管理、交付或重放入口观察外部行为，CLI 验证参数、退出码与文件成果；不测试私有中间结构。需要的小范围预重构先做并保持已有测试通过，再完成本票行为。
