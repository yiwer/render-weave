# 04: 导入资源为 v1 并用它完成出图

**What to build:** 资源维护者通过公开接口或 CLI 把现有图片、字体导入有内容版本的资源仓库，并立即用同一模板出图验证导入前后一致。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

**Trace:** 第二阶段 PRD；用户故事 29、33、35、47、48；验收 A01、A08、A11。

- [ ] 导入保留资源 ID、种类与实际字节，首个内容版本为 1；可查询当前元信息并按明确版本读取，内容有完整性哈希。
- [ ] 用导入前后两份资源仓库渲染同一 M402 请求，图片、问题清单及摘要一致；旧资源清单和旧单次渲染仍可用，原文件不改写。
- [ ] 重复 ID、不可读内容、非法路径及损坏的已导入内容返回可定位问题；不把当前文件的新字节静默归入旧版本。
- [ ] 导入排他提交，已有资源不覆盖；写入失败和同一目标并发导入不会产生可读取的半成品，原有资源保持可用。
- [ ] 公开版本读取支持固定一份资源版本映射供现有渲染入口消费；只扩展边界，不要求批量或出图记录先存在。
- [ ] CLI 准备、导入、查询和实际出图示例可从临时工作区复现，完成接口级和文件结果测试。

**测试接缝：** 优先通过本票涉及的公开渲染、资源管理、交付或重放入口观察外部行为，CLI 验证参数、退出码与文件成果；不测试私有中间结构。需要的小范围预重构先做并保持已有测试通过，再完成本票行为。
