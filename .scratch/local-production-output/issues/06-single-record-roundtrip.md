# 06: 一张纯文字牌的正式交付与自足重放

**What to build:** 以只有一个渲染项的批量请求交付一张纯文字牌，保存完整记录；把记录复制走并移除原工作区后，公开重放入口和 CLI 能重新得到相同结果。

**Blocked by:** 04：导入资源为 v1 并用它完成出图

**Status:** resolved

**Trace:** 第二阶段 PRD；用户故事 20、22、36、38、39、40、41、42、43、47；验收 A09、A10、A11。

- [x] 先完成单根模板、文本与图形、无模板调用的最小场景；对尚未支持的调用和图片记录明确拒绝，不能产出缺依赖却标为成功的记录。现有纯渲染接口仍可正常处理原有能力。
- [x] 请求包含唯一项标识、数据集引用或附带 JSON、参数与出图参数；本票仅接受单项正式交付，超出该范围明确拒绝，后续扩展保持合同兼容。
- [x] 交付包括图片、问题清单、布局摘要及带格式版本的记录；保存实际模板、数据集、静态定义及编译产物、请求与选项、使用的资源版本和字节。
- [x] 包括文本使用字体及后备字体配置的可用/缺失状态；内容先固定再渲染，归档的就是渲染读取的字节。
- [x] 构建标识覆盖实际引擎和锁定依赖，不能只用包版本或 Git 提交；复制到独立目录后重新渲染并比对图片、问题清单和摘要，不以返回旧图作为成功。
- [x] 损坏、缺文件、引用逃出记录、不支持的记录版本和构建不符均拒绝；不读当前工作区补缺，也不执行记录携带的程序。
- [x] 输出目标排他创建，项标识不能控制路径；内容完整后才发布完成清单，可捕获写入失败和单项进程中断不留下可读为成功的半成品。
- [x] 公开入口及 CLI 完成往返演示，记录与重放文件故障测试同步交付；默认独立复制，不依赖后续去重能力。

**测试接缝：** 优先通过本票涉及的公开渲染、资源管理、交付或重放入口观察外部行为，CLI 验证参数、退出码与文件成果；不测试私有中间结构。需要的小范围预重构先做并保持已有测试通过，再完成本票行为。

## Answer

2026-10-12 完成，已获用户确认提交。

- 新增公开 `deliverBatch`、`readOutputRecord`、`replayOutputRecord` 和 CLI `deliver`、`record-read`、`replay`。请求沿用 template/mode/items，单项支持数据集引用或 inline、对外参数、PNG/JPEG 出图参数；id 只作为数据保存。超出单项正式、单根文字/图形范围明确拒绝，原 render 保持兼容。
- 文档在异步读取前复制并序列化，字体先固定元信息和版本，再读取校验并独立保存，渲染使用同一份字节。记录保存静态定义原文与编译产物、实际请求/数据、后备及 SVG 字体配置，并包含缺失候选状态。内置定义保存其实际编译产物。
- `renderweave-output-record/1` 完成清单含文件哈希/字节数、资源 ID/种类/内容版本、实际构建标识。构建散列覆盖引擎、包元数据/锁文件及递归解析的实际生产依赖字节；相同构建可移动，源码执行与编译执行分别识别。读取验证完整性，重放核对构建后重新渲染并比较图片、问题清单及布局，归档图片改动后即使更新哈希也无法伪装成重放成功。
- 输出目录独占，受控文件名、内容先写且同步、完成清单最后原子发布；路径逃逸、链接、缺文件、损坏、不支持版本、构建不符均拒绝。默认独立字体文件，不依赖去重。写入失败留下无清单残留，可明确判断未交付。
