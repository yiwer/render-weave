# 02: 竖排站名：两端分布、收紧字距与纵向压缩

**What to build:** 竖排文本在固定高度内两端分布：首字墨迹贴顶、末字墨迹贴底、中间均分。放不下时先收紧字距，再纵向压缩字形，最多压到原高 60%，字号始终不变；仍放不下时返回严重问题。这是首期风险最高的部分，参照 design-layout-draw 的 CanvasKit drawCore V4 竖排算法（busbox-render-engine Legacy 是它的移植），并按 M82、M88 补齐"先收紧字距"、60% 下限与问题上报。本票同时建立逐字绘制流程，文字描边归本票。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 文本元素支持竖排书写方向与垂直方向的两端分布对齐。
- [ ] 在 M402 站名区的尺寸下，2 字、7 字、11 字站名的布局摘要分别给出字距与压缩比；2 字站名首尾两字贴边。
- [ ] 字距收紧到 0 之前不压缩字形；压缩比不低于 0.6；仍放不下时返回以元素路径定位到该文本元素的严重问题。
- [ ] 整个适配过程中字号不变（布局摘要可核对）。
- [ ] 文字描边（颜色、宽度），横排与竖排都适用；描边在字形变换之后施加，压缩后描边宽度不变，有对应测试。M402 的线路号文字用到描边（07 演示）。
- [ ] 适配的决定在绘制之前完成并写入布局摘要，绘制只按记录执行。
- [ ] golden 图片测试覆盖上述三种站名。
