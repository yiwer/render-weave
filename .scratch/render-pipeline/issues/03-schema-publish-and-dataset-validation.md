# 03: 数据把关：发布静态数据定义与完整的数据集校验

**What to build:** 提供"发布静态数据定义"入口（规格中的次接缝）：把数据定义 DSL 发布为静态数据定义，并编译出 JSON Schema 2020-12，工作区中的编译产物从此由发布生成，取代 01 的手写夹具。渲染入口的数据集校验扩展到全部字段类型与约束，并检查数据集选定的版本与模板基准是否一致。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 支持全部字段类型：文本、数值、日期、时刻、时间、布尔、图片、列表、数据定义引用；各类型可用的约束（必填、长度、范围、整数、枚举、正则、项数、图片允许来源）按类型校验。
- [ ] 发布时检测约束冲突（如最小长度大于最大长度、下界大于上界、枚举值违反其他约束），并拒绝引用成环、列表嵌套列表、引用不存在的静态数据定义版本，均返回问题。
- [ ] 编译产物内联展开引用，不允许未定义的键，`title` 取显示名称，时刻与时间使用 `rw-time`、`rw-datetime` 自定义格式并附等价正则；M402 两份数据定义的编译产物与 DSL 草稿中的编译产物一致（快照测试）。
- [ ] 数据集校验能定位到字段路径：必填缺失、值为 null、出现未定义的键、日期/时刻/时间格式错误、数值越界（数值按十进制精确解析与比较）。
- [ ] 图片字段中的资源引用不存在、或指向字体资源时返回定位到字段路径的问题（使用 01 的资源仓库，不依赖 05）。
- [ ] 数据集选定的静态数据定义版本与模板基准不一致时返回严重问题，属于阻止展开的问题（M102）。
- [ ] M402 数据集校验得到 0 个问题。
