# 04: 布局方式、尺寸方式与图形

**What to build:** 容器的三种布局方式、元素的三种尺寸方式、外观属性与五种图形元素，画板宽度变化时重新排布。用不含数据的 M402 版式骨架（顶栏、站点面板、道路带、底栏的容器与图形）演示。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 容器布局方式：自由（横向距左或距右、纵向距上或距下，M93）、堆叠（方向、间距、主方向分布、交叉方向对齐）、网格（行列定义取固定毫米、比例或随内容，行间距与列间距，行列从 1 编号，跨行与跨列）。
- [ ] 元素尺寸取固定、随内容或填满；支持最小与最大尺寸、外边距、内边距。
- [ ] 外观：填充、描边、四角各自的圆角、透明度、旋转；叠放顺序等于容器内的元素顺序（M72）。
- [ ] 图形：矩形、椭圆、线条、多边形、SVG 路径语法的路径；坐标以毫米计、相对元素框，框变化时图形不拉伸（M94）。
- [ ] M402 版式骨架在 740 mm 与 1500 mm 宽度下的布局摘要符合预期：站点面板与道路带随宽度变宽，固定尺寸的元素（箭头、底带收尾）不变。
- [ ] golden 图片测试覆盖 M402 版式骨架。
