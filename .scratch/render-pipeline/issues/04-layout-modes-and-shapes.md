# 04: 布局方式、尺寸方式与图形

**What to build:** 容器的三种布局方式、元素的三种尺寸方式、外观属性与五种图形元素，画板宽度变化时重新排布。用不含数据的 M402 版式骨架（顶栏、站点面板、道路带、底栏的容器与图形）演示。

**Blocked by:** 01

**Status:** resolved

- [x] 容器布局方式：自由（横向距左或距右、纵向距上或距下，M93）、堆叠（方向、间距、主方向分布、交叉方向对齐）、网格（行列定义取固定毫米、比例或随内容，行间距与列间距，行列从 1 编号，跨行与跨列）。
- [x] 元素尺寸取固定、随内容或填满；支持最小与最大尺寸、外边距、内边距。
- [x] 外观：填充、描边、四角各自的圆角、透明度、旋转；叠放顺序等于容器内的元素顺序（M72）。
- [x] 图形：矩形、椭圆、线条、多边形、SVG 路径语法的路径；坐标以毫米计、相对元素框，框变化时图形不拉伸（M94）。
- [x] M402 版式骨架在 740 mm 与 1500 mm 宽度下的布局摘要符合预期：站点面板与道路带随宽度变宽，固定尺寸的元素（箭头、底带收尾）不变。
- [x] golden 图片测试覆盖 M402 版式骨架。

## Comments

**2026-10-09 实施完成。** `npm test` 5 个文件 58 个用例全过（新增 22 个；CI 模式下 golden 只比对不改写），`npm run typecheck` 无错误。

实现要点：

- 模板解析拆为 `src/template/model.ts`（类型）与 `src/template/parse.ts`（解析与检查）；`place` 可写的属性随所在容器的布局方式检查，写错报 `template.unknownProperty`。
- 排版拆为 `src/layout/`：`index.ts` 负责测量（自下而上算随内容的尺寸）与决定（自上而下给框），`text.ts`、`shapes.ts` 记录文字与图形；绘制指令新增 save/restore（透明度、旋转、裁剪）、rect、ellipse、path。
- 布局规则见 M111，描边位置见 M110，写法见 DSL 草稿 README 的 S19、S20。
- 夹具 `fixtures/workspaces/m402-skeleton`：由 M402 主模板去掉数据与绑定、循环换成占位矩形而来。740 mm 下站点面板 740 × 100、站点列占位 694 × 96、底带收尾 x = 734；1500 mm 下站点面板 1500 宽、站点列占位 1454 宽，开往箭头、票价框、服务时间箭头、底带收尾与下一站区尺寸不变，顶栏留白多出 760 mm。
- 实测发现 M402 草稿的票价框估小了：68 × 11 mm 时"票价：一票制2元"放不下（需 60.6 mm，框内 50 mm）。按设计稿逐像素量得白框约 x 539.4–659.8 mm、y 13.3–29.2 mm，草稿与骨架都改为 120 × 16 mm，记在 DSL 草稿 README 的"更正"中。
- 外观逐像素验证（254 DPI）：叠放顺序、单角圆角、透明度、旋转、框内描边、椭圆、线条与虚线、多边形不随框拉伸、evenodd 与 nonzero 填充规则、容器裁剪。

已知限制：网格中随内容的行列只按只占一行（列）的元素算，跨行跨列的元素不撑大行列；自由布局中超出容器的元素不报问题。
