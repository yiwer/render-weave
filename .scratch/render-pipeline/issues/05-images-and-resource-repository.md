# 05: 图片元素与资源仓库

**What to build:** 文件形式的资源仓库按资源 ID 管理图片资源与字体资源；图片元素可以显示资源仓库中的 PNG、JPEG、WebP 与 SVG 图片，并支持三种适配方式。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 资源仓库按资源 ID 定位资源，区分图片资源与字体资源；资源引用写成 `res:资源ID`。
- [ ] 图片元素的来源为资源引用；适配方式支持完整显示、铺满裁剪与拉伸。
- [ ] SVG 加载时去除脚本与外部引用，并按出图分辨率栅格化，不出现模糊。两套参考引擎都不支持 SVG，需要单独的 SVG 栅格化方案（如 resvg），这是本票的风险点。
- [ ] 引用不存在的资源，或在图片位置引用了字体资源时，返回定位到元素的问题。
- [ ] golden 图片测试覆盖三种适配方式与 SVG。
