# 06: 模板变量、求值与模板检查

**What to build:** 模板的参数、派生变量、检查项、绑定、条件显示、状态样式、变量插槽与文本片段，以及出图前的模板静态检查。用 M402 的顶栏与底栏演示：开往、票价、服务时间、下一站随数据集与本站序号正确变化。

**Blocked by:** 03, 05

**Status:** ready-for-agent

- [ ] 对外参数与内部参数：类型为字段类型或颜色，带约束与默认值；对外参数未提供且没有默认值时为严重问题；调用方不能填写内部参数。
- [ ] 派生变量：条件分支（按序取首个命中，必须有"否则"；条件为结构化比较，右侧可以是固定值或变量；运算符为 eq、ne、lt、le、gt、ge、empty、notEmpty）、取项（首项、末项、第 N 项，超出范围得空值）、长度、加减；派生变量必须声明结果类型。
- [ ] 检查项：问题条件为真时，按其等级与提示文字记入问题清单。
- [ ] 绑定：可绑定属性的值写成变量引用即为绑定；缺值时得空值，不回退到设计时的占位内容。
- [ ] 条件显示：元素的显示与否可以绑定布尔值；隐藏的元素不参与布局。
- [ ] 状态样式：按某个变量的取值覆盖属性，未列出的取值沿用元素自身属性；覆盖值可以是字面值或变量。
- [ ] 文本由文字片段与变量插槽组成，每个片段可单独设字体、字号、颜色、字重与倾斜（以错切变换模拟，参考引擎没有）；插槽展示格式至少支持 `HH:mm` 与 `0.##`；文字描边。
- [ ] 模板静态检查：未知变量、路径穿过非单引用、模板内名称重复、绑定或状态样式的取值类型与属性不符，返回定位到模板与元素名称的问题。
- [ ] M402 顶栏与底栏：本站序号为 5 时显示"开往 万国城总站""下一站：田贝"及其地标、"票价：一票制2元"、服务时间；本站序号为 0 或本站是末站时"下一站"整行隐藏；本站序号超过站点数时返回严重问题；有线路号图片时显示图片，没有时显示倾斜描边的线路号文字。
