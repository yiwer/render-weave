# 06: 文字片段、展示格式与倾斜

**What to build:** 横排文本由文字片段与变量插槽组成，每个片段可以单独设定样式，插槽按展示格式输出，文本可以倾斜。本票的插槽只绑定数据集中的数据字段，参数与派生变量见 07。用 M402 的票价、服务时间、运营说明与线路号文字演示（各自直接绑定数据字段）。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 文本内容是文字片段与变量插槽的序列；每个片段可单独设字体、字号、颜色与字重，未设的沿用文本元素的设置；同一行中字号不同的片段按基线对齐。
- [ ] 插槽展示格式：时刻、时间与日期按 `HH:mm` 一类的模式格式化，数值按 `0.##` 一类的模式格式化（不出现浮点误差，如 2.10 显示为"2.1"）；未给格式时按类型的默认写法输出。
- [ ] 倾斜：以错切变换模拟（参考引擎没有），角度以度计；测量与布局摘要中的文本宽度包含倾斜带来的外扩。
- [ ] 插槽绑定的字段缺值时结果为空，不回退到占位内容（M16；草稿预览的占位见 12）。
- [ ] M402 演示：票价显示"票价：一票制2元"，其中"票价："为深灰、其余为橙色；服务时间显示 `HH:mm` 格式的首末班；运营说明显示"（…）「…」"；线路号文字以 12° 倾斜显示（描边见 02，二者组合在 07 演示）。
- [ ] golden 图片测试覆盖多片段混排与倾斜。
