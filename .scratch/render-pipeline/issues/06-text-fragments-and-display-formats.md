# 06: 文字片段、展示格式与倾斜

**What to build:** 横排文本由文字片段与变量插槽组成，每个片段可以单独设定样式，插槽按展示格式输出，文本可以倾斜。本票的插槽只绑定数据集中的数据字段，参数与派生变量见 07。用 M402 的票价、服务时间、运营说明与线路号文字演示（各自直接绑定数据字段）。

**Blocked by:** 01

**Status:** resolved

- [x] 文本内容是文字片段与变量插槽的序列；每个片段可单独设字体、字号、颜色与字重，未设的沿用文本元素的设置；同一行中字号不同的片段按基线对齐。
- [x] 插槽展示格式：时刻、时间与日期按 `HH:mm` 一类的模式格式化，数值按 `0.##` 一类的模式格式化（不出现浮点误差，如 2.10 显示为"2.1"）；未给格式时按类型的默认写法输出。
- [x] 倾斜：以错切变换模拟（参考引擎没有），角度以度计；测量与布局摘要中的文本宽度包含倾斜带来的外扩。
- [x] 插槽绑定的字段缺值时结果为空，不回退到占位内容（M16；草稿预览的占位见 12）。
- [x] M402 演示：票价显示"票价：一票制2元"，其中"票价："为深灰、其余为橙色；服务时间显示 `HH:mm` 格式的首末班；运营说明显示"（…）「…」"；线路号文字以 12° 倾斜显示（描边见 02，二者组合在 07 演示）。
- [x] golden 图片测试覆盖多片段混排与倾斜。

## Comments

**2026-10-10 实施完成。** `CI=1 npm test` 8 个文件 147 个用例全过（新增 `test/text.test.ts` 27 个），`npm run typecheck` 与加上未使用变量检查的类型检查都无错误，`npm run build` 通过。

实现要点：

- 片段样式：文字片段与插槽都可单独写 `font`、`fontSize`、`color`、`slant`，求值时合并上文本元素的设置（`src/evaluate.ts`）。横排逐片段测量，排在同一条基线上，行框取有字片段的最大上下高度；相邻同样式的片段合成一条字形指令；有描边时先画全部片段的描边再画填充（`src/layout/text.ts`）。验证：10 mm 与 20 mm 的"H"墨迹底边相差不超过 1 像素（254 DPI）；"票价：一票制2元"前 3 字只有深灰、后 3 字只有橙色。
- 字重：随字体资源，不设 `fontWeight`（写了会说明改用对应字重的字体资源）。理由：资源仓库中一个字体资源就是一个字重的字体文件，M402 草稿已经用 `res:font-hei-medium`、`res:font-hei-heavy` 区分字重；另设字重属性就要引入字体族，或用合成加粗冒充。票据 11 的缺字替代改为读取原字体文件记录的字重（M115）。
- 展示格式（`src/display-format.ts`）：时刻、时间、日期按 `HH:mm`、`yyyy年M月d日` 一类的模式输出；数值按 `0.##`、`0.00` 在十进制数字串上四舍五入，2.005 按 `0.00` 得 2.01、9.995 按 `#0.00` 得 10.00、2.10 得 2.1，不出现浮点误差（M116）。
- 倾斜：以基线为轴的错切，绘制时设在字体上，描边随之倾斜；测量把每个片段的行框按倾斜变成平行四边形，宽度包含外扩。验证：20 mm 的"H"向右倾 12° 时宽度比直立多 4.251 mm（20 × tan 12°），墨迹上带左边比下带右移约 rise × tan 12°，墨迹不出元素框；负角度向左倾（M117）。
- 插槽检查（`src/template/check.ts`）：在求值前对照编译产物检查插槽路径与展示格式，新增问题代码 `template.unknownVariable`、`template.invalidPath`、`template.typeMismatch`；没有通过检查的插槽求值为空（M118）。票据 07 把参数与派生变量加入同一检查。
- 布局摘要的文字项新增 `fragments`，列出各片段的文字与合并后的样式；两份布局摘要快照因此更新，图片 golden 未变。
- M402 演示（`test/golden/m402-text-fragments.png`）：在 M402 草稿工作区里加一个基准为"线路牌 v1"的实验模板，用 M402 数据集出图：线路号"M402"红字白描边、向右倾 12°；票价框"票价：一票制2元"；"始发站服务时间：07:30-22:30"；"（工作日运营）「定时班车」"。
- 写法见 DSL 草稿 README 的 S23；草稿中 22 个文本片段按新写法复查无问题。

限制：竖排文字的片段只能单独设颜色，竖排不能倾斜（遇到时报 `template.unsupported`）。
