# 07: 模板变量、求值与模板检查

**What to build:** 模板的参数、派生变量、检查项、绑定、条件显示与状态样式，以及出图前的模板静态检查。用 M402 的顶栏与底栏演示：开往、票价、服务时间、下一站随数据集与本站序号正确变化。

**Blocked by:** 02, 03, 04, 05, 06

**Status:** resolved

- [x] 对外参数与内部参数：类型为字段类型或颜色，带约束与默认值；对外参数未提供且没有默认值、或取值违反约束时为严重问题；调用方不能填写内部参数。
- [x] 派生变量：条件分支（按序取首个命中，必须有"否则"；条件为结构化比较，右侧可以是固定值或变量；运算符为 eq、ne、lt、le、gt、ge、empty、notEmpty）、取项（首项、末项、第 N 项，超出范围得空值）、长度、加减；派生变量必须声明结果类型。
- [x] 检查项：问题条件为真时，按其等级与提示文字记入问题清单。
- [x] 绑定：可绑定属性的值写成变量引用即为绑定；变量插槽可以引用参数、派生变量，路径可经过单引用（如 `terminal.name`）；缺值时得空值，不回退到设计时的占位内容。
- [x] 条件显示：元素的显示与否可以绑定布尔值；隐藏的元素不参与布局。
- [x] 状态样式：按某个变量的取值覆盖属性，未列出的取值沿用元素自身属性；覆盖值可以是字面值或变量。
- [x] 模板静态检查：未知变量、路径穿过非单引用、变量名重复（数据字段、参数、派生变量共用命名空间）、绑定或状态样式的取值类型与属性不符，返回以模板名与元素路径定位的问题；模板无法解析属于阻止展开的问题（M102）。
- [x] M402 顶栏与底栏：本站序号为 5 时显示"开往 万国城总站""下一站：田贝"及其地标、"票价：一票制2元"、服务时间；本站序号为 0 或本站是末站时"下一站"整行隐藏；本站序号超过站点数时返回严重问题；有线路号图片时显示图片，没有时显示倾斜描边的线路号文字。

## Comments

**2026-10-10 实施完成。** `CI=1 npm test` 9 个文件 166 个用例全过（新增 `test/variables.test.ts` 19 个），`npm run typecheck` 与加上未使用变量检查的类型检查都无错误，`npm run build` 通过。

实现要点：

- 同一个模板读取器有两种用法（`src/template/parse.ts`）：静态读取时遇到 `{"var": …}` 记下引用（绑定、插槽、状态样式）并返回占位值，状态样式的每个取值与元素合并后各读一遍；求值读取（`src/evaluate.ts`）按作用域取值，状态样式先选中取值再合并，隐藏的元素不再读取其余属性。属性的写法与取值规则只写一份。
- 变量声明（`src/template/declarations.ts`）：参数、派生变量与检查项的写法；模板静态检查（`src/template/check.ts`）：变量表（数据字段来自编译产物，参数与派生变量来自声明）、重名、成环、运算数与结果类型、绑定与状态样式的类型、状态取值；作用域（`src/template/scope.ts`）：请求参数的检查、派生变量按需计算、检查项。
- 新增问题代码：`template.duplicateVariable`、`template.variableCycle`、`template.unknownStateValue`、`template.bindingValueInvalid`、`parameter.missing`、`parameter.unknown`、`parameter.internal`、`parameter.invalid`、`check.failed`；问题位置新增 `variable`（模板名与变量名）。
- 加减按十进制计算（`src/decimal.ts`），0.1 + 0.2 得 0.3。
