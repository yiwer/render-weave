# 08: 循环容器与子模板调用

**What to build:** 循环容器为列表中的每一项调用循环模板，子模板调用按数据来源调用另一个模板。用 M402 的站点列（含本站高亮）、标识行与班次列演示。

**Blocked by:** 07

**Status:** resolved

- [x] 循环容器可遍历元素为数据定义引用的列表，以及基本类型的列表（每项包装为单值数据定义，字段为 `value`）。
- [x] 循环信息（序号从 1 开始、是否首项、是否末项、总数）只能经循环模板的对外参数显式传入；被调模板不继承调用方的作用域。
- [x] 循环项的宽度可以等分、按内容或固定。
- [x] 子模板调用支持三种数据来源：单引用字段（路径可经过多层单引用）、基准相同时的调用方当前数据、不传数据（被调模板以空数据定义为基准）。
- [x] 被调模板以调用框尺寸重新排布；调用框随内容时，取被调模板内容的自然尺寸；实际尺寸须在被调模板的适用尺寸范围内，否则返回严重问题。
- [x] 元素路径穿过子模板调用与循环容器，循环容器处带循环序号（M101）：第 12 站站名的问题定位为 `标准线路单边/站点面板/站点列[12]/名称区/站名`；布局摘要按同样的层级列出每个循环项。
- [x] 静态检查：循环模板的基准与列表元素不一致、参数填写了不存在或内部的参数、模板之间的调用关系成环；其中调用成环与循环模板基准不符属于阻止展开的问题（M102）。
- [x] M402 站点列：35 列等分宽度；本站（序号 5）显示黄色高亮底框与红字，已过站为灰字与半透明地标，未到站为正常样式；没有地标的站名占满整列；标识行显示地铁、医院图标；班次列按内容宽度排成一行，末项后没有"/"。
- [x] golden 图片测试覆盖 M402 站点列。
