# 09: 缩字组与按站数分档字号

**What to build:** 站名字号由主模板按站数分档给出、经对外参数传入站点模板；站数多到列宽放不下时，同一缩字组的全部站名统一缩小到同一字号，保证一块线路牌上站名字号一致。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 缩字组：同一次出图中，同组文本缩到相同字号；实现为两轮排版：第一轮各自测出需要的字号，第二轮全组按最小值统一重排（M91）。
- [ ] 统一缩小不低于最小可读字号 5 mm；仍放不下时返回严重问题（M83、M86）。
- [ ] 2、20、35、50 站的数据集：站名字号分别落在分档值上，且同一块牌上全部一致（以布局摘要核对）。
- [ ] 另构造列宽放不下的用例：全组统一缩小到同一字号，布局摘要标明所属缩字组。
- [ ] 画板宽度为 740 mm 与 1500 mm 时，站名字号不随宽度变化（M85）。
