# 10: 缩字组与密集站点适配

**What to build:** 站名字号由主模板以常规字号给出、经对外参数传入站点模板，站数增加时优先收窄等分列之间的留白（M135）；站数多到列宽放不下时，同一缩字组的全部站名统一缩小到同一字号，保证一块线路牌上站名字号一致。

**Blocked by:** 08

**Status:** resolved

- [x] 缩字组：同一次出图中，同组文本缩到相同字号，缩字组跨越各个循环项与子模板调用；实现为两轮排版：第一轮各自测出列宽允许的字号，第二轮全组按最小值统一重排（M91）。
- [x] 第二轮中各站名按统一后的字号再做竖排适配（02 的收紧字距与纵向压缩），因此字号变小后压缩程度减轻（compression 数值趋向 1）。
- [x] 统一缩小不低于最小可读字号 5 mm；仍放不下时返回严重问题（M83、M86）。
- [x] 2、20、35、50 站的数据集：站名字号保持常规值 10 mm，且同一块牌上全部一致（以布局摘要核对）。
- [x] 另构造列宽放不下的用例：全组统一缩小到同一字号，布局摘要标明所属缩字组。
- [x] 画板宽度为 740 mm 与 1500 mm 时，列宽足够就保持常规字号；仅列宽不足触发缩字（M85、M135）。
