# 11: 缺字替代

**What to build:** 所用字体缺少某个字时，只把缺的字按字重换成思源黑体，其余字保持原字体；替代成功记为提示，替代后仍缺字记为严重问题，横排与竖排都适用。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 以字形 ID 为 0 判断缺字；逐字替代，不整段换字体（参考引擎是整段替换，M12）。
- [ ] 后备字体按原字体的字重（字重随字体资源，读字体文件 OS/2 表记录的字重，M115）选用对应字重的思源黑体；后备字体由引擎配置指定、经 01 的准备脚本获取，不需要模板引用；字重缺档时取最接近的字重。
- [ ] 替代成功记为提示，替代后仍缺字记为严重问题，问题以元素路径定位到文本元素并列出缺失的字。
- [ ] 横排与竖排都适用；布局摘要标明哪些文本发生了替代。
- [ ] 测试使用一个缺少若干常用字的小字体夹具（由开源字体子集化生成，生成方式写在夹具说明里），覆盖替代成功与仍缺字两种情况。
- [ ] 原字体本身就是思源黑体时（M402 的情形），缺的字直接记为严重问题，不重复尝试同一字体。
