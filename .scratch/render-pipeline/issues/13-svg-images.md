# 13: SVG 图片

**What to build:** 图片元素可以显示资源仓库中的 SVG 图片，按出图分辨率栅格化，不出现模糊。M402 不需要 SVG，本票不阻塞端到端验收，可在任何时候插入。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 资源仓库接受 SVG 图片资源；图片元素显示 SVG 时，按元素框的像素尺寸栅格化，放大不模糊。
- [ ] SVG 加载时去除脚本与外部引用（含外部图片、字体与样式表）；SVG 中的文字只使用资源仓库中的字体，不使用系统字体（M99）。
- [ ] 两套参考引擎都不支持 SVG，需要单独的 SVG 栅格化方案（如 resvg）；选型写明理由，并确认它在 Windows 与 Linux 上输出一致。这是本票的风险点。
- [ ] 三种适配方式对 SVG 同样适用。
- [ ] SVG 无法解析时返回以元素路径定位的问题。
- [ ] golden 图片测试覆盖 SVG 的三种适配方式与高 DPI 输出。
