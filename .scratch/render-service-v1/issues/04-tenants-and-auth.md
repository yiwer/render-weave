# 04: 平台管理员开通租户与成员，成员登录并管理 API 密钥，租户之间互相看不到

**What to build:** 租户、成员账号、角色、会话登录、API 密钥、代建工程师令牌、行级安全与审计日志。

**Blocked by:** 03

**Status:** ready-for-agent

**Trace:** [阶段 4 PRD](../spec.md)「租户、账号与鉴权」；用户故事 1、19、20、21、39、40、42；验收 A03、A04；ADR-0018、M247。

- [ ] 平台管理员能创建租户和成员账号，能重置密码。不做自助注册、第三方登录与邮件找回。
- [ ] 成员用邮箱加密码登录，密码用慢哈希保存。
- [ ] 客户管理员能管理本租户的成员与角色。
- [ ] 客户管理员能创建和吊销 API 密钥：服务端只存哈希，创建时显示一次，吊销后立即失效。
- [ ] 代建工程师令牌只能访问被指定的租户。
- [ ] 按 M247 的权限矩阵逐项覆盖五种身份：客户管理员、客户操作员、API 密钥、代建工程师、平台管理员。
- [ ] 隔离：
  - 鉴权后只拿到本租户的存储句柄，客户端不能提交对象键或路径；
  - 每张租户表开启行级安全，每个事务都设置当前租户；
  - 测试里故意漏写租户条件的查询，也查不到别的租户的行。
- [ ] 维护一张跨租户端点清单：对其中每个端点，用另一租户的会话和密钥访问都被拒绝，也不泄露对象是否存在。后续票据新增端点时加进这张清单。
- [ ] 写操作和跨租户操作追加写入审计日志，不记业务数据内容和密钥。客户管理员能查本租户的审计。
- [ ] 仓库与日志中扫描 key 与密钥，命中 0。
- [ ] 决定记 M 编号。

**测试接缝：** 开放 API。内存后端覆盖权限矩阵，Docker 后端覆盖行级安全。
