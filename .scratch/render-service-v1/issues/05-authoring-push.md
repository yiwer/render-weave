# 05: 代建工程师用一条命令把本地工作区与资源推送到客户的租户

**What to build:** 命令行推送命令，以及对应的服务端导入接口：先算差异，有冲突就整体拒绝，没有冲突就在一个事务里提交。

**Blocked by:** 04

**Status:** ready-for-agent

**Trace:** [阶段 4 PRD](../spec.md)「代建导入」；用户故事 33、34、35、36；验收 A05；ADR-0017、M243。

- [ ] 推送两类内容：
  - 本地工作区里的静态数据定义、编译产物、模板与样例数据集；
  - 资源版本仓库里的资源及其内容版本。
- [ ] 推送前列出差异：新增、更新、冲突。可以只看差异、不提交。
- [ ] 判定冲突：
  - 静态数据定义同名同版本、内容却不同（ADR-0008）；
  - 资源按 ID 和内容版本对比，种类不同。
  
  有冲突就整体拒绝，服务端保持原样。
- [ ] 模板每推送一次记一个新修订，按名称指向当前修订，也可以把当前修订指回旧修订。
- [ ] 文档按原始字节入库；推送后从服务端读回的字节与本地一致。
- [ ] 推送凭代建工程师令牌鉴权。令牌只经环境变量传入，不出现在参数、日志和输出里；每次推送记审计。
- [ ] 推送未初始化的目录或旧版资源目录时，问题说明与 M239 一致。
- [ ] 决定记 M 编号；[代建指南](../../../docs/agent-guide.md)补上推送这一步。

**测试接缝：** 命令行推送命令，推送到内存后端的服务；结果经开放 API 读回核对。
