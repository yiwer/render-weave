# 07: 经开放 API 异步批量正式交付，逐项提交出图记录，可查进度、可取消

**What to build:** 批量交付接口、批次快照、逐项任务、出图记录写入对象存储、批次汇总、取消与幂等键。

**Blocked by:** 02、06

**Status:** ready-for-agent

**Trace:** [阶段 4 PRD](../spec.md)「开放 API」「出图记录」；用户故事 12、14、15、23、24；验收 A06、A08；ADR-0017、ADR-0019、M246。

- [ ] 提交批量交付时，接口进程做票据 01 的"固定"，存好批次快照，按项入队，立即返回批次标识。单张正式图也按只有一项的批次交付。
- [ ] 一个批次只由接受它的那个构建的 worker 处理。滚动发布时，旧 worker 做完已接受的批次再退出。
- [ ] 每项正式交付成功时，先写对象，再在一个事务里提交记录行。事务提交之前，这一项对任何读者都不存在。
- [ ] 同一租户内相同字节只存一份，跨批次也是。
- [ ] 能查批次状态、逐项进度与结果。失败项带的问题清单与单次渲染一致（票据 02）。
- [ ] 全部项结束后写批次汇总，语义同本地的 `batch.json`（M153）。
- [ ] 取消：还没开始的项标为未执行，正在渲染的一项由调度进程结束。
- [ ] 幂等：
  - 提交时带幂等键，重试返回同一批次，不重复交付；
  - worker 重领同一项时，记录行只提交一次。
- [ ] API 密钥可以提交批次、查询结果。
- [ ] 决定记 M 编号。

**测试接缝：** 开放 API。结果经查询接口和票据 08 的导出核对。
