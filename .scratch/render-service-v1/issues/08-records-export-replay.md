# 08: 查询与导出出图记录，导出包能离线重放；服务端重放按构建标识找确切构建

**What to build:** 记录查询、单张与整批图片下载、按项或按批次导出，以及按构建路由的重放。

**Blocked by:** 07

**Status:** ready-for-agent

**Trace:** [阶段 4 PRD](../spec.md)「出图记录」；用户故事 13、16、17、47；验收 A08；ADR-0019。

- [ ] 能按时间、模板、批次查询出图记录。
- [ ] 能下载单张图片和整批图片的压缩包。
- [ ] 能按项或按批次导出，导出的目录结构、文件名与内容和本地 `deliver` 的成果一致。
- [ ] 测试断言：导出包能用 `renderweave record-read` 与 `renderweave replay` 离线通过。
- [ ] 重放：
  - 交给记录所属构建的 worker，不计额度；
  - 那个构建的镜像已不在时拒绝，问题说明写明缺哪个构建；
  - Docker 后端测试用两个打了不同构建标签的 worker 验证路由。
- [ ] 发布流程保留旧构建的 worker 镜像。规则写进运维文档：只要还有记录引用某个构建，就不删它的镜像。
- [ ] 读取时逐文件核对 SHA-256 与字节数，不一致时报完整性问题。
- [ ] 决定记 M 编号。

**测试接缝：** 开放 API，以及命令行的 `record-read`、`replay`。
