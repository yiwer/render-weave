# 09: 按月额度计量正式交付张数与代建 token，额度不够整批拒绝

**What to build:** 用量事件、当期计数、套餐设置、批次预占与逐项结算、对账、用量查询，以及推送时附带的 token 用量。

**Blocked by:** 07

**Status:** ready-for-agent

**Trace:** [阶段 4 PRD](../spec.md)「计量与额度」；用户故事 18、24、30、37、39、41；验收 A09；ADR-0020、M242。

- [ ] 平台管理员设置租户套餐：每月出图张数、单张最大像素、并发数。
- [ ] 提交批次时预占额度：在一个事务里锁住当期计数行，检查"已用 + 预占 + 本批项数 ≤ 限额"。不够就整批拒绝，问题码 `quota.exceeded`，HTTP 429，说明里写剩余额度。
- [ ] 结算：
  - 每项成功时，在提交记录行的同一个事务里写用量事件：已用加 1，预占减 1；
  - 失败和未执行的项退回预占；
  - 批次结束时退回剩下的预占。
- [ ] 不重复计费：同一幂等键重试、worker 重领同一项，都只计一次。
- [ ] 对账任务回收崩溃后遗留的预占。Docker 后端测试在批次进行中结束 worker 和接口进程来验证。
- [ ] 草稿预览和重放不计额度。
- [ ] 计费周期是按 UTC+8 切分的自然月，额度不结转。
- [ ] token：推送命令可以附带轮次目录，读取各轮 `round.json` 里的输入、输出、缓存读、缓存写 token，记为该租户的用量事件，只记不拦。
- [ ] 客户管理员和平台管理员能查已用、预占、剩余与明细。
- [ ] 决定记 M 编号。

**测试接缝：** 开放 API 与推送命令。
