# 10: 经开放 API 管理数据集与图片、字体资源，替换资源前先看影响

**What to build:** 数据集的读写与校验接口，资源的上传、列出、替换检查与应用替换接口。

**Blocked by:** 05

**Status:** ready-for-agent

**Trace:** [阶段 4 PRD](../spec.md)「开放 API」；用户故事 6、7、8、22、27；验收 A06；ADR-0018、M152、M241。

- [ ] 数据集：
  - 能新建、读取、修改、复制、列出；
  - 按原始字节存；
  - 保存时按静态数据定义的编译产物校验，问题清单定位到字段，结果与引擎一致。
- [ ] 提供只校验、不保存的接口，供表单实时提示。
- [ ] 资源：
  - 操作员能上传新的图片和字体，得到资源 ID 和 v1；
  - 字体不做授权确认（M241）；
  - 资源种类创建后不能改。
- [ ] 替换资源分两步：
  1. 只读检查，返回受影响的模板、数据集与字体配置；
  2. 管理员凭检查报告应用，按预期版本提交，过期的报告被拒绝（M152）。
- [ ] 每个新端点都加进票据 04 的跨租户端点清单。
- [ ] 决定记 M 编号。

**测试接缝：** 开放 API。
