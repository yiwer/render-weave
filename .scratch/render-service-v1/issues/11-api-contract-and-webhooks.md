# 11: 开放 API 有可快照的 OpenAPI 合同，批次结束时发带签名的 webhook

**What to build:** OpenAPI 描述与快照测试、统一的错误与状态码映射、webhook 的注册、签名、重试与投递记录，以及 API 兼容策略文档。

**Blocked by:** 08、09、10

**Status:** ready-for-agent

**Trace:** [阶段 4 PRD](../spec.md)「开放 API」；用户故事 25、26、28、29、31；验收 A06、A10；M246。

- [ ] 全部端点都有 OpenAPI 描述，并做快照测试。快照有变化时必须显式更新，并在文档里写明是否兼容。
- [ ] 错误一律带问题清单（问题码、等级、位置、说明）。HTTP 状态按类别映射，逐个端点核对：
  - 400 请求不合法；401 未鉴权；403 无权限；
  - 404 不存在；409 冲突；429 额度不足或限频。
- [ ] webhook：
  - 客户管理员和 API 密钥能注册、停用 webhook；
  - 批次结束时（完成、部分失败、取消）投递一次，正文带批次摘要；
  - 用租户的签名密钥对正文做 HMAC 签名，附带时间戳；
  - 投递失败按指数退避重试有限次，投递记录可查。
- [ ] 文档：写开放 API 的使用说明，以及 1.x 兼容策略：只做加法，比照 ADR-0016。
- [ ] 决定记 M 编号。

**测试接缝：** 开放 API。webhook 用测试里自建的接收端，验证签名与重试。
