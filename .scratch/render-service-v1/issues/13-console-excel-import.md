# 13: 客户从 Excel 导入一批数据，逐行看到问题，确认后再交付

**What to build:** 服务端解析 Excel 的接口和控制台的导入界面：一行一个渲染项，支持简单列表和一层引用列表两种写法。

**Blocked by:** 12

**Status:** ready-for-agent

**Trace:** [阶段 4 PRD](../spec.md)「出图控制台」；用户故事 9、10；验收 A11；M248。

- [ ] Excel 在服务端解析，解析库只用 MIT 或 Apache 许可证的。
- [ ] 支持的写法：
  - 一行一个渲染项；
  - 列对应顶层字段，表头写显示名称或字段名称都可以；
  - 简单类型的列表用分隔符写在一格里；
  - 一层数据定义引用的列表另起一张表，用关联列对应主表的行。
- [ ] 导入结果先作为预览返回：数据集、批量请求，以及逐行逐列的问题清单。有问题的行不进入批次，客户确认后才提交。
- [ ] 控制台能下载模板：按数据定义生成一份带表头的空白 Excel。
- [ ] 准备两份 Excel 样例，测试中都能导入并交付成功：
  - 价签：字段是扁平的；
  - 线路牌：站点是引用列表。
- [ ] 单个文件的大小和行数有上限，超出就拒绝。
- [ ] 决定记 M 编号。

**测试接缝：** 开放 API 的导入接口；控制台的导入走一条浏览器端到端测试。
