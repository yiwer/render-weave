# 模板 Agent 的受控上下文与恢复交接

依据：2026-10-22 用户要求在 template-design 分支落实 P0；[架构方案](../../docs/template-design-harness-review.md)第 6 节。实现基线 8f845f8。

范围：短模板任务核心、从权威 DSL 参考生成按需章节、逐请求上下文观测、显式阈值停止与已有轮次机制接续、禁用个人编码 skills。保留九个 MCP 工具与合同 0.8.0，不改变 DSL。阶段 4 及票据 34/35 的其他验收范围不变。

## 验收
- A01：模板设计/修改不再要求全读。固定 StaticSchema/数据集边界与项目说明优先级保留；提取任务资料不进入模板默认资料。
- A02：DSL 章节由同一权威文件生成，目录含标题/路径/哈希；可逐章取回，包括完整示例；不用手工维护第二份语法。
- A03：按请求 ID 去重有效输入（含缓存）、记录峰值、压缩事件、工具结果文字与图片体积；未知 usage 不伪造为零，合成测试不冒充模型测量。
- A04：可选 --context-limit 正整数表示观测到单请求有效输入达到阈值后停止本轮；缺省仅观测，不宣称防止请求超限。停止后保存候选及交接材料，不自动重试。
- A05：接续保留项目约束、Agent 自述的进度与待办；候选/输入变更或交接包被改时不能沿用旧核查结论；hostRecovery 只能查看/续做。
- A06：业务执行器显式禁用 skills；不动开发者个人安装。真实 Claude Code 请求捕获确认工具面和技能隔离。
- A07：通过公开 Agent/CLI 接缝测试、类型检查及两轴 review；用同输入的本机脚本端点报告前后体积，真实模型对照另列结果或明确阻塞。

## 实施选择
使用生成的文件章节而非新增 MCP 端点。完整资料在磁盘，任务入口只给索引；短进度存 state.json，宿主交接清单与指纹放在 Agent 工作目录之外。阈值是显式运维参数，不是行业通用注意力退化线。
