# 01: 不开工作副本也能读模板内容，只看不改不再留审计

**What to build:** 开放 API 加读当前修订内容的端点；设计页打开时只读内容，第一次改动才开工作副本。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 1、4；验收 A02、A03；方案第 12 节；M356、[P1 验收](../../../docs/p1-acceptance.md)「后续」第 5 项。

- [ ] 新端点（如 `GET /v1/templates/{name}/content`）回答当前修订的原文、内容哈希与修订号，权限是 `tenant.read`；代建端点同形。不存在答 404，进跨租户端点清单。
- [ ] 打开设计页：有工作副本读工作副本，没有就读内容；这一步不写任何东西。
- [ ] 第一次改动才开工作副本，然后暂存。开的时候当前修订已经变了，回答 409 时提示读回最新内容，不悄悄盖掉。
- [ ] 只看不改离开页面：审计里没有 `templateWorkingCopy` 的 `create`、`delete`。
- [ ] 基准已变而这边没有改动的旧工作副本，打开时换成当前修订（M356），这条行为保留。
- [ ] `docs/api.md` 记变更，OpenAPI 快照更新，小版本加一。

**测试接缝：** 开放 API 用例；浏览器用例核对只看不改的审计。
