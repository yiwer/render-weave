# 02: 预览能答出一个元素实例的变量取值、命中分支与各实例的状态

**What to build:** 渲染入口与预览端点按元素路径带回求值结果，页面不用自己再算一遍。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 10、11、22；验收 A02、A04；方案第 12 节。

- [ ] 引擎 `render` 加可选项（照 `elementLocations`）：给元素路径，回答这个实例所在作用域的全部变量（名称、种类、类型、当前值）、每个 `branch` 派生变量命中第几支、每个检查项是否成立。作用域在 `src/evaluate.ts` 展开时就有。
- [ ] 同一回答带这个元素定义的全部实例：路径、状态样式 `states.by` 的取值。
- [ ] 对外参数带来源：调用方的元素路径与 `args` 的运算数（变量、固定值或循环信息），页面据此画来源链。
- [ ] `POST /v1/previews?workingCopies=true&inspect=<元素路径>`：回答多一个字段，渲染请求的 DSL 不变（同 M352 的写法）。路径不存在时这个字段为空，不报错。
- [ ] 回答有上限：列表只给项数，引用只给一层字段，超长文本截断。
- [ ] 不要就没有；要了不改变图片、问题清单与布局摘要。代建端点同形。

**测试接缝：** 引擎公开入口，M402 的 `站点列[12]` 与 `站点列[5]`（`stopState` 的命中不同）；开放 API 用例。
