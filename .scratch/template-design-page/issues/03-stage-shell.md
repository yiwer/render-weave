# 03: 模板设计页换成舞台加浮动面板的外壳，现有能力一项不少

**What to build:** 版式换成方案第 2 节：文档条、织纹舞台、左面板、右检查器、操作条、样例带的位置；现有内容先原样搬进去。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 1、25；验收 A01、A11；方案第 2 节；原型截图 `01-选中站名.png`。

- [ ] 结构页搬到左面板"结构"，参数与检查项搬到左面板"变量"，属性与适配规则搬到右边，右边不再分页。
- [ ] 面板浮在舞台上：适应按两个面板之间的空隙算，放大后图从面板底下穿过，`Ctrl+\` 收起面板。
- [ ] 平移：`H`、按住空格、拖舞台空白处；缩放：滚轮以光标为锚；`Ctrl+0` 适应、`Ctrl+1` 物理 1:1（96 DPI）。
- [ ] 草稿与正式的切换按钮去掉，换成常驻的一句结论（可以正式出图、N 个严重问题正式出图不会出、N 个提示），口径同现在的 `ProblemsOfPreview`。
- [ ] 文档条：位置、基准与尺寸范围、撤销重做、保存状态、未发布数、保存、发布修订。保存语义不变（M383）。
- [ ] 窄窗口面板默认收起，页面不横向滚动。
- [ ] 设计页分包，控制台主包不再因它变大。
- [ ] 术语表补"舞台"：放画板的工作区；"画板"的说法不变。

**测试接缝：** `service/test/console-suite.ts` 的模板设计用例照过，选择器可以改，断言不能删；和原型截图对照。
