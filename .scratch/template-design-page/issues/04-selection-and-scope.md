# 04: 点图上的元素，范围条写明定义在哪、图上几处、改一处全改

**What to build:** 选中分清定义与实例，影响范围写在舞台上和检查器顶部。

**Blocked by:** 03

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 2、3、5；验收 A05；方案第 3 节。

- [ ] 点图选中最深的、会显示的元素；Alt + 点沿层叠穿透；右键列出这个位置的全部元素，从最深到画板，加上现有的复制元素路径、在结构中定位、打开绑定的变量。
- [ ] `Esc`、`Enter` 上一层、下一层。什么都没选时，检查器显示画板。
- [ ] 主实例实线框，其余实例虚线框；新图到了框和图一起换，不错位。
- [ ] 范围条：元素路径每段可点，跨模板的段换颜色；写明定义所在模板、图上几处、这是第几处。
- [ ] 检查器顶部：图上多于一处，或定义在子模板里时，写明改的是哪个模板、几处一起变。
- [ ] 切子模板不离开这张图，地址照旧带 `?in=`（M356）。
- [ ] 当前样例下不显示的元素，检查器写明原因（`visible` 绑定的变量与当前值）。

**测试接缝：** 浏览器用例，M402 的 `站点列[12]/名称区/站名`：35 处、定义在站点。
