# 06: 打开适配层，一眼看到哪些文字被压缩、哪些放不下

**What to build:** 操作条开关四个叠加层，选中容器时显示排布参考线，都不重新出图。

**Blocked by:** 03

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 8、9；验收 A02、A08；方案第 4 节。

- [x] 控制台的 `LayoutNode` 类型声明布局摘要的 `text`、`image` 等；OpenAPI 描述补上这些键，回答本身不变。
- [x] 问题层（默认开）：编号框，点了选中元素并打开问题页。
- [x] 结构层：全部元素框。
- [x] 适配层：按 `compression` 着色，`overflow` 标红，图例写被压缩的处数与最低压缩比、放不下的处数。
- [x] 数据层：有插槽或绑定内容的是数据驱动，其余是固定内容，图例说明。
- [x] 选中容器时显示间距、内边距、网格轨道及其尺寸。这一票只画不拖，拖动在票据 13。
