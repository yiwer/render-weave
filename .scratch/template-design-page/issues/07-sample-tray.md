# 07: 样例带上换数据、参数与尺寸，试值不写进模板

**What to build:** 底部的样例带：样例卡片、试值旋钮，以及问题、改动、DSL 三页；同时定下预览节奏。

**Blocked by:** 03

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 6、7、14、15、16；验收 A06；方案第 4、8 节。

- [ ] 样例是一个渲染项：数据集、对外参数、画板尺寸。卡片有缩略图、名称、问题数；基准相同的数据集列出来，名称带"压测"的单独一组（M356），保留空白数据。
- [ ] 旋钮按对外参数的类型与约束生成：数值有范围时是滑块，枚举是分段，颜色是色块；画板宽高按 `sizeRange` 限定。试值存浏览器，读写都容错。
- [ ] 只重出当前样例，其他卡片标"改动后没重新出"，点到才出。
- [ ] 预览节奏：选项、开关立刻写回并出图；打字停 500 ms；滑块松手才出。
- [ ] 问题页：点一条定位到元素、字段或检查项，三种位置都接上。
- [ ] 改动页：结构化差异沿用 `check` 的回答；能在图上拖分割线对比，当前修订的图用不带 `workingCopies` 的预览出。
- [ ] DSL 页：选中元素的片段或整份，能复制、下载，含还没写回的改动。
- [ ] 术语表补"样例"：用来看的渲染项，不写进模板、不出图。

**测试接缝：** 浏览器用例：切样例、改试值之后工作副本的内容哈希不变，审计没有新增。
