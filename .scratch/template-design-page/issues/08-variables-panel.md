# 08: 变量面板看得到当前值，悬停标出谁在用

**What to build:** 左面板的变量页：字段、参数、派生变量、检查项，取值来自票据 02。

**Blocked by:** 02、03

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 10；验收 A06；方案第 6 节。

- [ ] 作用域是选中元素所在的模板，头部写明不继承。
- [ ] 四组：字段（来自基准的编译产物）、对外与内部参数、派生变量、检查项。每行有类型标记、显示名称、当前样例的取值；成立的检查项标红。
- [ ] 悬停一行，图上标出用它的元素，连带派生变量（`variableClosure`）。
- [ ] 选中变量时右边显示它：参数沿用 `listItemPanel` 编辑；字段只读，链到数据定义并展开这个字段；派生变量这一票只读（票据 16 才改）；检查项沿用现有编辑。
- [ ] 改对外参数的缺省值写进模板，试值在样例带，两处都写明区别。
- [ ] 右边列出"谁在用"：元素与派生变量，可点。

**测试接缝：** 浏览器用例，M402 的 `stopNameSize` 改缺省值，图随之变化；取值只从接口来，不在页面里求值。
