# 08: 变量面板看得到当前值，悬停标出谁在用

**What to build:** 左面板的变量页：字段、参数、派生变量、检查项，取值来自票据 02。

**Blocked by:** 02、03

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 10；验收 A06；方案第 6 节。

- [x] 作用域是选中元素所在的模板，头部写明不继承。
- [x] 四组：字段（来自基准的编译产物）、对外与内部参数、派生变量、检查项。每行有类型标记、显示名称、当前样例的取值；成立的检查项标红。
- [x] 悬停一行，图上标出用它的元素，连带派生变量（`variableClosure`）。
- [x] 选中变量时右边显示它：参数沿用 `listItemPanel` 编辑；字段只读，链到数据定义并展开这个字段；派生变量这一票只读（票据 16 才改）；检查项沿用现有编辑。
- [x] 改对外参数的缺省值写进模板，试值在样例带，两处都写明区别。
- [x] 右边列出"谁在用"：元素与派生变量，可点。

**测试接缝：** 浏览器用例，M402 的 `stopNameSize` 改缺省值，图随之变化；取值只从接口来，不在页面里求值。

## Answer

完成于 2026-11-05，分支 `worktree-template-design-page`。

**成果**

- `service/console/src/design/variables.tsx`：变量面板、选中变量时右边的 `VariableInspector`、`useInspection`、`usesOfVariable`。取值都来自 `POST /v1/previews/inspection`，页面没有求值。
- 求值改成单独的端点（见票据 02 的偏差）：每次点选都要问，不能占预览的频率。
- 问题定位接全了：元素选中它；字段、参数、检查项、派生变量打开变量页并选中那一行。

**验证**

- 新增浏览器用例「模板设计（票据 08）」：四组当前值、悬停标出谁在用、字段只读链到数据定义、改内部参数缺省值图跟着变、谁在用可点、试值让检查项成立、问题定位到检查项、进子模板后派生变量标出命中。
- P1 用例的参数编辑从左面板搬到检查器，断言没删。
- 用例环境：P1 用例 32 秒发 62 次预览（实测），撞每分钟 60 次的上限，浏览器用例的内存后端放宽到 600 次；Docker 后端仍是真实上限，等图放宽到 90 秒。限频本身由 `service/test/preview-suite.ts` 测。

**偏差**

- 派生变量这一票只读，编辑器在票据 16；检查项沿用现有编辑，没有退步。
