# 09: 每个属性一个值格，能绑定、断开、提取为参数，能追到值从哪来

**What to build:** 检查器的字段外观换成值格，生成规则仍是 `properties.ts`。

**Blocked by:** 08

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 11、12、13；验收 A07；方案第 7 节。

- [ ] 形态：字面值、没写（淡色显示缺省值）、绑定（显示名称与当前值）、被状态覆盖（标签前加圆点）、不能绑定（没有按钮，提示原因）。
- [ ] 能不能绑定以 Schema 的变体为准，Schema 加属性时面板自动多一项这条测试继续通过。
- [ ] 绑定弹层只列类型相符的变量，分字段、参数、派生三组，带当前值。
- [ ] 断开绑定：当前值变成字面值。
- [ ] 提取为参数：把当前值存成内部参数的缺省值并绑定它，起名可改，一步撤销。
- [ ] 来源链：绑定的是对外参数时，写明来自哪个模板的什么参数，一键跳过去；经循环信息传入的写明是循环序号。
- [ ] 数值可以拖标签调整，松手才写回。

**测试接缝：** `service/test/template-properties.test.ts` 同一入口加绑定、断开、提取的写回，结果由 `checkDslDocument` 判断；浏览器用例走 M402 站名字号的来源链。
