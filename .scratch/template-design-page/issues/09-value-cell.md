# 09: 每个属性一个值格，能绑定、断开、提取为参数，能追到值从哪来

**What to build:** 检查器的字段外观换成值格，生成规则仍是 `properties.ts`。

**Blocked by:** 08

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 11、12、13；验收 A07；方案第 7 节。

- [x] 形态：字面值、没写（淡色显示缺省值）、绑定（显示名称与当前值）、被状态覆盖（标签前加圆点）、不能绑定（没有按钮，提示原因）。
- [x] 能不能绑定以 Schema 的变体为准，Schema 加属性时面板自动多一项这条测试继续通过。
- [x] 绑定弹层只列类型相符的变量，分字段、参数、派生三组，带当前值。
- [x] 断开绑定：当前值变成字面值。
- [x] 提取为参数：把当前值存成内部参数的缺省值并绑定它，起名可改，一步撤销。
- [x] 来源链：绑定的是对外参数时，写明来自哪个模板的什么参数，一键跳过去；经循环信息传入的写明是循环序号。
- [x] 数值可以拖标签调整，松手才写回。

**测试接缝：** `service/test/template-properties.test.ts` 同一入口加绑定、断开、提取的写回，结果由 `checkDslDocument` 判断；浏览器用例走 M402 站名字号的来源链。

## Answer

完成于 2026-11-05，分支 `worktree-template-design-page`。

**成果**

- `service/console/src/template/properties.ts`：变体编辑器带 `bindable`（类型、字面值编辑器、初值），能不能绑定只看 Schema 有没有 `{ var }` 变体、字面值类型说不说得清；字段带 `fallback`（引擎的缺省值，对过 `src/template/parse.ts`）与 `noBinding`（不能绑定的原因）。
- `service/console/src/template/binding.ts`：作用域变量、类型筛选（和静态检查一样完全相符，M71）、断开写什么、提取为参数、起名、来源链的文字。纯函数。
- `components/property-fields.tsx` 的 `ValueCell`、`components/binding-popover.tsx`：绑定态灰底条、字面值加绑定按钮、没写时淡色显示缺省值；数值拖标签松手才写回，一次拖动只出一张图、撤销一步。
- 被状态覆盖的属性标签前有圆点，写明哪些取值；编辑写进 `states.cases` 在票据 17。

**验证**

- `service/test/template-properties.test.ts` 新增 18 个用例：Schema 决定能不能绑定、类型、断开、提取、起名、来源链，写回结果由 `checkDslDocument` 判断。
- 浏览器用例「模板设计（票据 09）」走 M402 站名：来源链写"来自 标准线路单边「站名字号」（内部参数）"并能跳过去，弹层只列颜色变量，换绑定、断开、提取、一步撤销，拖标签松手前没有写回，经循环传入的写明循环序号。
- 这个用例查出一个真问题：弹层打开时焦点在触发按钮上，Esc 会变成舞台的"选上一层"。已改成捕获阶段接住。
- 观感：真页面截图和原型第 7 节的值格对过，灰底条、来源链、弹层一致；检查器的分组与"其他 N 项"还是旧的，票据 10 换。

**偏差**

- 弹层底部没有"新建派生变量"：派生变量的编辑器在票据 16，到时再加入口。
- 传入参数（`args`）的值是 `{ value }`、`{ loop }`、`{ var }`，字面值没有单一类型，还是老的变体下拉，票据 15 的调用表单一起换。
- 引用字段的第二层类型取编译产物的 `kind`，颜色字段在编译产物里算文本，所以引用里的颜色字段不会列进颜色弹层；顶层字段用引擎回答的类型，不受影响。
