# 10: 检查器按元素类型分组，文字的内容与适配能直接看懂

**What to build:** 分组顺序按元素类型定，加内容与适配两个专属编辑器。

**Blocked by:** 09

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 8；验收 A07；方案第 7 节。

- [ ] 分组顺序照方案第 7 节的表；没写的可选项留在组里显示缺省值，取代"其他 N 项"（M356）。
- [ ] 内容：文字与插槽排成一行，打字是文字，`/` 插入字段，点插槽改展示格式，格式按字段类型校验；片段样式点开改。写明一个文字元素只排一行或一列（M339）。
- [ ] 双击图上的文字就地打开内容编辑。
- [ ] 适配：只给 DSL 合法的步骤组合，横排竖排分开；下限、放不下时的等级、缩字组及成员数；最后一行是这一处实例的结果（压缩比、字号、字距）。
- [ ] 字体按字体族分组列字重，选的仍是资源引用（M115）。
- [ ] 互斥与失效写明原因，不等报错。

**测试接缝：** 单元测试走 `properties.ts` 的入口；浏览器用例改竖排站名的适配步骤。
