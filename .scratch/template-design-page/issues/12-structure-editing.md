# 12: 在结构树上复制、删除、排序元素，包进容器，改名字

**What to build:** 结构树能改结构，写回是一个纯函数模块。

**Blocked by:** 11

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 17；验收 A09；方案第 5 节。

- [x] 操作：复制、删除、拖动排序、上移下移、包进容器、拆开容器、重命名。每个操作一步撤销。
- [x] 名称在模板内唯一（`template.duplicateElementName`）：复制时自动起名，重命名重复时当场提示。
- [x] 换父容器时 `place` 只留新布局认识的键，网格的行列补上（沿用 `writeProperty` 的做法）。
- [x] 排序时写明顺序同时决定叠放。
- [x] 删除或改名被多处调用的子模板里的元素，先列出调用方与图上处数。
- [x] 键盘：`Del`、`Ctrl+D`、`F2`、`Alt+↑`、`Alt+↓`，打字时不触发。

**测试接缝：** 纯函数单元测试，每个操作配三种布局，结果由 `checkDslDocument` 判断，撤销还原字节；浏览器用例走一遍。

## Answer

完成于 2026-11-08，分支 `worktree-template-design-page`。

**成果**

- `service/console/src/template/structure.ts`：复制（连子元素一起起新名，自由布局里错开 2 mm）、删除、上移下移、拖到别的容器（`moveElementTo` 与 `dropTarget`）、包进容器（新容器占原来的位置、纵向堆叠，图不变）、拆开容器、重命名（`nameProblem`：非空、不带 /、[、]、模板内唯一）、列出调用方（`callersOf`）。纯函数，原文档不变。
- 结构页：拖动排序（上半、下半放前后，容器的中间放进去，只在同一个模板里）、就地改名、顶上写明"顺序就是 DSL 的顺序"。右键菜单加复制、上移、下移、包进容器、拆开容器、重命名、删除；快捷键 `Ctrl+D`、`Del`、`F2`、`Alt+↑`、`Alt+↓`，打字时不触发。
- 每个操作写回一次，用新的合并键，所以一步撤销。被多处调用、或图上多于一处的子模板里删除与改名，先列出调用方与图上处数，确认才动。
- 检查器里的名称也按模板内唯一当场拦下。
- `fitChildren` 往网格里补行列时不再超出网格的行数：排满了放最后一行，重叠由布局的问题清单说，不然静态检查不过。

**验证**

- `service/test/template-structure.test.ts` 24 项：每个操作配自由、堆叠、网格三种父布局，写回结果由 `checkDslDocument` 判断，名称唯一，原文档不变。`template-session.test.ts` 加一项：复制再包进容器，撤销两次按字节还原。
- 浏览器用例「模板设计（票据 12）」：复制、上移、改名（重名拦下）、包进再拆开、拖进容器、删除，七步撤销回到开始的内容；检查器改成重名被拦下；删除站点模板里的站名先问"图上 35 处"，不确定就不动。全部「模板设计」浏览器用例 7 个通过。
- 观感：右键菜单与结构页顶上的说明在浏览器面板里看过。

**用例查出的问题**

- 拖进收起的容器之后看不到元素：树只按图上的实例展开，新预览回来之前选中项没有实例。改成按选中的路径也展开，并且切回结构页时一开始就展开到选中的那一行，不再先画一棵收起的树再跳开。

**偏差**

- 拆开容器时子元素的 place 按外层布局只留认识的键，从堆叠拆到自由布局的元素会回到左上角，位置要重新调；第二期的手柄（票据 13）之后可以按布局摘要保留位置。
- 图上拖动元素换父容器不在这张票（手柄在票据 13），这里只在结构树上拖。
