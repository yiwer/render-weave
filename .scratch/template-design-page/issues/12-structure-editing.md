# 12: 在结构树上复制、删除、排序元素，包进容器，改名字

**What to build:** 结构树能改结构，写回是一个纯函数模块。

**Blocked by:** 11

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 17；验收 A09；方案第 5 节。

- [ ] 操作：复制、删除、拖动排序、上移下移、包进容器、拆开容器、重命名。每个操作一步撤销。
- [ ] 名称在模板内唯一（`template.duplicateElementName`）：复制时自动起名，重命名重复时当场提示。
- [ ] 换父容器时 `place` 只留新布局认识的键，网格的行列补上（沿用 `writeProperty` 的做法）。
- [ ] 排序时写明顺序同时决定叠放。
- [ ] 删除或改名被多处调用的子模板里的元素，先列出调用方与图上处数。
- [ ] 键盘：`Del`、`Ctrl+D`、`F2`、`Alt+↑`、`Alt+↓`，打字时不触发。

**测试接缝：** 纯函数单元测试，每个操作配三种布局，结果由 `checkDslDocument` 判断，撤销还原字节；浏览器用例走一遍。
