# 13: 在图上用手柄改元素，能拖什么由父容器的布局决定

**What to build:** 舞台上的手柄（M392）：拖动只画幽灵框与读数，松手写 DSL 已有的数。

**Blocked by:** 11

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 18；验收 A09；方案第 4 节「手柄」；M392。

- [ ] 自由布局：移动与八个手柄，写 `place` 的锚点值（原来是距右、距下的保持）、`width`、`height`。
- [ ] 堆叠：沿主轴拖动改 `children` 顺序，读数写明同时决定叠放；固定尺寸才有主轴手柄。
- [ ] 网格：吸到格子写 `row`、`column`，边缘改 `rowSpan`、`columnSpan`，不超出轨道数。
- [ ] 选中堆叠容器：间距条写 `layout.gap`。选中网格容器：固定轨道的线写 `rows[i].fixed`、`columns[i].fixed`。
- [ ] 没有手柄：循环项、画板；值绑定了变量；尺寸是随内容或撑满；按比例或随内容的轨道。读数或检查器说明怎么改。
- [ ] 状态样式选中某个取值时，手柄写进这个取值的覆盖。
- [ ] 元素在子模板里时，读数写明图上几处一起变。
- [ ] 拖动中不写回、不出图；松手记一步撤销、暂存、出图。
- [ ] 吸附 0.5 mm，按住 Shift 到 0.1 mm；方向键步长相同。
- [ ] 旋转的元素只给移动。

**测试接缝：** 写回是纯函数（文档、元素、手势与增量，得到新文档）：每种父布局、每种手柄配字面值与绑定两种情况，结果由 `checkDslDocument` 判断；浏览器用例拖胸牌的相框与 M402 顶栏的间距。
