# 13: 在图上用手柄改元素，能拖什么由父容器的布局决定

**What to build:** 舞台上的手柄（M392）：拖动只画幽灵框与读数，松手写 DSL 已有的数。

**Blocked by:** 11

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 18；验收 A09；方案第 4 节「手柄」；M392。

- [x] 自由布局：移动与八个手柄，写 `place` 的锚点值（原来是距右、距下的保持）、`width`、`height`。
- [x] 堆叠：沿主轴拖动改 `children` 顺序，读数写明同时决定叠放；固定尺寸才有主轴手柄。
- [x] 网格：吸到格子写 `row`、`column`，边缘改 `rowSpan`、`columnSpan`，不超出轨道数。
- [x] 选中堆叠容器：间距条写 `layout.gap`。选中网格容器：固定轨道的线写 `rows[i].fixed`、`columns[i].fixed`。
- [x] 没有手柄：循环项、画板；值绑定了变量；尺寸是随内容或撑满；按比例或随内容的轨道。读数或检查器说明怎么改。
- [x] 状态样式选中某个取值时，手柄写进这个取值的覆盖。
- [x] 元素在子模板里时，读数写明图上几处一起变。
- [x] 拖动中不写回、不出图；松手记一步撤销、暂存、出图。
- [x] 吸附 0.5 mm，按住 Shift 到 0.1 mm；方向键步长相同。
- [x] 旋转的元素只给移动。

**测试接缝：** 写回是纯函数（文档、元素、手势与增量，得到新文档）：每种父布局、每种手柄配字面值与绑定两种情况，结果由 `checkDslDocument` 判断；浏览器用例拖胸牌的相框与 M402 顶栏的间距。

## Answer

完成于 2026-11-08，分支 `worktree-template-design-page`。

**成果**

- `service/console/src/template/handles.ts`（纯函数）：`handlesOf` 按父容器的布局给出手柄，写不进的写明原因与改法；`applyHandle` 把一次手势变成新文档、幽灵框与读数，拖动中与松手用同一个函数；`nudge` 是方向键；`gridTracks` 按引擎 resolveTracks 的口径算网格轨道的位置（舞台的网格参考线也改用它，线画在哪手柄就在哪）。
  - 自由布局：移动与八个手柄，原来写的是距右、距下的保持；都没写时移动补 `left`、`top`。尺寸不小于 0.1 mm。
  - 堆叠：沿主轴越过兄弟元素的中线就换位（折行时先比行），读数写明先后也是叠放的先后；固定的尺寸才有手柄。
  - 网格：吸到指针所在的格子，右边、下边改跨度，不超出轨道数；只有一列（一行）时不给那条边。
  - 选中堆叠或循环：每个空隙一个间距条，写 `layout.gap` 或 `itemLayout.gap`；主轴两端对齐时没有。选中网格：固定轨道末端的线写 `rows[i].fixed`、`columns[i].fixed`。
  - 没有手柄：画板（出图参数）、循环项（排布在循环容器上改）、子模板调用的画板（在调用它的元素上改）、绑定了变量的值、随内容与撑满的尺寸、按比例与随内容的轨道；旋转的元素只给移动（或改顺序、换格子）。
  - 选了状态样式的取值：写进 `states.cases[取值]`，整份 `place`（或 `layout`、`itemLayout`）；覆盖是整项替换，和引擎合并的口径一致（`src/template/parse.ts:450`）。
  - 定义在图上多于一处时，读数后面写"图上 N 处一起变"。
- `service/console/src/design/handles.tsx`：手柄画在选中的那一处上。拖动中只画幽灵框、插入线与读数，不写回、不出图；Esc 取消（之后松手那一下也不算点击）；松手交给页面。挪不到 3 像素算点击，照常点选与 Alt 穿透。
- 页面：松手记一步撤销并立刻暂存、出图；焦点在页面或舞台上时方向键微调，连着按合成一步撤销，读数显示一会儿。检查器顶上写一句图上能做什么，再列没有手柄的原因。

**验证**

- `service/test/template-handles.test.ts` 24 项：三种父布局、每种手柄配字面值与绑定，距右锚点、拖过头、吸附与 Shift、方向键、旋转、状态样式的覆盖（已有与新建的取值）、网格的跨度与行号上限、两列网格、间距条（两端对齐与绑定时没有）、循环的项间距、画板与循环项；写回结果都过 `checkDslDocument`。
- 浏览器用例「模板设计（票据 13）」：胸牌相框只有右、下、右下三个手柄；拖下边时有幽灵框与读数、没有任何写回；Esc 取消后选中不变、文档不变；再拖一次松手，写回的高是 0.5 的倍数且和读数一致，一步撤销复原；在图上点它后按 ↓ 和姓名换位，撤销复原；M402 顶栏拖第一个间距条，写回的 `layout.gap` 和读数一致。全部「模板设计」浏览器用例 11 个通过；template-* 单元用例 226 个通过。
- 观感：本地预览里看过胸牌相框的三个手柄与幽灵框、全元素牌图片的八个手柄（移动吸到 52.5、49.5）、顶栏的间距条与拖动中的间距带、M402 画板的固定行线（拖到 42 mm 后线跟着新图走）。间距条的把手起初在橙底上看不清，加了白边。

**偏差**

- 堆叠里交叉方向的尺寸固定时也给手柄（票据只写了主轴）：写的是同一个 `place` 里已有的数，不给反而要解释。
- 循环的项间距也有间距条（票据只写了堆叠容器）：写 `itemLayout.gap`，规则相同。
- "状态样式选中某个取值时写进覆盖"：写回与用例已经有了（`HandleInput.state`），但页面要等票据 17 有了取值按钮才有地方选取值，现在传的总是不分状态。已在票据 17 补一条。（票据 17 已接上，选了取值时排序手柄去掉。）
