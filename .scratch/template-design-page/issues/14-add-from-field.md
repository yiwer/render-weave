# 14: 添加元素，或把字段拖进来生成绑定好的元素

**What to build:** 左面板的"添加"页：元素目录与从字段创建。

**Blocked by:** 12

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 19；验收 A09；方案第 13 节。

- [x] 元素目录列出 DSL 的全部元素类型，点击加到选中的容器，或拖到树与舞台上。必填项给合法的初值（如文字的字体取模板里已在用的）。
- [x] 放下的位置决定写什么：堆叠是顺序，网格是行列，自由布局才是坐标。
- [x] 字段映射：文本、数值、日期、时刻、时间变文字加插槽；图片变图片；布尔绑到选中元素的显示；单引用变子模板调用；列表变循环容器。
- [x] 列表与单引用要选被调模板时，只列基准相符的（`template.loopBaseMismatch`、`callBaseMismatch`），也可以当场新建（依赖票据 15、18 的表单，没合入前只列已有的）。
- [x] 元素名按业务含义起名：取字段的显示名称，重复时加序号。

**测试接缝：** 纯函数单元测试：每种字段类型配三种布局，结果由 `checkDslDocument` 判断；浏览器用例拖一个字段。

## Answer

完成于 2026-11-08，分支 `worktree-template-design-page`。

**成果**

- `service/console/src/template/create.ts`：元素目录（DSL 的十二种元素）的合法初值，文字的字体取模板里已在用的；`insertElement` 按父容器的布局写 place（自由写落点坐标、半毫米对齐，堆叠写顺序，网格写行列），名称在模板内唯一；`insertionPoint` 定加到哪（选中容器就放进去，选中别的元素就放在它后面）；字段映射 `planFromField`、`fieldInfo`（列表的项是引用时指向它，是基本类型时指向单值数据定义）、`matchingTemplates`。纯函数。
- `service/console/src/design/add-panel.tsx`：左面板的"添加"页，写明加到哪；元素目录与从字段创建，点一下加，或者拖到结构树、图上。循环、调用与列表、单引用字段先选基准相符的模板；调用另选传什么数据（当前数据、单引用字段、不传），模板按它的基准筛。布尔字段绑到选中元素的显示。
- 拖到图上：从最深处往外找第一个能放的容器，字段只放进这个模板自己的容器；拖经"结构"页签会切过去，可以直接放到树上。
- 每次添加写回一次，一步撤销。

**验证**

- `service/test/template-create.test.ts` 44 项：每种元素与每种字段类型配自由、堆叠、网格三种父布局，写回结果由 `checkDslDocument` 判断；落点、顺序、行列、只能放进容器与画板、字体、基准筛选。
- 浏览器用例「模板设计（票据 14）」：选中顶栏点矩形；把"线路号"字段拖到图上的道路带，生成 `[{ slot: routeNo }]` 的文字、名字加序号；"停靠站点"选模板只列站点与道路段（两个的基准都是停靠站点 v1），加出循环容器；拖经结构页签把椭圆放进底栏；四次撤销回到开始的内容。全部「模板设计」浏览器用例 8 个通过。
- 观感：添加页在真页面上看过。

**用例与观感查出的问题**

- 拖动经过页签时只收到 `dragenter` 没有 `dragover`，切页签挂在 `dragenter` 上。
- 选模板的表单落在面板可视区下面：下拉自动聚焦，滚进视野。
- 值格里写成对象的变体（内边距"分别设置"）挤在一行，每格太窄：改放在下拉下面占满整行（票据 09 留下的）。

**偏差**

- 没有基准相符的模板时只写明缺什么；当场新建要等票据 18 的从空白新建。（票据 18 已接上："新建一个"与"+ 新建模板…"。）
- 拖到图上的网格里，取落点下那个元素所在的格；落在空格子上时按顺序补行列（布局摘要不回答空格子的位置）。
