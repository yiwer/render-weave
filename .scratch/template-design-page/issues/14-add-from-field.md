# 14: 添加元素，或把字段拖进来生成绑定好的元素

**What to build:** 左面板的"添加"页：元素目录与从字段创建。

**Blocked by:** 12

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 19；验收 A09；方案第 13 节。

- [ ] 元素目录列出 DSL 的全部元素类型，点击加到选中的容器，或拖到树与舞台上。必填项给合法的初值（如文字的字体取模板里已在用的）。
- [ ] 放下的位置决定写什么：堆叠是顺序，网格是行列，自由布局才是坐标。
- [ ] 字段映射：文本、数值、日期、时刻、时间变文字加插槽；图片变图片；布尔绑到选中元素的显示；单引用变子模板调用；列表变循环容器。
- [ ] 列表与单引用要选被调模板时，只列基准相符的（`template.loopBaseMismatch`、`callBaseMismatch`），也可以当场新建（依赖票据 15、18 的表单，没合入前只列已有的）。
- [ ] 元素名按业务含义起名：取字段的显示名称，重复时加序号。

**测试接缝：** 纯函数单元测试：每种字段类型配三种布局，结果由 `checkDslDocument` 判断；浏览器用例拖一个字段。
