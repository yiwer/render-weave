# 15: 用表单配置循环与子模板调用

**What to build:** 循环容器与子模板调用的专属表单，取代通用字段。

**Blocked by:** 11

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 20；验收 A09；方案第 7 节。

- [ ] 循环的列表只列列表类型的变量；模板只列基准与列表元素相符的，基本类型列表对应单值数据定义。
- [ ] 调用的数据：不传、当前数据、单引用字段；模板按所选数据过滤。
- [ ] 传入参数：列出被调模板的全部对外参数，每行来源是变量、固定值或循环信息（序号、是否首项、是否末项、总数、组内项数）；没有缺省值又没传的标红。
- [ ] 每项排布：方向、每项尺寸（等分、随内容、固定）、间距、折行、反序、只取一段、合并相邻。
- [ ] 互斥直接禁用并写原因：折行不能配等分或合并，合并只能配等分，横向写每项宽、纵向写每项高。
- [ ] 显示实际结果：项数、每项实际尺寸。
- [ ] 进入被调模板：选中它的画板，不离开这张图。

**测试接缝：** 单元测试走写回入口，结果由 `checkDslDocument` 判断；浏览器用例配胸牌的会场带（`mergeBy`）。
