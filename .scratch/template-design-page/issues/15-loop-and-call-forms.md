# 15: 用表单配置循环与子模板调用

**What to build:** 循环容器与子模板调用的专属表单，取代通用字段。

**Blocked by:** 11

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 20；验收 A09；方案第 7 节。

- [x] 循环的列表只列列表类型的变量；模板只列基准与列表元素相符的，基本类型列表对应单值数据定义。
- [x] 调用的数据：不传、当前数据、单引用字段；模板按所选数据过滤。
- [x] 传入参数：列出被调模板的全部对外参数，每行来源是变量、固定值或循环信息（序号、是否首项、是否末项、总数、组内项数）；没有缺省值又没传的标红。
- [x] 每项排布：方向、每项尺寸（等分、随内容、固定）、间距、折行、反序、只取一段、合并相邻。
- [x] 互斥直接禁用并写原因：折行不能配等分或合并，合并只能配等分，横向写每项宽、纵向写每项高。
- [x] 显示实际结果：项数、每项实际尺寸。
- [x] 进入被调模板：选中它的画板，不离开这张图。

**测试接缝：** 单元测试走写回入口，结果由 `checkDslDocument` 判断；浏览器用例配胸牌的会场带（`mergeBy`）。

## Answer

完成于 2026-11-08，分支 `worktree-template-design-page`。

**成果**

- `service/console/src/template/calls.ts`：换方向时每项尺寸从 widths 换到 heights（值不变）；每项尺寸、折行、合并相邻的写回与互斥原因（折行不能配等分或合并，合并只能配等分并写 spanBy，关折行时换行间距一起去掉）；传入参数的行（被调模板的全部对外参数，标出没缺省值又没传的，多传的另列）；调用的数据；`setElement` 换掉整个元素。纯函数。
- `service/console/src/design/loop-form.tsx`：循环的列表只列列表类型的变量，模板只列基准与列表的项相符的（基本类型的列表对应单值数据定义），对不上时写明 `template.loopBaseMismatch`；调用按传的数据（当前数据、单引用字段、不传）筛模板；合并相邻按被调模板数据的字段选。传入参数每行来源是变量、固定值、循环信息或不传，类型相符的才列；没缺省值又没传的标红。每项排布用分段按钮，用不了的禁用并写原因；最后一行是这一处的实际结果（项数、每项尺寸）。
- 检查器顶上"进入模板「X」"：选中被调模板的画板，预览还是这一张图（地址带 `in=`）。

**验证**

- `service/test/template-calls.test.ts` 8 项：换方向、三种每项尺寸、折行与等分互斥、合并相邻与折行互斥、传入参数的三种来源与去掉、多传的参数、调用的数据；写回结果由 `checkDslDocument` 判断。
- 浏览器用例「模板设计（票据 15）」走 M402：站点列的模板只列站点与道路段；当前序号换成固定值再换回变量；等分时折行禁用并写原因，换随内容后能折行、等分禁用；换纵向后每项尺寸跟过去，实际结果写 35 项；道路段列按道路合并时随内容禁用、折行写明原因，取消合并后 spanBy 一起去掉；进入道路段模板，地址带 `in=`。全部「模板设计」浏览器用例 10 个通过（P1 用例改从新表单填每项的固定尺寸）。
- 观感：循环表单在真页面上看过。

**偏差**

- 票据写的是配胸牌的会场带；会议胸牌的样例里没有合并相邻的循环，改用 M402 的道路段列（按所在道路合并），同一个 DSL 能力。
- 调用传单引用字段时，被调模板列全部、名字后面写基准：编译产物里引用已内联，读不出这个字段指向哪个数据定义；选错了由基准检查报 `template.callBaseMismatch`。
