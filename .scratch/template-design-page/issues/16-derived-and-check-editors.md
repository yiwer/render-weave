# 16: 不写表达式配派生变量与检查项，分支标出当前命中

**What to build:** 派生变量每种运算一个表单，新增与删除派生变量、检查项。

**Blocked by:** 11

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 21；验收 A09；方案第 6 节；ADR-0004。

- [x] 分支编辑器：每行"当 [左] [比较] [右]，取 [值]"，最后一行"否则取"（必填）；`all`、`any` 是一层分组；可以增删、调整顺序。
- [x] 当前样例命中的那一支高亮，运算数旁边显示当前值（票据 02）。
- [x] 运算数选变量或固定值，只列类型相符的；结果类型按运算推，能改时才给选。
- [x] 其他运算：取项（首项、末项、第 N 项）、拆取文本、长度、加减乘除取模，各是小表单。
- [x] 新增派生变量、检查项；名称一般用英文、显示名称写中文（M89）；同作用域不能重名。
- [x] 删除时列出谁在用；还有元素在用时先提示，确认后留给问题清单报，不替人改绑定。
- [x] 循环引用（`template.variableCycle`）当场提示。
- [x] 不做表达式输入框。

**测试接缝：** 纯函数单元测试：每种运算的写回由 `checkDslDocument` 判断；浏览器用例配 M402 的 `stopState`。

## Answer

完成于 2026-11-08，分支 `worktree-template-design-page`。

**成果**

- `service/console/src/template/derived.ts`：每种运算的合法初值（要的变量没有时说明原因，不造坏的）、结果类型按运算推（取项随列表的项，引用写明数据定义）、分支的增删与移动（至少留一支）、条件的三种写法互换、比较换运算（为空只有左侧）、改结果类型时换掉对不上的固定值、检查项的新增删除、循环引用 `cycleOf`、谁在用 `definitionsUsing`。纯函数。
- `service/console/src/design/derived-editor.tsx`：分支每行"当 [左] [比较] [右]，取 [值]"，最后一行"否则取"；条件可选单个、全部成立、任一成立；每支能上移、下移、去掉；当前样例命中的那一支用强调色边框并标"当前命中"，变量旁边显示当前值。取项、拆取文本、长度、加减乘除取模各是小表单。运算数是变量或固定值，只列类型相符的变量。
- 变量面板能新建派生变量（选运算）与检查项，名称一般用英文、同作用域不能重名；右边能删，还有元素或别的定义在用时先列出来确认，删了留给问题清单报，不替人改绑定。循环引用当场写明 `template.variableCycle`。
- 字段带上列表项的类型（`baseFieldsOf`，从数据定义文档读），取项的结果类型才推得对。

**验证**

- `service/test/template-derived.test.ts` 18 项：每种运算的初值加进 M402 站点模板后由 `checkDslDocument` 判断，结果类型、分支行、条件写法、改类型、检查项、删除、循环引用。
- 浏览器用例「模板设计（票据 16）」走 M402 的 `stopState`：本站序号 0 时第 1 支命中高亮，改取值，加一支再去掉，第 2 支换成全部成立，新建派生变量（重名拦下），删还在用的先问、不确定就不动，删没人用的，新建再删检查项，最后和开始的内容一样。全部「模板设计」浏览器用例 9 个通过。
- 观感：和原型 05 对照，把命中的那一支从只换底色改成强调色边框加标签（底色和普通行太像，看不出来），运算数的写法下拉收窄。

**偏差**

- 原型把运算数画成一个带当前值的小标签（"本站序号 = 5"），这里是下拉加当前值，能直接换变量；版式比原型松一些。
- 改名不做：名称是身份，改名等于删一个加一个，引用要跟着改，留给以后的重命名操作。
