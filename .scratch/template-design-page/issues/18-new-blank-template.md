# 18: 从空白开始新建模板

**What to build:** 模板列表的新建弹窗与新建空白工作副本的接口（M356 放到这之后）。

**Blocked by:** 14

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 23；验收 A02、A10；M343、M356、M362。

- [x] 开放 API：新建没有基准修订的空白工作副本，名称已被占答 409；代建端点同形；进审计。
- [x] 新建弹窗（M362 的做法）：名称、基准（选静态数据定义的确切版本，或空数据定义）、适用尺寸范围与默认尺寸。
- [x] 进入设计页后是一块空画板，舞台上写明下一步：从"添加"页加元素或拖字段。
- [x] 没有样例数据集时用空白数据，草稿显示占位。
- [x] 第一次发布记修订 1（沿用"复制为新模板"的流程）。
- [x] 循环与调用的表单里能当场新建被调模板，基准预先填好。

**测试接缝：** 开放 API 用例；浏览器用例走新建到发布。

## Answer

完成于 2026-11-09，分支 `worktree-template-design-page`。

**成果**

- 开放 API 1.17.0：`POST /v1/templates` 与代建端点 `POST /v1/authoring/tenants/{tenantId}/templates`（同一份实现，`service/src/api/template-copies.ts`）。请求体是名称、基准、适用尺寸范围，写法同模板 DSL；服务端生成一块空画板，按保存时的同一套模板静态检查过一遍，成为没有基准修订的工作副本，保存时记修订 1，同复制为新模板。名称已有模板或工作副本答 409；基准不存在、最小大于最大答 400。审计动作 `templateWorkingCopy.blank`，代建的另标跨租户。`docs/api.md` 加了接口说明与变更记录，OpenAPI 快照已更新。
- `service/console/src/components/new-template.tsx`：新建弹窗（M362 的 `<dialog>`）：名称、基准（静态数据定义的确切版本，或空数据定义 v1）、适用尺寸范围一行一组、默认尺寸；不对时当场说明、不能提交。从循环与调用的表单打开时基准预先填好、写明为什么是它，尺寸范围放宽（1–2000 mm），因为实际尺寸由调用方分配。
- 模板列表：客户管理员有"新建模板"，建好进设计页。设计页里空画板时舞台下方写明下一步，带"打开'添加'页"的按钮；没有数据集时样例带只有空白数据，草稿显示占位。
- 当场新建被调模板：检查器里循环与调用的表单、"添加"页选模板处（循环、调用、列表与单引用字段）都有"+ 新建模板…"；没有基准相符的模板时直接给"新建一个"。建好就选上，页面跟着打开它，结构树里看得到。

**验证**

- 开放 API 用例（`template-copies-suite.ts`，内存后端）：新建得到的文档就是那块空画板、没有基准修订、还不在模板列表里；空白数据能出草稿、模板本身没有问题；内置空数据定义能当基准；已有模板、已有工作副本答 409，基准不存在、尺寸颠倒、名称带斜杠、缺尺寸答 400；保存记修订 1；审计记 `templateWorkingCopy.blank`；代建端点同形、标跨租户；操作员答 403。OpenAPI 合同用例通过。
- 浏览器用例「模板设计（票据 18）」：模板列表新建（默认尺寸超出范围时当场拦下），进设计页是空画板、"新模板，未发布"、样例带宽 20；从提示打开"添加"页加"站名"后提示消失；发布为修订 1。再从"站名上方的标识"加循环时当场新建被调模板，基准写着单值·文本 v1，选上并加出循环；检查器里循环的表单再新建一个，循环换过去。整套控制台浏览器用例 40 个通过；template-*、复制与 OpenAPI 用例 255 个通过。
- 观感：本地预览里看过新建弹窗（尺寸起初排成 3+1、外框是浏览器默认的，改成一行一组）、空画板的提示（起初被两侧面板盖住，改成落在两个面板之间）、表单里当场新建的弹窗。

**修掉的问题**

- 在"添加"页的表单里打开新建弹窗，提交会整页重载：表单套表单时，里面的提交事件到外层表单就不再冒泡，React 的根监听接不到，浏览器按原生表单提交了。弹窗改为挂在 `document.body` 下（`components/modal.tsx`），并截住沿组件树往外传的提交与点击。

**偏差**

- 默认尺寸不是 DSL 里的数：记成这个浏览器里设计页样例带的尺寸，出图仍由请求给尺寸。
- 调用传单引用字段时，检查器的表单读不到字段指向的数据定义（票据 15 的偏差），这时没有"+ 新建模板…"；"添加"页按数据定义文档读得到，那里有。
- 还没发布的新模板不在"选模板"的列表里（列表读的是有修订的模板），刚建的那一个会作为当前选中项显示。
