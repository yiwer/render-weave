# 18: 从空白开始新建模板

**What to build:** 模板列表的新建弹窗与新建空白工作副本的接口（M356 放到这之后）。

**Blocked by:** 14

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 23；验收 A02、A10；M343、M356、M362。

- [ ] 开放 API：新建没有基准修订的空白工作副本，名称已被占答 409；代建端点同形；进审计。
- [ ] 新建弹窗（M362 的做法）：名称、基准（选静态数据定义的确切版本，或空数据定义）、适用尺寸范围与默认尺寸。
- [ ] 进入设计页后是一块空画板，舞台上写明下一步：从"添加"页加元素或拖字段。
- [ ] 没有样例数据集时用空白数据，草稿显示占位。
- [ ] 第一次发布记修订 1（沿用"复制为新模板"的流程）。
- [ ] 循环与调用的表单里能当场新建被调模板，基准预先填好。

**测试接缝：** 开放 API 用例；浏览器用例走新建到发布。
