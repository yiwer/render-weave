# 19: 把一块元素提取成子模板

**What to build:** 选中一个容器，提取成新模板，原地换成子模板调用。

**Blocked by:** 12、15

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 24；验收 A09；方案第 5 节；ADR-0007。

- [x] 新模板的基准是当前模板的基准，调用的数据用 `current`；只用到某个单引用字段时，提示可以改成传这个字段。
- [x] 这块元素用到的参数与派生变量：参数变成新模板的对外参数并由调用传入；派生变量复制过去。列出来让人确认。
- [x] 适用尺寸范围取这块元素的实际尺寸，留出余量，可改。
- [x] 两边一步撤销，同一个编辑会话（M356 的跨模板撤销）。
- [x] 提取后图和提取前逐像素相同，否则提示差异，不算完成。

**测试接缝：** 纯函数单元测试加引擎渲染比对：M402 的名称区与胸牌的照片区提取前后图片相同。

## Answer

完成于 2026-11-09，分支 `worktree-template-design-page`。

**成果**

- `service/console/src/template/extract.ts`（纯函数）：`planExtract` 先看会带走什么（参数、派生变量连同依赖、用到的字段、只用到某个单引用字段时的提示、按图上各处实际尺寸放宽的适用尺寸范围、建议的名称），`extractTemplate` 得到新模板与换成调用之后的原模板。为了图逐像素不变：
  - 新模板的画板是空板，里面只放这块元素本身，样式、状态样式、旋转、不透明度都跟着它走，位置只留尺寸（网格里没写宽高的写明撑满）；
  - 调用接过原来的位置与显示，传当前数据，参数按同名传入；画板的缩字下限照抄（M238）。引擎把被调模板的画板展开成不加绘制的容器（`src/evaluate.ts` 的 invoke），分到的框和原来一样。
  - 状态样式按取值改了位置或显示的元素不能提取，写明原因：调用只能按取值换位置与显示，元素自己那份接不住。
- 编辑会话（`template/session.ts`）：`editMany` 把两个模板的改动记成一步撤销，撤销与重做两边一起；`open(name, { created })` 记下这一页刚建的工作副本，撤销后离开时还是空板就删掉。
- 页面：右键菜单（图上与结构树）加"提取为子模板…"，确认弹窗（`design/extract-dialog.tsx`）列出基准与传的数据、变成对外参数的参数、复制过去的派生变量、可改的尺寸范围与名称（和已有模板重名当场拦下）；预览还没出来时不能提取。提取时先建空白工作副本（票据 18 的接口），再一步写两边；两边都暂存后用同一个请求再出一张图，和提取前逐像素比对（`design/pixels.ts`），相同就说明，不同写明差几个像素、这次不算完成、可以撤销。

**验证**

- `service/test/template-extract.test.ts` 6 项，引擎渲染比对：M402 站点模板的名称区（状态样式、7 个参数、2 个派生变量）、站名（缩字组、竖排）、主模板的顶栏（网格里撑满），胸牌的照片区、页眉与信息网格里的一格，提取前后引擎出的图字节相同，新旧模板都过 `checkDslDocument` 与带变量表的静态检查；另有建议名称与尺寸范围、画板与改了位置的状态样式不能提取、单引用字段的提示。
- `template-session.test.ts` 补了两个模板一步撤销、重做的用例。
- 浏览器用例「模板设计（票据 19）」：右键 M402 站点的名称区提取，弹窗列出 7 个参数与 2 个派生变量，名称重了当场拦下；提取后提示"提取前后的图逐像素相同"，原地是调用、新模板带着名称区；点一次撤销，原模板逐字节还原、新模板回到空板。全部「模板设计」浏览器用例 14 个通过，template-*、复制与 OpenAPI 单元用例 262 个通过。
- 观感：本地预览里看过右键菜单、确认弹窗（参数与派生变量排成标签、尺寸一行一组）与提取后的提示。

**偏差**

- 新模板里多一层：画板下面是这块元素本身，不是把容器拆开、子元素直接放在画板上。画板不能有状态样式，也接不住容器的旋转与不透明度，拆开就不能保证图不变。
- 逐像素比对只比当前样例、当前分辨率这一张图；别的样例由引擎用例的口径保证。
- 原模板里的参数与派生变量不删：别的元素或检查项可能还在用。

**下一步**：提取出的新模板还没发布时，原模板发布会因为找不到被调模板被静态检查拦下（保存检查只叠加这一个模板的工作副本），要先发布新模板。票据 18 当场新建的被调模板同样如此；第二期验收（票据 20）走查时看要不要在发布页提示先发布哪几个。
