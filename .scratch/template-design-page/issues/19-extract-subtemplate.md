# 19: 把一块元素提取成子模板

**What to build:** 选中一个容器，提取成新模板，原地换成子模板调用。

**Blocked by:** 12、15

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 24；验收 A09；方案第 5 节；ADR-0007。

- [ ] 新模板的基准是当前模板的基准，调用的数据用 `current`；只用到某个单引用字段时，提示可以改成传这个字段。
- [ ] 这块元素用到的参数与派生变量：参数变成新模板的对外参数并由调用传入；派生变量复制过去。列出来让人确认。
- [ ] 适用尺寸范围取这块元素的实际尺寸，留出余量，可改。
- [ ] 两边一步撤销，同一个编辑会话（M356 的跨模板撤销）。
- [ ] 提取后图和提取前逐像素相同，否则提示差异，不算完成。

**测试接缝：** 纯函数单元测试加引擎渲染比对：M402 的名称区与胸牌的照片区提取前后图片相同。
