# 01: 宽高一格写完：数值加尺寸方式，打数就是固定

**What to build:** 把堆叠、网格与画板里的宽高，和循环的每项尺寸，换成"数值 + 尺寸方式"一格（方案「检查器」、原型 01）。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 2；验收 R01、R09；M396。

- [ ] `place.width`、`place.height`（父布局是堆叠、网格时）与循环 `itemLayout` 的每项宽高换成一格：左边数值框显示这一处的实际尺寸（布局摘要），右边下拉选随内容、撑满、按比例撑满；没写时数值淡色。
- [ ] 在数值框里打数就写 `{ fixed: n }`，选随内容、撑满写 `hug`、`fill`，选按比例撑满写 `{ fill: n }`；固定值绑定变量仍走值格（`{ fixed: { var } }`），绑定时显示灰底条。
- [ ] 自由布局的左、右、上、下、宽、高与最小、最大不变；画板的适用尺寸不变。
- [ ] 状态样式里改尺寸照旧写进覆盖（票据 17），手柄写的数不变（M392）。
- [ ] 写回的纯函数有单元测试：三种父布局、每种写法，`checkDslDocument` 没有严重问题，撤销还原字节。
- [ ] 第一、二期里改尺寸的浏览器用例改成新控件照过。

**测试接缝：** 写回纯函数（`service/console/src/template/`）；浏览器用例。
