# 02: 内边距、外边距一格写四边，要分开时再点开

**What to build:** 把 `padding`、`place.margin` 的"数值 / 分别设置"下拉加四个框，换成一格（方案「检查器」、原型 02）。

**Blocked by:** 无

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 3；验收 R01、R09；M396。

- [x] 一格显示摘要：四边相同时是一个数，不同时写"上 1 · 下 2"之类；没写时淡色显示缺省。
- [x] 点开是四边四个框（每个仍是值格，能绑定变量）；只改一边时只写那一边，四边都一样时收回成一个数。
- [x] 不再出现"分别设置"这一步：直接在展开的某一边打数就行。
- [x] 写回的纯函数有单元测试：一个数、只写一边、四边不同、绑定变量，`checkDslDocument` 没有严重问题，撤销还原字节。
- [x] 票据 20 用例里的"分别设置"步骤改掉，照过。

**测试接缝：** 写回纯函数；浏览器用例。

## Answer

完成于 2026-11-09，分支 `worktree-template-design-page`。

**成果**

- `service/console/src/template/edges.ts`（纯函数）：`partValues` 把一个数或一个变量摊成各边的值；`writePart` 答改一边之后整格写什么（只写改过的那一边，四边都写了且一样时收回成一个数或一个变量，一边都不剩时去掉整格）；`edgesSummary` 是收起时的摘要（"上 1 · 下 2""上下 1 · 左右 2"，绑定的那一边写变量的显示名称）；`inSpokenOrder` 是页面上说和摆的先后（上下、左右）。
- `template/properties.ts`：生成规则认出"一个数 / 变量 / 各项同类的对象"这种字段，把各边的字段挂在 `parts` 上；`padding`、`place.margin`、`cornerRadius` 没写时的缺省是 0。
- `components/property-fields.tsx` 的 `EdgesCell`：收起是一格（值格，能整格绑定），四边不同时框里是摘要；右边的按钮点开四个框，每个仍是值格，能绑定变量与提取为参数（参数名取"整格的名字 + 这一边"，如 `paddingLeft`、"容器内边距（左）"）。没有"分别设置"这一步，也没有写法下拉。
- `template/binding.ts` 的 `extractParameter` 多一个 `written`：只提取一边时，参数照旧声明，写回的是整格的对象。

**验证**

- `service/test/template-edges.test.ts` 13 项：哪些字段是这一格；一个数、只写一边、四边不同、清空一边、四边一样收回、一边都不剩、绑定一边、四边同一个变量收回、提取一边为参数、圆角四角；每一步写回的文档过 `checkDslDocument`，没有严重问题；摘要的各种写法。
- 浏览器用例「模板设计（第三轮 02）」：全元素牌的容器里整格打数、点开改下边、改回收成一个数、上边绑定与断开、左边提取为参数、整格打数盖掉四边；堆叠里的文字外边距没写时淡色 0，只写下边是 `{ bottom: 2 }`，清空后去掉；撤销到底内容回到原样。票据 20 用例里两处"分别设置"换成点开。
- 全部控制台浏览器用例 44 个通过（3 个平时不跑），template 单元用例 279 项通过，三处类型检查没有报错。
- 观感：本地开发服务上截了九种状态（收起一个数、展开、一边不同、一边绑定、摘要、四角、没写、只写下边、一边的绑定弹层），收起时"内边距 1""外边距 下 2"和原型 02 的写法一致。

**偏差**

- 圆角（`cornerRadius`）也成了这一格：规则是按 Schema 的形状认的，四角和四边同形，摘要与展开写"四角"。
- "撤销还原字节"：纯函数这层写回原值比的是内容相等；逐字节还原是编辑会话的撤销负责的（它存的是原文），浏览器用例撤销到底后比内容相等。同票据 01。
- 四个框按上下、左右摆（四角是左上右上、左下右下，和方位对上），写回的对象仍按上右下左的先后。
- 每次选中都是收起的；四边不同时在整格里打数，是把四边都盖成这个数。
- 一边的绑定弹层挂在四格整块下面：挂在窄格上会伸出检查器左边，被画布挡住点不到。
- 没有绑定来源的地方（列表项里的字段）仍是原来的写法下拉，里面还有"分别设置"；现有模型里这种位置没有四边字段。
