# 03: 排布用方向图标加九宫格，间距与内边距一行

**What to build:** 把容器、画板的排布（`layout`）与循环的每项方向，换成方向图标、九宫格对齐与一行间距内边距（方案「检查器」、原型 02，参照 Penpot 与 Figma 的自动布局）。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 4；验收 R01、R09；M396。

- [ ] 方向四个图标：自由、横向堆叠、纵向堆叠、网格；点了写 `layout.mode` 与 `direction`，换布局时按现有规则清掉子元素认不得的 `place` 键（`fitChildren`）。
- [ ] 堆叠时九宫格对齐：主轴写 `justifyContent`，交叉轴写 `alignItems`，横向与纵向的映射各有单元测试；两端、均分在九宫格旁边的小下拉里。
- [ ] 间距与内边距一行（内边距用票据 02 的一格）；网格的行列轨道编辑照旧。
- [ ] 循环的每项方向用同样的两个图标（横、纵），每项尺寸用票据 01 的一格。
- [ ] 写回的纯函数有单元测试，`checkDslDocument` 没有严重问题，撤销还原字节。

**测试接缝：** 写回纯函数；浏览器用例。
