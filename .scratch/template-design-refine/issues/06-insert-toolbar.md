# 06: 底部工具栏点一下就加元素，不用切到"添加"页

**What to build:** 把元素目录从左面板的"添加"页搬到舞台底部的工具栏（方案「底部工具栏管插入」、原型 08）。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 1；验收 R02、R09；M396。

- [ ] 工具栏：选择、平移 ｜ 文字、图片、形状（弹出矩形、椭圆、线条、多边形、路径、二维码、条码）、容器、循环、调用 ｜ 缩放、叠加层。评论是第四期，不显示。
- [ ] 点一下加到 `insertionPoint` 算出的位置（选中容器就放进去，选中别的就放在它后面），写回与票据 14 的同一操作逐字节相同；也能拖到图上或图层里。
- [ ] 循环与调用点了弹出小表单：选列表或数据，再选基准相符的模板，含"+ 新建模板…"（票据 18）。
- [ ] 快捷键 `T` 加文字、`F` 加容器；`V`、`H` 照旧；输入框有焦点时不触发。
- [ ] 左面板"添加"页的元素目录去掉（从字段创建的部分在票据 07 搬走之前先留着）。
- [ ] 票据 14 的浏览器用例改成从工具栏加，照过。
