# 06: 底部工具栏点一下就加元素，不用切到"添加"页

**What to build:** 把元素目录从左面板的"添加"页搬到舞台底部的工具栏（方案「底部工具栏管插入」、原型 08）。

**Blocked by:** 无

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 1；验收 R02、R09；M396。

- [x] 工具栏：选择、平移 ｜ 文字、图片、形状（弹出矩形、椭圆、线条、多边形、路径、二维码、条码）、容器、循环、调用 ｜ 缩放、叠加层。评论是第四期，不显示。
- [x] 点一下加到 `insertionPoint` 算出的位置（选中容器就放进去，选中别的就放在它后面），写回与票据 14 的同一操作逐字节相同；也能拖到图上或图层里。
- [x] 循环与调用点了弹出小表单：选列表或数据，再选基准相符的模板，含"+ 新建模板…"（票据 18）。
- [x] 快捷键 `T` 加文字、`F` 加容器；`V`、`H` 照旧；输入框有焦点时不触发。
- [x] 左面板"添加"页的元素目录去掉（从字段创建的部分在票据 07 搬走之前先留着）。
- [x] 票据 14 的浏览器用例改成从工具栏加，照过。

**测试接缝：** 浏览器用例。

## Answer

完成于 2026-11-10，分支 `worktree-template-design-page`。

**成果**

- 舞台底部的工具栏多了"插入"一组（`service/console/src/design/insert-bar.tsx` 的 `InsertBar`，渲染在 `pages/template-design.tsx` 的 `.design-dock` 里）：选择、平移 ｜ 文字、图片、形状、容器、循环、调用 ｜ 缩放 ｜ 叠加层 ｜ 面板。评论不显示。文字、图片、容器点一下就加；形状点开是浮在工具栏上方的小目录（矩形、椭圆、线条、多边形、路径、二维码、条码，四列一排），底下一行写明加到哪（"点一下加进「顶栏」的最后；也能拖到图上或图层里。"）。加元素的按钮是动作不是模式：没有按下的状态，加完再点一下再加一个。
- 加到哪还是 `insertionPoint`（选中容器放进去，选中别的放在它后面，没选中放画板最后），写回还是 `template/create.ts` 的 `newElement` 加 `insertElement` 一处；页面里的 `addKind` 给工具栏的点击和快捷键共用。`template/create.ts` 新增四样纯数据与纯函数：`INSERT_BAR`（工具栏上的六项与快捷键）、`SHAPE_KINDS`（形状里的七种）、`insertKey`（按键对应哪种元素）、`insertionLabel`（把加到哪说成一句话）。
- 工具栏上的按钮和形状目录里的每一项都能拖：拖到图上或图层里走票据 14 原有的落点规则（`addOnStage` 与结构树的拖放没改）。从形状目录拖出去时目录先藏起来，不挡要放的地方。正在拖的新元素与"能不能放"（`startAddDrag`、`currentAdd`、`canDropInto`）从 `add-panel.tsx` 搬到 `insert-bar.tsx`，舞台、结构树、"添加"页共用。
- 循环与调用点开是小表单：循环先选列表字段，调用先选传给它的数据（当前数据、某个单引用字段、不传数据），再从基准相符的模板里选一个，下拉最后一项是"+ 新建模板…"，一个相符的都没有时直接给"新建一个"（票据 18 的 `NewTemplate`，基准预先填好）；选齐之前"添加"按钮是灰的。打开表单时重新读一次模板列表。点别处或按 Esc 收起，Esc 在这里拦下，不再往上选父级。
- 快捷键：`T` 加文字、`F` 加容器，不分大小写；`V`、`H` 照旧。输入框、下拉、多行输入有焦点时，输入法正在组字时，以及按着 Ctrl、Meta、Alt、Shift 时不触发。
- 左面板"添加"页的元素目录去掉了，只剩"从字段创建"和一行说明（"文字、图片、形状、容器、循环、调用从底部工具栏加。"），等票据 07 搬走。空画板上的提示改成指向底部工具栏。
- 样式：工具栏加了一组后宽 620px。窗口宽不到 1300px 时它会伸到两侧面板底下，这时面板让出底下一条（`.design-panel { bottom: 54px }`）；小目录或表单弹开时空画板的提示先隐藏，不叠在一起。

**验证**

- `service/test/template-create.test.ts`「底部工具栏（第三轮票据 06）」4 项：直接摆出来的五种加形状里的七种就是元素目录，不重不漏，形状里的都不用先选模板；T、F 不分大小写，别的键和要先选模板的不认；选中容器、选中别的、没选中、选中的不在了四种情况下"加到哪"的说法；十二种元素在三种选中下插两次，文本逐字节相同、位置就是 `insertionPoint` 说的、没有严重问题。
- 浏览器用例「模板设计（第三轮 06）」：工具栏上的分组与顺序、没有评论；把"容器"拖到顶栏的留白上，放进留白并选中；没选中时点文字加在画板最后，按 T 再加一个，两次写回都和用例里用同一组纯函数算出的文本逐字节相同；改名时在输入框里打 `tF` 不加元素；H、V 照旧切工具；选中顶栏按 F 加进顶栏；形状点开七项、写明加到哪、点别处收起，点线条加进刚才的容器并收起，再点图片放在线条后面；循环表单选齐之前按钮是灰的，下拉有焦点时按 T 不加元素，列出基准相符的站点与道路段，"+ 新建模板…"的弹窗基准预先填好、取消回到表单，选 stops 与站点后加进底栏；"添加"页没有元素目录、只有从字段创建；撤销到底内容回到原样。再到站点页开调用表单：传当前数据时列出道路段、不列自己，换成不传数据基准变成空数据定义、没选模板不能加，Esc 收起后选中没动、焦点回到按钮，选道路段加上后撤销回到原样。
- 票据 14 的用例改成从工具栏加：点形状目录里的矩形加进选中的顶栏，椭圆从形状目录拖经"结构"页签放到树上；字段仍从"添加"页拖。票据 20（不写 DSL 从空白做出站点模板）里加容器的一步也改成点工具栏，出图仍和原来的逐字节相同。
- 全部控制台浏览器用例 48 个通过（3 个平时不跑），template 单元用例 326 项通过，三处类型检查（`service/console`、`service`、根目录）没有报错。Docker 后端的用例这张票没跑。
- 观感：本地开发服务上截了二十张（1440×900、1180×800、1024×768；选中顶栏、形状目录、循环与调用表单、"添加"页、空画板），和原型 08 对照：形状目录是四列一排的小格、浮在工具栏正上方、底下有一行加到哪，一致；三种窗口宽度下工具栏不压面板、没有横向滚动。

**偏差**

- 叠加层保留原来的四个开关（问题、结构、适配、数据），没有照原型收成一个"叠加"按钮：票据只说"缩放、叠加层"留在工具栏，收成一个要另做弹出层。
- 小目录与表单浮在整条工具栏的正上方居中，不是对着被点的那个按钮。
- "添加"页还在，只剩从字段创建，票据 07 搬走后这一页才去掉。
- 把工具栏上的元素拖到循环的某一项上，会放进被调模板（比如道路段），不是放进循环所在的容器。这是票据 14 拖放原有的规则，这张票没改；新用例因此拖到顶栏的留白上。
- "写回逐字节相同"在浏览器用例里是把控制台的纯函数（`template/create.ts`、`template/document.ts`）导进用例来算期望文本；Docker 里的测试镜像带着 `service/console`，推断能解析，没有实跑。
- 窗口宽不到 1300px 时两侧面板底下让出 54px 给工具栏，原型没画这种宽度。
