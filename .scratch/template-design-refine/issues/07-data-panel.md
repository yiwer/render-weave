# 07: 左面板的"数据"页：字段拖到图上建元素，拖到元素上就连上

**What to build:** 把"变量"页和"添加"页的"从字段创建"合成"数据"页，左面板只剩"图层 / 数据"两页（方案「左面板」、原型 05）。

**Blocked by:** 06

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 7、17；验收 R03、R09；M396。

- [ ] "数据"页四组：字段（类型标记、名称、当前值，可拖）、参数、派生变量、检查项；变量页现有的悬停标出谁在用、选中显示在右边都留着。
- [ ] 字段拖到图上空白处或图层里：建绑定好的元素（同票据 14 的从字段创建）；列表与单引用字段先选基准相符的模板。
- [ ] 字段拖到已有元素上就是连上：文字换成这个字段的插槽，图片换来源，布尔字段绑显示；类型不合的拒绝并在落点写原因；一步撤销。
- [ ] 右键菜单加"连接数据…"：列出类型相符的字段与变量，选了同上（票据 13 的选中条复用它）。
- [ ] 左面板页签是"图层 / 数据"；Agent 页接入 P2 时作第三页出现，本票不显示（M396）。
- [ ] 写回的纯函数有单元测试；票据 08、14 的浏览器用例改到"数据"页，照过。

**测试接缝：** 写回纯函数；浏览器用例。
