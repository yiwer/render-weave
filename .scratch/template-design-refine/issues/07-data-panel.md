# 07: 左面板的"数据"页：字段拖到图上建元素，拖到元素上就连上

**What to build:** 把"变量"页和"添加"页的"从字段创建"合成"数据"页，左面板只剩"图层 / 数据"两页（方案「左面板」、原型 05）。

**Blocked by:** 06

**Status:** resolved

**Trace:** [PRD](../spec.md)；用户故事 7、17；验收 R03、R09；M396。

- [x] "数据"页四组：字段（类型标记、名称、当前值，可拖）、参数、派生变量、检查项；变量页现有的悬停标出谁在用、选中显示在右边都留着。
- [x] 字段拖到图上空白处或图层里：建绑定好的元素（同票据 14 的从字段创建）；列表与单引用字段先选基准相符的模板。
- [x] 字段拖到已有元素上就是连上：文字换成这个字段的插槽，图片换来源，布尔字段绑显示；类型不合的拒绝并在落点写原因；一步撤销。
- [x] 右键菜单加"连接数据…"：列出类型相符的字段与变量，选了同上（票据 13 的选中条复用它）。
- [x] 左面板页签是"图层 / 数据"；Agent 页接入 P2 时作第三页出现，本票不显示（M396）。
- [x] 写回的纯函数有单元测试；票据 08、14 的浏览器用例改到"数据"页，照过。

**测试接缝：** 写回纯函数；浏览器用例。

## Answer

完成于 2026-11-11，分支 `worktree-template-design-page`。

**成果**

- 左面板只剩"图层 / 数据"两页（原来是"结构 / 变量 / 添加"）。`design/add-panel.tsx` 删掉，`design/variables.tsx` 改写成 `DataPanel`：四组依次是字段、参数（对外、内部）、派生变量、检查项。字段一行是类型标记、显示名称、字段名、当前样例的值；参数、派生变量、检查项三组标题右边各有一个"+"，点开才出新建的小表单。变量页原有的悬停标出谁在用、点一下选中并在右边显示都留着。Agent 页不显示（M396）。
- 字段整行能拖。拖到图上的空白处、容器里或图层里是建元素，走票据 14 原有的从字段创建（`template/create.ts`，没有第二处实现）；行尾悬停出现的"+"是不拖的做法，加到工具栏说的同一个位置；布尔字段的"+"是绑到选中元素的显示，没选中元素时提示先选一个。列表字段与单引用字段先在行下面的小表单里选基准相符的模板（也能当场新建），再加循环容器或子模板调用。
- 字段拖到已有元素上是连上，写回只有一处：新文件 `template/connect.ts` 的 `connectData`。文字换成这个字段的插槽（内容整个换掉，字号、颜色等不动），图片换来源，布尔绑显示。类型不合的不写回，原因写在落点的提示条上，例如"「运营方」是文字，接不了图片类型的「线路号图片」：拖到图片上换来源，或拖到空白处建一个图片。"；已经连着的也不再写一次。一次连上是一步撤销。
- 拖的时候落点有标记：图上是一个框加一句话，实线的"连到「X」"或虚线的"放进「X」"；图层里要连上的那一行整行标出来。落到哪一层由 `fieldDropKind` 定：文字与图片是连上，容器与画板是放进去，形状、循环等让给外层；布尔拖到哪个元素上都是连上。拖完或取消（Esc）后标记收起。
- 右键菜单加了"连接数据…"（图上与图层里同一个菜单）：点开在菜单里换成一个列表，只列类型相符的字段、参数与派生变量（`connectChoices`），每项右边写明选了会怎样（换内容、换来源、绑显示），已经连着的那一项是灰的并写"已连着"；选了走的也是 `connectData`。列表是单独的组件 `design/connect.tsx` 的 `ConnectList`，票据 13 的选中条直接用它。
- 连上或被拒绝后在落点出一条提示（成功的 2.6 秒、拒绝的 5.2 秒后自己消失，点一下也消失），连上的元素随即选中。
- 顺带改了一处：元素在图的右半边时，选中框与落点框上的标签靠右对齐，不再伸到检查器底下。

**验证**

- `service/test/template-connect.test.ts` 新增 23 项：三种连法各自只动一个属性；同一份数据连两次逐字节相同；图片拖到文字、文字拖到图片、列表与引用、形状与容器、颜色、画板各自的拒绝原因；已连着的不再写；拖到各类元素上算连上、放进去还是让给外层；"连接数据…"按元素类型列哪些，列出来的每一项选了都连得上且写回通过 `checkDslDocument`。
- 浏览器用例「模板设计（第三轮 07）」：页签是"图层 / 数据"，四组齐全；把"票价（元）"拖到图上的运营方，落点标"连到「运营方」"，写进工作副本的文本和用例里用 `connectData` 算出的逐字节相同，没有严重问题，撤销一步回到原样；把"线路号图片"拖到运营方被拒绝，落点写原因，没有写回；把"线路号图片"拖经"图层"页签放到树上的下一站地标，换了来源；把"运营方"拖到顶栏留白里建出绑好的文字；把"停靠站点"拖进去先出选模板的表单，选站点后加出循环容器；右键票价框的"连接数据…"只列布尔的，已连的 hasFare 是灰的，能退回上一层菜单；右键运营方列文字类的与布尔的、不列图片、列表与颜色，选 hasFare 后绑上显示；每一步都撤销回原样。
- 第一、二期与第三轮 01–06 的浏览器用例里用到"结构""变量""添加"页的都改到"图层""数据"页（票据 08 的变量页、票据 14 的从字段创建等），全部照过：控制台浏览器用例 49 个通过（3 个平时不跑）。template 单元用例 349 项通过，三处类型检查（`service/console`、`service`、根目录）没有报错。Docker 后端的用例这张票没跑。
- 观感：本地开发服务上截了十一张（1440×900；数据页、悬停字段、拖到文字上的落点、连上与拒绝的提示、拖到容器里的落点、列表字段选模板、新建参数、右键菜单、"连接数据…"、拖到图层里），和原型 05 对照：页签、四组的顺序、字段行的类型标记加名称加字段名加当前值、三组标题右边的"+"一致。

**偏差**

- 样例的线路牌与停靠站点里没有布尔字段，"布尔字段拖到元素上绑显示"只有单元用例；浏览器用例里绑显示走的是右键"连接数据…"选派生变量 hasFare，写回是同一个 `connectData`。
- 字段行的拖动把手只在悬停或有焦点时显示，原型是一直显示；类型标记是单个字，没有做成原型的小方块。面板顶上保留了变量页原有的那句作用域说明，原型没有。
- 原型 05 的"数据"页顶上有"一键建好 3 个参数"一块，那是票据 08 的内容，这张票没做。
- "连接数据…"不列颜色、列表与引用：颜色连的是填充等属性，不在这张票的三种连法里；列表与引用建的是循环容器与调用，不是连到已有元素上。
- 连到文字上是把内容整个换成一个插槽，原来写的固定文字与别的插槽不保留；只想插进去一个字段还是用检查器里的"插入字段"。
- 拖字段经过"图层"页签时"数据"页会卸掉，拖动结束的事件收不到，记着"正在拖什么"的那个值会留到下一次拖动开始；判断能不能放看的是拖动自带的数据类型，实测不影响下一次拖放。
- 自动化的拖动要在落点再挪一下才发最后一次 dragover，用例里补了这一步；真鼠标不需要。
