# 08: 调用方传了的参数，在被调模板里一键建好

**What to build:** 被调模板缺调用方传入的参数时，一键按调用方建好（方案「流程」第 1 条、原型 05）。

**Blocked by:** 07

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 8；验收 R04、R09；M396。

- [ ] 纯函数：给调用方文档、循环或调用元素、被调模板文档与调用方的作用域，答出缺的参数：类型照传入值（循环序号、项数、合并项数是整数，是否首项、末项是布尔，变量照它的类型，固定值照字面值），显示名称与缺省值照调用方那个参数，没有就用名称；可见性对外。
- [ ] "数据"页顶部与空画板提示写明"站点列传了 3 个参数，这个模板还没有"，一个按钮建好；循环与调用表单里"被调模板没有这个对外参数"的行旁边也能建这一个。
- [ ] 建好之后循环表单不再报多传的参数；预览不多出严重问题；一步撤销。
- [ ] 单元测试覆盖 M402 的站点列（循环，三个参数）与编码线路牌调用标准线路单边（`docs/examples/coded-route-sign/`，调用传 `currentIndex`）；`checkDslDocument` 与带变量表的静态检查没有严重问题。

**测试接缝：** 写回纯函数；浏览器用例。
