# 09: 一个弹层建好参数、派生变量或检查项

**What to build:** 把"数据"页里建参数、派生变量、检查项的行内表单换成弹层，一次填完（方案「流程」第 2 条、原型 06）。

**Blocked by:** 07

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 9；验收 R01、R09；M396。

- [ ] 参数：名称、显示名称（占位符是名称，不预先写进去）、类型、谁来给（调用方 / 设计时定，即对外 / 内部）、缺省值（按类型给输入框）；回车建好并选中。
- [ ] 派生变量：名称、显示名称、运算；检查项：名称、显示名称。
- [ ] 重名、名称含点等问题当场写在弹层里，不建；名称一般用英文的提示照旧（M89）。
- [ ] 建好的写回过 `checkDslDocument`；票据 16 的浏览器用例改成弹层，照过。

**测试接缝：** 浏览器用例。
