# 11: 新元素按父布局给尺寸，新容器直接起名，新建被调模板预填尺寸并进入

**What to build:** 减少加元素之后的修改：尺寸、名字与当场新建的被调模板（方案「流程」第 4、7 条）。

**Blocked by:** 无

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 11、12；验收 R06、R09；M396。

- [ ] `insertElement`：父容器或画板是堆叠时，文字、容器、循环、调用不写宽高（随内容）；图片、码、形状仍给固定尺寸；网格与自由布局照旧。单元测试覆盖三种父布局、十二种元素。
- [ ] 新建容器之后结构树直接进入改名（同 F2），回车写回，Esc 保留缺省名。
- [ ] 循环或调用表单里"+ 新建模板…"：适用尺寸按这一处各实例的实际尺寸放宽预填（复用 `template/extract.ts` 的 `planExtract` 的算法），建好直接进入新模板，图不离开。
- [ ] 票据 18、20 的浏览器用例跟着改，照过。

**测试接缝：** 写回纯函数；浏览器用例。
