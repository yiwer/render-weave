# 13: 选中元素后，图的上沿浮出常用操作

**What to build:** 选中条：元素名、连接数据、状态、包进容器、提取为子模板、更多（方案「选中条」、原型 01，参照 Canva 的快捷操作条）。按 [Pixso 对照](../pixso-reference.md)（M397）加"包进容器并排 / 上下"两个方向。

**Blocked by:** 07

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 14；验收 R07、R09；M396、M397。

- [ ] 选中元素实例时在图的上沿外浮出，水平跟着元素，限在两个面板之间；画板、拖手柄、就地改文字时不显示。
- [ ] 连接数据用票据 07 的选择；状态打开检查器顶部的状态样式依据；提取为子模板、更多（同右键菜单）各调用现在的同一个函数。
- [ ] 包进容器给两个方向："并排"（横排）与"上下"（纵排，原来的动作）。两者都调用 `wrapInContainer` 的同一份写回，方向只作为参数；右键菜单的"包进容器"仍是纵排，结果与选中条的"上下"逐字节相同。
- [ ] `Shift+A` 等于"包进容器并排"：只在焦点在舞台或页面空白、且没在输入框 / 按钮 / 链接里时生效；本轮只有单选，多选不在本轮。选中条上的按钮本身也带这个键位提示与无障碍名称。
- [ ] 一个动作一处实现：浏览器用例比对选中条与右键菜单做"包进容器（上下）"的写回逐字节相同；选中条的"并排"与快捷操作里的"包进容器并排"写回逐字节相同。
- [ ] 键盘能到达（Tab 进入，方向键在按钮间移动），有无障碍名称；焦点在选中条里时 Tab 不再切同级（见票据 14 的键位边界）。

**测试接缝：** 浏览器用例。
