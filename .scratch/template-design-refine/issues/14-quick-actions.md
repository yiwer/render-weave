# 14: 按 Ctrl+/ 搜动作与属性，直接执行

**What to build:** 快捷操作面板：搜对选中元素能做的动作、能设的选项属性，与这个模板的动作（方案「快捷操作」、原型 07，参照 Figma 的 Quick actions）。按 [Pixso 对照](../pixso-reference.md)（M397）收进"包进容器并排 / 上下"与 Tab / Shift+Tab 选同级。

**Blocked by:** 13

**Status:** ready-for-agent

**Trace:** [PRD](../spec.md)；用户故事 15；验收 R07、R09；M396、M397。

- [ ] 动作来自选中条与右键菜单共用的动作表；选项属性来自检查器的字段（例："书写方向：竖排""垂直对齐：分散"）；模板级的有新建参数、派生变量、检查项、发布修订。动作表里含"包进容器并排"（`Shift+A`）与"包进容器上下"，与票据 13 的选中条调用同一份写回。
- [ ] 按名称与关键词的子串匹配，回车执行，Esc 关；执行结果与从检查器、选中条或菜单做的写回逐字节相同。
- [ ] `Ctrl+K` 照旧管模块与页面，不混；输入框有焦点时 `Ctrl+/` 照样打开。
- [ ] 同级切换：焦点在舞台或页面空白、且没在输入框 / 按钮 / 链接里时，`Tab` / `Shift+Tab` 选同级的下一个 / 上一个（同一父容器内按树的顺序），到两端停住，不绕回；焦点在输入框、按钮、选中条或面板里时，`Tab` 仍是正常的焦点导航，不切同级（票据 13 的选中条要能用 Tab 进入）。
- [ ] 浏览器用例：`Tab` / `Shift+Tab` 的选择结果与在结构树里点同级元素一致；焦点在输入框与选中条里时按 `Tab` 不改选中；`Shift+A` 与快捷操作里的"包进容器并排"写回逐字节相同。

**测试接缝：** 浏览器用例。
