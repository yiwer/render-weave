## 和本页的对照

| Pixso 的做法 | 本页现状 | 建议 |
| --- | --- | --- |
| 左面板页签"图层 / 组件 / 资源 / 页面"；组件从面板拖到画布建实例 | 票据 07：左面板"图层 / 数据"，字段拖到图上建元素、拖到元素上连上 | 一致，不改 |
| 悬停图层，画布上蓝框标出它 | 已有（图层悬停标出、变量悬停标出谁在用） | 一致 |
| 右键"选择图层"列出这一点下面的图层 | 已有（右键"这里的元素"） | 一致 |
| Enter 选子级、Shift+Enter 选父级、Tab / Shift+Tab 选同级下一个 / 上一个 | Enter 下一层、Esc 上一层；没有同级切换 | 采纳 Tab / Shift+Tab 选同级；并进票据 14（快捷操作）的键位 |
| 单击先选父级，双击往下一层，Ctrl+单击深选 | 单击选最深的，Alt+单击穿透，双击文字就地改 | 不采纳：模板的元素少而深，改的多是叶子；双击已用于改文字 |
| 工具栏中间跟着选中的东西变（编辑对象、创建组件、蒙版…） | 票据 13 的选中条 | 一致，票据 13 照做 |
| 自动布局：Shift+A、右键"添加自动布局"；没选中容器时自动包一层 | 有"包进容器"，排布在检查器里改 | 采纳：选中条与快捷操作里加"包进容器并横排 / 竖排"，键位 Shift+A；并进票据 13、14 |
| 边距四边一致显示一个数，不一致显示"混合"，点"独立边距"分开改 | 票据 02 已做（一格写四边，点开改某一边） | 一致 |
| 对齐九宫格；"均匀分布"是间距写"自动" | 票据 03 已做九宫格；均匀分布要看 DSL 的 stack 有没有对应写法 | 未知：先查 DSL，再定 |
| 按住 Alt 悬停另一个对象，红线标出两者间距 | 没有 | 候选新票据：只读、不写回，成本低，对"对不齐"的排查有用 |
| 图层行上显示 / 隐藏、锁定 | 没有；隐藏在 DSL 里是 visible 绑定，锁定是编辑器自己的状态 | 候选：先做"锁定"意义不大（一页一个人改），"临时隐藏"可作叠加层的一项 |
| 标尺与参考线、布局网格 | 有叠加层（问题 / 结构 / 适配 / 数据），没有标尺 | 不采纳：尺寸由布局与适配决定，不靠手摆 |
| 约束（左右、居中、缩放）与交互式图示 | 自由布局的元素有锚定；没有图示 | 候选：看过设计文件再定 |
