# 模板区域纠偏与检查点交接

依据：用户要求继续 P1 实测后的下一步。基线 ce1800a，沿用 template-design 分支。

- A01：宿主核查计划可声明最多 12 个命名参考区域、设计目标和 proposed/approved 状态。原图、区域与依据随计划绑定；未核准目标只作诊断，不被当作已批准字号或新增硬门槛。M402 先量取结构区域并保留待核准标记，墨迹高度不等于字号。
- A02：复用同一像素采样与 SSIM 算法报告命名区域分数；默认短摘要，按 designTarget 读坐标、目标与关联路径。Agent 仅在提供计划时读取纠偏指导，最多两次局部纠偏，保存前后证据，技术通过不直接结束视觉核查。
- A03：check_outcome 反馈模板进度缺失/无效；有效 state.json 与当前候选快照进入已有宿主工具日志，交接优先采用匹配的检查点。业务 MCP 仍只读，不增加工具、不让进度改变模板技术 verdict。
- A04：候选变化后的旧检查点不冒充当前进度；恢复仍核对输入和候选绑定。兼容旧轮次的 state.json，但标明未经检查点绑定。短核心继续保持 1200 字符以内，个人 skills 继续禁用。
- A05：公开入口测试、两轴 review；冻结后用 Haiku 5.5 跑门槛与两次 60k 交接，保留所有失败，比较命名区域/全图像素、峰值、耗时和检查点覆盖。与 P1 历史样本的差异不推断稳定因果。

不引入 OCR、自动审批样式、语义裁判或默认 60k 阈值。未核准的项目数值目标在结果中单列，不掩盖为已完成的样式验收。
