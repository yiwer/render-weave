# 有界元素反馈的真实模型修复对照

用户要求 Haiku 5.5 对照“只看图”与“最多两条元素差异反馈”，相同坏例和修改预算，报告修复率、新增缺陷、上下文峰值与耗时。

- A01：先固定参考、坏例、评分与执行顺序；两臂除附加反馈外相同，不按结果换坏例或重试质量失败。
- A02：3 个新部件/参数组合 × 2 臂 × 2 次重复；每单元固定 2 次修改轮，每轮 maxTurns=20；都使用公开业务 Agent 路径、同模型与工具。
- A03：反馈由布局评判生成，最多 2 项、1200 字符，不加入模型自评或总分；参考期望来自受控正例，不称为任意 PNG 的自动真值。
- A04：分别记录初始目标修复、原通过检查新增失败、技术交回、跨数据绑定、峰值与 wallMs；失败/额度中断不丢弃、不冒充零缺陷。
- A05：先验证脚本与评分，再冻结执行；保留指纹、可视化、原始摘要及两轴 review，依据效果给正式接入判断。
