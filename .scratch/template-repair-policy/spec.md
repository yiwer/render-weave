# 可选区域反馈与修复停止

用户授权合并 push 后接入已验证策略（M312、M314）。

- A01：只对宿主明确核准的非空参考和区域开启；每个登记用例均有参考，逐元素/片段内容、字号、颜色及同类布局框测量。缺失、歧义、未知和未登记元素不能通过；像素分数不作停止依据。
- A02：复用 check_outcome，每次按核准区域去重，最多两项、1200字符。完整参考仅留宿主，默认资料无增量；按需 designCase 查看局部检查，工具输出有界。
- A03：每次重算绑定候选、输入、计划和资源的完整检查。仅技术合格、无待确认项、全部登记检查 measured 且通过才停止；表示登记范围完成，人工视觉审核仍保留。
- A04：显式 --repair-rounds 1–4 开启宿主串行续轮，每轮 maxTurns 不变；完成立即停止，额度/运行/上下文中断不自动继续，预算用尽单独报告。自动续轮不审批/应用，不阻止用户手动反馈；输入漂移不沿用旧反馈。
- A05：公开入口测试、两轴 review 和真实 Haiku 5.5 接线验证；资料/合同变动按 M230 运行四场景门槛。不可用或未达线如实记录，不改通过线。
