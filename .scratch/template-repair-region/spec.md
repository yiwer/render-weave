# 区域反馈与停止条件实验

用户要求继续实验，并结合票据 33–35 和另一位 agent 的观察，实际验证可行方案。

- A01：对固定归档版本的样式核查做真实 render 反例探针；未测量与失败分别记录，不把观察中的因果推断当事实。
- A02：复用前次 C 位置坏例、参考、数据和阈值。每角色去重与按已登记区域去重对照，各重复两次；每轮最多两条、1200 字符，Haiku 5.5，每单元两轮，每轮 maxTurns=20。
- A03：第一轮评分后先持久化全检查停止决定，再执行第二轮影子续跑。停止仅限全部预登记检查存在且通过、技术交回合格；与固定两轮共享第一轮，不宣称独立停止臂。
- A04：冻结脚本、源码、运行包、资料、输入与资源指纹；质量失败不替换，额度中断停止。报告两轮修复率、全检查通过、新增失败、回退、上下文峰值、耗时和实际调用数。
- A05：测试与双轴 review 后给接入判断，保留结果与图片。生产 MCP/默认上下文不变；不据此关闭原票据 33–35。
