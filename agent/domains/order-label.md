# 领域约定：餐饮订单杯贴

适用于茶饮、咖啡、快餐门店打印在杯身或餐盒上的订单标签（杯贴、餐贴）。约定来自门店热敏标签打印的通行做法。具体尺寸、要印哪些要素与客户的特别说明，以项目说明为准。

## 数据定义与数据集

1. **一份数据集对应订单中的一杯（一份）商品**：同一订单的多杯各出一张，"第 n/m 杯"的 n 与 m 是两个整数字段，斜杠与"杯"字由模板写。
2. **取餐号是文本**（常带字母前缀与前导零）；就餐方式是文本枚举（如堂食、外带、外卖）。
3. **商品名与英文商品名是两个文本字段**；杯型、温度等如果是商品名的一部分（如"(大杯)"），按图上写法留在商品名里。
4. **定制选项是文本列表**（甜度、冰量、加料、换奶等），按顾客选择的顺序；可以为空。
5. **备注是可选文本**，顾客没写就省略。
6. **下单时间是日期时间**；门店名称随数据集给出。二维码内容（如订单查询链接）作为文本字段给出。提示语随品牌配置变化时建可选文本字段。

## 模板

7. **取餐号是杯贴上最醒目的文字**，在顶部；就餐方式与第几杯在同一栏的另一侧。
8. **定制选项是圆角描边标签**，数量随数据变化，一行放不下时自动折行（循环或堆叠的 `wrap`）；按项目说明的最多选项数验证区域高度，选项为空时整块不占位。
9. **备注为空时整块隐藏**，不显示"备注："标签与空框；下面的内容不跟着错位时可以固定位置留白。
10. **商品名最长**：文字元素不会自动换行，商品名放一行，按项目说明的最长字数先压缩字形、再缩字，不截断。
11. **热敏打印**：底色只用浅色或不用，文字与描边用深色；二维码保留规定的留白。
