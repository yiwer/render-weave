# Excel 导入的宿主校验

`src/agent/excel-import.ts` 通过 Python 3.13 标准库运行 `verify.py`。此目录属于宿主运行时，不是提供给模型的工具或生成代码。

- `workbook.py` 从固定 xlsx 重建坐标、原值、显示状态与未读内容。
- `generic_check.py` 按 `rw-excel-plan/2` 独立重算全部候选和来源，不判断业务字段映射是否合理。
- `verify.py` 只读原件、目标、映射和候选，生成新的视图与检查结果；从不导入或执行 `transform.py`。

读取器和映射检查器从本仓库 P01–P04 原型提升，不复用旧系统源码。保留原型版本用于历史证据复现；正式检查器另限制总来源/分类引用数为 200000。其他上限包括原件 16 MiB、解压总量 32 MiB、100000 个实际单元格、200 KB 映射、20000 个映射求值节点、24 层递归，以及宿主 30 秒超时。Python 子进程仅获得系统运行必需的环境变量，不继承模型凭据。

格式和转换子集见[映射合同](../../scripts/prototypes/excel-agent/CONTRACT.md)。部署正式 CLI 时须连同本目录及 `web/` 发布；仅复制 `dist/` 不足以运行审核功能。尚未承诺完整 Excel 兼容或共享生产环境隔离。
