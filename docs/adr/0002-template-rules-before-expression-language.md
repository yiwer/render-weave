# 先提供可理解的模板规则，再按必需用例选择表达式能力

旧项目的表达式实现成本高且复杂难用，用户与开发 agent 也未达成共同理解。新设计以可视配置和中文意图辅助创作为主，使字段绑定、重复排列、条件规则可查看并可用样例验证；无法清楚表达的必需规则出现时，再确定公式入口与计算能力。

数据定义及模板 DSL 可以复用经过实例核对的概念，表达式语法重新按需求选择；旧文件原样加载仅在有明确资产需要时纳入范围。这一选择将复用重点放在可解释的业务语义上，而不是提前继承旧语言的全部约束。

依据：2026-09-30 用户第 1 轮 Q2、Q4，以及接受第 2 轮 Q8、Q9 推荐的回答，见[需求探索记录](../discovery/requirements.md)。
