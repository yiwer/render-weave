# 业务任务成果与 agent 执行器分开，先跑通单 agent 闭环

聚合 coding agent 能力首先体现为统一业务任务成果要求、允许替换执行 agent，首个线路牌场景先由一个 agent 跑通。更换执行 agent 时保留业务成果与验收要求；当具体任务需要分工才能满足时，再引入多个 agent 的协作。

这一取舍优先验证 agent 能否完成提取、辅助设计和辅助修改，避免在业务任务尚未跑通时引入协作复杂度；具体 agent 产品和接入协议仍按后续任务合同选择。

依据：2026-09-30 用户接受第 2 轮 Q10 推荐的回答，见[需求探索记录](../discovery/requirements.md)。
