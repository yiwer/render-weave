# 派生值用单步运算按名组合，不引入文本表达式

模板视为以基准数据定义和模板参数为输入的出图函数，模板内可读取的值统一为模板变量。需要计算得到的值作为派生变量：每个派生变量只含一个运算，操作数是其他模板变量或固定值，不允许嵌套，复杂规则靠引用其他派生变量的名字组合。条件分支是首个运算，条件只用结构化比较，按序取首个命中的分支且必须有"否则"分支，结果表达业务语义，元素再按该值选择样式。拼接不作为变量，放入文本元素内容中的变量插槽，展示格式也设在插槽上。

这样每个中间值都有名字并可用样例值展示，依赖关系可检查，agent 改动按变量对比，延续 ADR-0002 可查看、可用样例验证的要求；代价是复杂规则需要较多中间变量。旧设计按种类扩展的条件分支数据源、拼接数据源没有定义组合方式；文本表达式会重新带来语法、类型、空值与报错负担，两者均未采用。若必需规则要很长的变量链才能读懂，再按 ADR-0002 评估文本公式，且公式应编译为同一结构。

依据：2026-10-08 建模草稿讨论 M1–M4、M8，见[需求探索记录](../discovery/requirements.md)。
