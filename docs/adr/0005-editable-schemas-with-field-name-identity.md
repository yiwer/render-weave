# 数据定义可修改，不发布不可变版本；字段以字段名称为身份

数据定义保持可修改，不设不可变的发布版本。字段以字段名称为身份：数据集中的键和模板绑定都使用字段名称；显示名称供人阅读，可随时修改且不影响任何绑定。修改字段名称、删除字段或修改被模板使用的字段类型都会影响绑定，执行前列出受影响的模板并要求确认。

旧 RenderWeave 采用 Draft 加不可变 StaticSchema 的发布模型，模板永久钉住精确版本，更换版本只能复制出新模板；那套机制能保证已发布模板不被破坏，但显著增加了理解与实现成本。本项目以共同理解为首要目标，让数据定义随业务演进。讨论中曾考虑另设与名称无关的稳定字段 ID，使改名不影响绑定；最终以字段名称为身份，因为数据集本身就以字段名称为键，名称即身份最容易解释，改名带来的影响由确认前的影响列表承担。代价是一次数据定义修改会同时作用于所有使用它的模板与数据集。

依据：2026-10-08 建模草稿讨论 M18 及业务实体模型 G1，见[需求探索记录](../discovery/requirements.md)。
