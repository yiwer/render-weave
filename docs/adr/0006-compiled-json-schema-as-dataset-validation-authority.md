# 以编译出的 JSON Schema 作为数据集校验权威

数据定义 DSL 单向编译为 JSON Schema 2020-12，并以它作为数据集是否符合数据定义的权威判定，不另写一套自有校验器。可配置约束限于可编译的子集；时刻、时间不带时区，标准 `time`、`date-time` 格式不适用，因此以注册的自定义格式校验；数值按十进制精确解析，避免二进制浮点误差。资源引用的存在性与种类等需要查询资源仓库的检查属于图片类型自带的检查，不在此列。

旧 RenderWeave 的 ADR-0002 做了相反选择：以自有验证器为权威、JSON Schema 只作互操作，理由是通用校验器对 format、数值精度和时间语义的处理不一致。本项目通过限制约束集合、注册自定义格式和指定十进制解析来消除这些差异，从而只维护一份规则来源；代价是校验错误以 JSON Schema 路径表达，需要映射回字段才能向用户解释，且未来若需要不可编译的约束（如跨字段规则），须另立检查阶段。

依据：2026-10-08 建模草稿讨论 M5、M17，见[需求探索记录](../discovery/requirements.md)。
