# 模板地位平等，沿数据定义引用组合；列表由循环容器调用循环模板渲染

不设"子模板"这一模板种类：任何模板都以自己的基准数据定义为数据输入，被另一个模板调用时才称为子模板。调用时传入的数据只能是一个单值：调用方的单引用字段、基准相同时调用方的当前数据，或者不传数据（被调用模板以空数据定义为基准）。列表[数据定义引用] 由循环容器遍历，容器指定一个基准与列表元素一致的循环模板，为每一项各调用一次。被调用的模板不继承调用方的作用域，调用方的参数与派生变量只能通过被调用模板的对外参数显式传入；循环信息（从 1 开始的序号、是否首项、是否末项、总数）同样由循环容器填入循环模板的对外参数。基本类型的列表由系统内置的单值数据定义包装每一项。作用域因此不再嵌套，列表项需要的派生变量定义在循环模板中。

这样数据定义的引用结构直接决定模板如何组合，每个模板都能用自己的数据与参数单独预览和验证；后续"按条件选择模板"只需在同一基准数据定义的多个模板之间选择，数据兼容性天然成立。代价是即使很简单的列表项也要单独建一个循环模板，循环中需要的序号、本站等信息必须显式传入。旧 RenderWeave 在 Repeat 内直接书写项内容、再按需嵌套 TemplateUse，未被采用；rid-rs 的循环容器指定循环模板的做法与本决定一致。

依据：2026-10-08 建模草稿讨论 M2、M13、M19–M21，见[需求探索记录](../discovery/requirements.md)。
