# 数据集自成一体，不设跨数据集共享实体

每份数据集对应一个业务对象（如一条线路的一个方向），其中引用的结构（如站点）直接内嵌在数据集里，不设跨数据集共享的站点等实体，也不按 ID 关联或同步更新。同一站点出现在多份数据集中时分别维护，或由外部业务系统重新推送；数据集可以直接修改，正式出图以出图记录中的内容快照保证复现。

rid-rs 中站点、线路来自公交管理系统的数据库，并能追踪数据变化后哪些站牌需要重新制作；那种能力依赖共享实体、ID 关联与变更传播，是业务主数据系统的职责。RenderWeave 首版定位为出图系统，渲染消费一份准备好的完整数据即可，这样数据定义引用保持为单纯的结构嵌入，模板沿引用组合的规则也保持简单。代价是首版不提供"改一处、全部更新"，也不提供数据变更后的站牌影响追踪；出现明确业务需要时，再引入共享实体或与外部系统联动。

依据：2026-10-08 建模草稿讨论 M60–M66（回答第 3 轮 Q11），见[需求探索记录](../discovery/requirements.md)。
