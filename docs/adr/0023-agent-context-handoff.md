# 业务 Agent 上下文按需读取，显式预算通过轮次交接控制

依据：2026-10-22 用户批准实施 P0；M305。

模板任务使用短核心、项目输入和资料索引，DSL 章节从现有权威参考生成，不另立 DSL 或 MCP 合同。逐请求统计与原始日志分开，记录观测来源；缓存 token 仍计入有效输入。

缺省只观测。用户可指定 --context-limit；宿主在收到达到阈值的 usage 后停止进程树，保存已有成果及交接包，给出 --from/--feedback 入口，不自动启动新调用。这是事后观测的轮次停止阈值，不是请求前 token 限额或通用注意力退化线。输入/输出余量由调用方按模型与任务配置。

这扩展 ADR-0021 的运行停止原因：硬额度停止规则保留，contextLimit 单独标记，不能冒充 hardQuota。有效 Agent outcome 与 hostRecovery 仍分开，恢复草稿不能批准或应用；交接中的自述状态不构成核查通过证据。输入或候选变化后重新核查。

业务执行器禁用全部运行时 skills，保留文件资料和任务 MCP 工具；不修改开发者个人配置。未来需要业务 skills 时，另定明确的加载清单与版本并重新做运行时及模型评估。

代价：章节取回增加少量工具往返；阈值终止可能留下半写文件，只恢复完整候选。跨轮保存短状态而非整段历史，可能丢失细节，故原始资料及旧轮记录保留按需回读。
