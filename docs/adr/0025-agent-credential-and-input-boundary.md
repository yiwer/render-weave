# ADR-0025：本地 Agent 凭据由宿主持有，低可信内容不授予权限

## 背景

ADR-0015 使用受限 Claude Code 与只读 MCP。检查事实、审核与应用已经位于业务 Agent 工作目录之外，但 Anthropic 直连仍把上游 key 放入执行器环境。真实 CLI 的隔离凭据回归证明，上游错误回显授权值会进入 stream.jsonl 和 round.json；仅要求提示词不输出秘密不能保证日志安全。

## 决定

Anthropic 与 Google 都经本轮宿主的本机代理，执行器只持随轮次撤销的随机令牌。代理不提供任意 URL 转发；限定接口、Host、Origin 与认证。已知凭据在上游响应和执行器持久输出之前精确脱敏，日志原件指已脱敏后的实际观测；用量、错误状态和证据身份保留，不事后改写已封存尝试。

继续使用真实 Claude 的受限文件工具与严格只读 MCP。图片文字、数据值、资源 ID、历史成果和模型备注是资料；允许原样业务处理，不产生新的权限、真值或批准。宿主固定基准与人工审核不接收这些内容的授权声明。实际路径及链接逃逸、替代基准参数、伪造检查/审核都从公开入口验证，配对正常任务仍必须可交付。

## 取舍与范围

代价是 Anthropic 多一跳本机转发，轮次必须关闭连接与令牌；收益是执行器不再获得可复用上游凭据，并在内容到达执行器前阻断已知凭据回显。透明流式转发保留协议、服务模型、用量与错误，随机本机端口不作为实验端点身份。

这不是对任意受信执行器、恶意同账号进程或托管租户提供操作系统沙箱。`--claude` 仍是操作者配置；原生权限证据须绑定实际 CLI 版本与平台。精确脱敏只覆盖宿主登记的凭据及明确编码，不宣称发现所有任意秘密。阶段 5 的服务端权限仍按 ADR-0022 单独实现。

复现与四类配对计划见 [本地信任边界](../agent-trust-boundary.md)，对应 M321。
