日期：2026-10-22。远端审查范围固定为 `66c6e4b...64d7baec6b795c2c5875b3ed754ef425438662be`；实施复审范围是该提交之后的工作区差异。审查按 code-review 技能分 Standards / Spec 两轴独立进行，没有把同一问题在两轴重复出现折成总发现数。原提交的 13 个专项测试通过，不能覆盖以下反例。

## Standards 轴：远端实现

1. **P1，模型自述替代事实。** ADR-0021 的“不得以模型自评取代内容或样式核查”被违反。旧 `coverage-verification.ts:340` 接受任意 notes 作为未知值来源；999 加“我认为正确”即可通过。修正为本次可信事实与实际 pending，普通备注不产生真值。
2. **P1，未测状态计为覆盖。** M296 要求独立样式/状态核查；旧 `style-verification.ts:170` 无条件计 normal、根据文本数量计终点、零异常即通过。修正为显式核准 state，未测维度保留未知。
3. **P2，关闭记录与证据不符。** issue-tracker 关闭规则要求记录验收偏差，远端 34 却勾选全部状态核查。已撤回未证实的关闭结论，保留历史记录并追加更正。

独立反例：`out/review-standards-64d7bae/probe.mjs`。本轮 Standards 复审未发现确定违规；只读复现见 `out/review-standards-current-probe.mjs`，输出 `selfClaim: needsWork`、`noBaseline: notChecked`、`missingRegion: needsWork`、`states: []`。

## Spec 轴：远端实现

1. **P1，普通轮次无法提供参考。** `run.ts` 没有参考输入路径，未配置基准仍声称通过。新增 `--reference`、固定原图与基准、缺省 notChecked。
2. **P1，把通用 code 当站码。** 对非站牌定义套用 15 个缺编号。取消默认样例事实，定义/字段必须显式映射。
3. **P1，覆盖 ID 或 notes 可伪造事实。** 任意覆盖声明可达到满分。取消未校准总分，核对字段/值，未知独立呈现。
4. **P1，否定项目说明被当作授权。** “付款方式不得作为固定常量”触发关键词放行。改用操作者核准的常量 ID 白名单。
5. **P2，框高错误推算字号。** 旧 `min(width,height)*0.95` 不能代表字体字号。明确区分布局框/墨迹框，字号只接受独立核准值。
6. **P2，缺少实际局部证据与状态核查。** 添加真实内容图、同尺度三联图、位置/尺寸/文字/文字颜色诊断、展开实例与源模板路径。最终像素遮挡、对比度与未标注状态明确未知；仍未完成全部独立样式/状态验收。
