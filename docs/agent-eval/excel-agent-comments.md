## 实现行为

- 读取器按工作表内部关系定位传统批注，保留单元格、富文本拼接后的原文、作者和源部件。换行、首尾空格、空文字及附在空单元格上的批注均不丢失。
- VML 只覆盖纯 Note 容器。Row/Column 零基坐标与批注单元格一一匹配，另存图形身份、Anchor 八项和可见性。缺失、重复、错位锚点及异常关系拒绝读取；非批注图形、图片、控件、未知部件仍阻止完成。没有 VML 的传统批注原文可保留，但不声称存在显示框。
- 映射新增通用 `comment` 节点，来源规则与正文分开，并携带批注部件路径；`commentContext` 对每条未映射批注单独记录理由。正文排除范围不能覆盖批注。独立检查直接重读原件，不执行模型脚本。
- 模型提取入口和正式导入共用 `agent/excel/` 的宿主读取器及检查器；旧原型文件留作历史基线。来源修正重放同时匹配规则和部件身份。
- 审核页展示全部批注、作者、源位置、VML 锚点、目标字段或未映射理由，并提供字段到批注的定位链接。批注不作为 HTML 解析。未完成包的导入错误改为可理解的说明。

格式依据与支持子集见[宿主说明](../../agent/excel/README.md)，用法见[审核指南](../excel-agent-review.md)。
