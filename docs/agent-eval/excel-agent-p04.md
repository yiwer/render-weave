# staticSchema 驱动的 Excel Agent：首轮真实测试

2026-11-03。已通过现有 Claude Code 执行器与 OpenCode Go 跑通非公交数据提取：从工作空间发布的 `商品价签@1` 读取字段和约束，处理 Excel，按独立反馈重新提交脚本，生成六份符合定义的数据集。验收状态与命令见[票据 02](../../.scratch/excel-agent-extraction/issues/02-connect-schema-driven-agent.md)。

## 接入方式与泛用范围

入口为分支 `prototype/excel-agent-p04` 的 `scripts/prototypes/excel-agent/agent-run.ts`。调用者给工作空间、准确的 staticSchema 名称与版本、xlsx 和项目说明；宿主通过公开 `readWorkspaceDocuments` 固定定义原文、编译产物与已有数据集身份，模型不能改目标。字段路径、嵌套对象和列表来自该定义，不从线路/站点模型生成。

模型工具是查看工作簿、读取区域、读取定义、提交脚本、交回候选。脚本提交后，Python 容器全量转换；宿主按通用映射递归重算对象、列表和源值，随后对全部候选调用公开 `checkDataset`。任一步失败都返回给同一 Claude 会话。通用转换支持显式数值、布尔、日期和分隔列表；映射合同另存 `scripts/prototypes/excel-agent/CONTRACT.md`。

`src/agent/run.ts` 只增加已有 `claudeCodeExecutor` 的模块导出，没有改变现有任务行为。新入口复用该执行器、模型配置、本机凭据代理、MCP 协议与用量读取；没有另造模型循环。隔离脚本继续复用 P02 容器边界。模型初始化实录仅有五个任务工具，没有 Bash、Read、Write 或任意文件工具。

## 实际结果

| 项目 | 观察 |
|---|---|
| 渠道 / 模型 / 执行器 | OpenCode Go / `claude-haiku-5-5` / Claude Code `2.1.296` |
| 输入 | `fixtures/excel/price-tags.xlsx`，工作空间 `fixtures/workspaces/price-tag`，已发布 `商品价签@1` |
| 模型会话 | 1 次，8 个模型轮次，128666 ms |
| 转换尝试 | 2 次，全部保留；第二次通过 |
| 完整性 | 6 份数据集；70 个非空源单元格全部归类 |
| 引擎校验 | 6 份候选均符合固定 staticSchema |
| 独立真值 | 与未提供给模型的 `fixtures/excel/price-tags.json` 按身份逐字段比对，6/6 相同 |
| 应用状态 | `semantic: needsReview`、`applicable: false`；未应用、发布或出图 |

第一份候选的商品卖点原应为两项。测试宿主在模型提交的脚本末尾追加截断代码，首次实际产物只剩一项；宿主独立检查返回 `countMismatch`、路径 `/datasets/0/data/features`、期望 2 / 实际 1。Claude 识别是注入段，重交原脚本；第二次实际执行时没有该段，完整性恢复。

**这证明真实模型能使用独立反馈并重新提交可用脚本；没有证明它修复了自身生成的算法错误。** 两次 requested 脚本 SHA-256 相同，第一次 executed 脚本不同；原始与实际脚本均归档。初始脚本不是从宿主示例拷入，而是模型读取定义、源表和通用工具合同后编写；代码按计划遍历视图，不手填六份业务值。

用量来自执行器的 result 汇总：输入 14、输出 30508（其中 thinking 18015）、缓存读取 128493、缓存创建 49441 tokens。各类别分别列出，不将“输入 14”当成完整上下文消耗；OpenCode Go 套餐实际扣费未知。此轮没有修改默认推理力度，不从一轮推断性能稳定性。

## 独立审核发现与剩余边界

- 候选数据中的前导零、数值、布尔、ISO 日期、可选缺省和列表均与既有真值相同。备注“新品 / 散装 / 进口”在定义中没有字段，作为待确认的未映射说明区保留。
- 模型自由文本说明对会员价空格的描述不准确：实际缺省为 H4、H6，H7 的 6.98 已正确保留。保留原说明，不把候选校验扩张为自由文本叙述也正确。
- 本轮生成脚本按当前工作簿日期体系转换；它不是可直接复用到任意日期体系的通用解析库。后续工作簿仍须重新检查；宿主检查器独立处理 date1904 与 1900 闰日例外。
- 本地检查验证了任意字段名下的嵌套对象和列表；真实模型这一轮只验证价签定义，未做复杂引用对象、多层表头、跨表 join、资源引用或大表性能验收。顶层候选目前逐份列计划；不能据此承诺大量记录时模型 token 成本可接受。
- 新入口尚未接入正式 `renderweave agent run` 的检查点、人工修正与审核应用；托管、多租户隔离和生产宿主崩溃恢复也未完成。原型可运行，不代表产品上线。
