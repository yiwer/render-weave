2026-11-03。用户提供上行第 13 站参考图，要求配合模板制作模块完成。此轮调用现有 `agent run` 的模板辅助设计、模板辅助修改，使用 Claude Code + OpenCode Go；随后通过公开渲染入口检查真实制作范围。执行结果和验收记录见[票据 09](../../.scratch/excel-agent-extraction/issues/09-template-module-115.md)，决定见 M373。

## 数据与模板如何衔接

第一轮直接使用已批准的 `production-direction@2` / `production-stop@2`。模型能设计动态布局，但原始 `annotation` 是自由文本，不能直接作为明确的换乘类别枚举；首版因此把换乘圆标统一画成蓝色。

第二轮在独立工作空间建立显示定义，而不是改写已批准原文：

- `production-connection-view@1`：`category` 枚举为 metro-1、metro-2、metro-3、metro-4、railway、airport。
- `production-stop-view@1`：保留原始站点字段，增加 `connections` 引用列表。
- `production-direction-view@1`：保留方向字段，站点列表引用显示定义。
- `115-up-view` / `115-down-view`：从原始候选生成显示投影。原 `annotation`、站名、尺寸、时间、批注等全部保留；解析出的换乘类别另存。每项记录原数据集、字段路径、C/J 列源坐标、原文与目标值，未知附注拒绝转换。

这套显示定义与映射属于该工作空间，不在通用引擎中增加“115 路”“站点”或“地铁编号”的分支。模板的可变内容仍由字段和 `currentIndex` 参数驱动：起终点、主副站名、本站/下一站状态、HH:mm、站码、换乘类别均随数据变化。

**显示投影尚未进入正式 Excel 导入/审核链路。** 本次对它做了原字段一致性、类型与来源映射核对，但不能把旧数据的批准当成新增解释的批准；现有 `agent prepare-output` 的已审核应用门槛没有放宽。接正式生产前，需要将新增显示字段纳入可重放的数据审核，再审核应用新模板。

## 真实模块调用

先用 `template-design`、数据集 `115-up` 和原图生成候选；再用 `template-revision`、数据集 `115-up-view`、明确的显示定义与修正要求做第二轮。原图对应请求为 `currentIndex: 13`、525 × 135 mm、96 dpi，主模板名 `wuxi-production-sign`。

两个轮次均固定源图、工作空间与资源。第二轮以第一轮候选为工作副本基线，仅先适配 `base/ref`；布局、类别标记和图例由模板模块修改。模型输出的四个模板是主模板、站点列、换乘标记列、单个换乘标记。

独立看图发现 450 mm 宽时线路号与“路”字相交，宿主追加一个局部修正：线路号由固定左偏移改为距线路色块右侧 25 mm。原模型轮次保持原样，修正单独记入 `manual-adjustment.json`，没有冒充模型原始成果或自动批准。
