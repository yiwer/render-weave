# 模板视觉反馈：研究、实施与提交结果

日期：2026-10-23。范围按用户最新决定 M307 聚焦中文、英文；阿拉伯文还原已停止，既有证据只作历史诊断。本次提交包含首期实现及已验证结果，不表示完整业务视觉验收结束。

## 结论与实现

采用可信参考区域与多维局部反馈，不用 SSIM、LPIPS 或加权总分代表还原质量。研究覆盖 Design2Code、感知指标与 Canvas 渲染证据，来源、适用限制和后续候选见[研究报告](research/2026-10-22-template-visual-fidelity-harness.md)；已批准设计见[方案](../.scratch/agent-template-authoring/visual-feedback-design.md)。

- `compare_reference` 返回区域匹配、文字、毫米位置/尺寸、文字颜色偏差，以及参考/候选/叠图；定位到展开实例与源模板。
- 渲染证据在草稿占位和问题边框之前取得。正式出图仍遵守严重问题拦截。
- `--reference` 和 `--content-baseline` 固定本次参考与内容事实。字段名、模型备注或领域名不能自证真值；未知与未核实状态保留审核。
- `check_outcome` 与交回后检查共用比较模块；报告绑定参考、候选、数据、请求、实际资源与构建。普通轮次保存实际提示词和资料副本。
- MCP 合同 0.10.1 增加区域分页并统一输出预算，截断后仍能发现全部区域与异常分类计数。

远端 33、34 的错误覆盖判定、框高反推字号、缺少参考输入等问题已修正，独立两轴复审见[复核报告](agent-33-34-review.md)。具体接入见[使用指南](agent-visual-feedback.md)。

## 复现与后续

无需模型额度的中英文工具验证：

```powershell
node --import tsx scripts/accept-agent-visual.mjs out/agent-visual-acceptance-zh zh
node --import tsx scripts/accept-agent-visual.mjs out/agent-visual-acceptance-en en
npm run typecheck
```

生成目录包含参考、候选、报告、真实内容图和三联图；目录位于不入库的 `out/`。真实模型日志与本地旧原图材料也不入库，换机器须恢复对应材料；可复现脚本和脱敏结果摘要随本次提交保存。
