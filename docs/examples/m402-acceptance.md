# M402 端到端验收

**结论：渲染流水线首期的结构与行为验收通过。** 直接加载 `docs/examples/m402-dsl/` 的完整原文件，正式出图为 3496 × 780 像素、120 DPI，0 个问题；35 个站点、15 段道路、15 个班次及本站状态均正确。精确外观的已知差异如下表记录。

## 复现

准备依赖和资源后，一条命令完成正式出图：

```powershell
npm install
npm run fetch-fonts
npm run render -- render --workspace docs/examples/m402-dsl --resources fixtures/resources --request docs/examples/m402-dsl/render-request-m402.json --out out/ticket14/base
```

生成全部场景、问题清单、布局摘要、输入哈希与并排对照页：

```powershell
npm run build
node scripts/accept-m402.mjs
```

在本地打开 `out/ticket14/comparison.html`，左侧参考图、右侧基准输出，可切换到原像素尺寸；下方列出其他场景。脚本逐一断言预期成功/失败及草稿/正式诊断相同，重复运行会清除失败场景的陈旧正式图片。11 份输入 JSON 的运行前后字节保持一致，哈希写到 `out/ticket14/inputs.sha256.json`。

本次已直接读取参考图和各场景 PNG 做目视核对。浏览器工具的 URL 策略拒绝 `file:` 页面，因此并排 HTML 未通过浏览器工具打开；其原始图片与场景结果均已检视。
