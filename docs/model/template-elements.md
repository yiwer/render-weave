# 模板元素目录（草稿）

第二阶段票据 01 已落地[二维码](../render-qrcode.md)，票据 02 已落地 [CODE128 条形码](../render-barcode.md)；实际 DSL、尺寸与诊断约束见相应说明，EAN/UPC 按票据 03 实施。

本文包含未来设计，不等同于当前引擎支持清单。首期可执行范围见 [阶段验收的 DSL 能力表](../stage1-acceptance.md#dsl-当前可承载的能力)，具体 JSON 写法见 [M402 DSL](../examples/m402-dsl/README.md)。

状态：2026-10-08 起草并对齐，对应业务实体模型的 G10；E1–E10 均已定（M67–M76）。参照来源：rid-rs 与 design-layout-draw 的 Wpf 元素（WpfFrame、WpfBox、WpfText 等），旧 RenderWeave `renderweave-design/1.0` 的十八种节点（`renderweave-template/.../NodeContractCatalog.java`）。排布与适配的具体规则（缩字、换行、循环项如何排列）随第 3 轮 Q13 决定，本文只给出它们挂在哪个元素、哪个属性上。文末 E 编号为对齐过程中的问题。

## 一、元素一览

| 元素 | 用途 | 关键属性 | 线路牌中的用法 | 旧系统对应 |
|---|---|---|---|---|
| 画板 | 模板的根，每个模板恰好一个 | 适用尺寸范围；背景色或背景图；内边距；布局方式（同容器） | 标准线路牌的整块牌面 | WpfFrame；旧 Canvas 节点 |
| 容器 | 把元素组织在一起并决定其排布 | 布局方式：自由、堆叠、网格（E1）；外观：填充、描边、圆角、内边距、是否裁剪超出部分 | 线路号与方向一行、站点条区域 | WpfBox；旧 Frame、Stack、Grid |
| 循环容器 | 遍历一个列表字段，为每项调用循环模板 | 列表字段；循环模板；参数填写（含循环信息）；项的排布（每项一列平分宽度，M82）；可按某字段合并相邻同值项，每组跨相应列数（M79）；外观同容器 | 站点列表、换乘标签列表 | WpfBox 的 loop；旧 Repeat |
| 子模板调用 | 调用另一个模板 | 被调模板；数据来源（单引用字段、当前数据或无）；参数填写；调用框尺寸即被调模板的实际尺寸，调用框随内容时取其内容的自然尺寸（E3、M92） | 首版线路牌未用；整版站牌中的站名模块会用 | WpfBox 的 embeddedTemplate；旧 TemplateUse |
| 文本 | 显示文字 | 内容由片段组成，片段是文字或变量插槽，可各自设字体、字号、颜色、字重、倾斜（E6、M80；字重随字体资源，M115）；书写方向（横排、竖排）；水平与垂直对齐；行高、字间距；换行（不换行、按字换行）；放不下时的处理（拉开或收紧字距、字形压缩、缩小字号、省略号、裁剪、报问题，顺序见第六节）；最小字号（默认 5 mm，M86）；缩字组（M91）；文字描边 | 线路号、"开往 丁站"、站名、首末班 | WpfText；旧 Text |
| 图片 | 显示图片 | 来源（资源引用，或绑定图片字段、图片参数）；适配方式（完整显示、铺满裁剪、拉伸） | 线路标识、运营方 logo（演示中未用） | WpfImage；旧 Image |
| 矩形 | 色块、底框、细线 | 填充色；描边（颜色、宽度、实线或虚线）；圆角 | 高亮底框、左右连线、换乘标签底框 | WpfRect；旧 Rect |
| 椭圆 | 圆点、圆形标记 | 填充色；描边 | 站点圆点（演示中可加） | WpfEllipse；旧 Ellipse |
| 线条 | 任意方向的直线 | 起点与终点（相对元素框）；描边（颜色、宽度、实线或虚线）；线端形状 | 斜向或虚线连线 | 旧 Line |
| 多边形 | 由若干顶点围成的图形 | 顶点列表（相对元素框，毫米，框变化时不拉伸，M94）；填充色；描边 | 方向箭头、三角标记 | WpfPolygon；旧 Polygon |
| 路径 | 由直线与曲线组成的任意图形 | 路径数据（SVG 路径语法，毫米，相对元素框，框变化时不拉伸，M76、M94）；填充色；描边；填充规则 | 弯曲的线路走向、自定义图标 | 旧 Path |
| 二维码 | 由文本生成二维码 | 内容；纠错等级；前景色、背景色 | 实时到站查询码（真实站牌常见） | WpfQrCode；旧 QrCode |
| 条形码 | 由文本生成条形码 | 格式（如 CODE128、EAN-13、EAN-8、UPC-A）；内容；前景色、背景色；是否在下方显示文字 | 站牌资产编号等 | WpfBarCode；旧 Barcode |

## 二、所有元素共有的属性

| 属性 | 说明 |
|---|---|
| 名称 | 必填，模板内唯一，用业务含义命名（如"站名""高亮底框"）。规则差异、问题清单与 agent 都靠名称定位元素，旧编辑器的 agent 规范也强调这一点；名称逐层组成元素路径（M101） |
| 位置与尺寸 | 由所在容器的布局方式决定，见第三节 |
| 透明度、旋转 | 数值 |
| 条件显示 | 按布尔值决定是否显示；隐藏的元素不参与布局（M27） |
| 状态样式 | 按某个模板变量的取值覆盖属性取值，另有"其他取值"（M28） |
| 绑定 | 把属性取值交给模板变量，范围见第四节 |

层叠顺序就是容器内的元素顺序，排在后面的画在上面，不另设层级编号（E5）。

## 三、位置与尺寸随布局方式而定

长度单位统一为毫米（E2）。

| 所在容器的布局方式 | 元素上的位置与尺寸属性 |
|---|---|
| 自由 | 横向位置取"距左"或"距右"、纵向位置取"距上"或"距下"（相对容器内容区，M93）；宽、高 |
| 堆叠（横向或纵向） | 宽、高各自取"固定""随内容""填满剩余空间"之一；最小与最大尺寸；外边距；交叉方向对齐；填满时的分配权重 |
| 网格 | 所在行、列与跨行、跨列数；宽、高方式同上；外边距；格内对齐 |

容器自身的布局参数：

- 堆叠：方向；元素间距；主方向分布（靠前、居中、靠后、两端、均分）；交叉方向对齐。
- 网格：行定义与列定义，每条取"固定毫米""按比例""随内容"；行间距、列间距。

## 四、哪些属性可以绑定

原则：内容、显隐、颜色、数值与网格中的位置可以绑定，结构不可以绑定（E4，M71）。绑定和状态样式的取值类型必须与属性类型一致。

| 可以绑定 | 不可以绑定 |
|---|---|
| 文本内容（通过变量插槽） | 元素种类、布局方式 |
| 图片来源、二维码与条形码内容 | 网格的行列定义（可用状态样式切换预设定义，E9） |
| 颜色：填充、描边、文字颜色 | 循环容器的列表字段与循环模板 |
| 数值：尺寸、间距、内边距、字号、圆角、透明度、旋转 | 子模板调用的被调模板（动态模板以后另行设计） |
| 网格中的位置：所在行、列与跨行、跨列数 | 多边形顶点与路径数据 |
| 是否显示（通过条件显示） | 元素名称 |

rid-rs 的实际用法支持这条原则：设计者常把间距、描边宽度交给自定义数据源调节（如"内容间距""是否显示白边"），在新模型中对应内部参数加绑定。

## 五、暂不提供

| 元素或能力 | 原因或替代 |
|---|---|
| 无布局的纯分组 | 用自由布局的容器代替 |
| 表格元素 | 班次表等用循环容器加网格表达 |
| 渐变填充、阴影、混合模式 | 有需要再加 |
| 小程序码 | rid-rs 有专门元素，属于特定业务，暂不提供 |

## 六、排布与适配（Q13 结论）

依据 [M402 设计稿解读](../examples/m402-design-analysis.md)，已定：

- 停靠站点每站一列，平分可用宽度；一块线路牌上的站名字号一致，经对外参数绑定到字号；默认保持 10 mm，站数增加时先收窄列间留白，列内确实放不下再全组缩字（M135，取代默认按站数分档）。
- 竖排站名放不下：两端分布、收紧字距，再纵向压缩字形，最多压到原高 60%，不减小字号；仍放不下记严重问题（M82、M88）。
- 站数多到列宽放不下：统一缩小全部站名字号到最小可读字号，仍放不下记严重问题（M83）；"统一"由缩字组实现（M91）。
- 横排短文本放不下：先横向压缩字形到原宽 60%，再缩小字号，再报问题；跨度大时拉开字距（M84）；横排同间隔分布让两侧留白与字间距相等，M402 道路名采用此方式（M131），另支持两端贴边分布。
- 画板宽度变化时重新排布，字号不变（M85）。
- 循环容器可合并相邻同值项（M79）。

旧系统中以下与排布相关的能力，首版不提供，有需要再加：

- 循环项的过滤：按序号区间、奇数项、偶数项、前半段、后半段取项，用于把站点分成上下两排（旧编辑器"列表数据过滤"）。
- 循环项前后附加固定项（旧编辑器 customChildren）。
- 指定某些项占双倍宽度（rid-rs 扩展属性；首版可通过绑定网格跨列数实现，M71）、反序排列（rid-rs 站牌"正"面分站列表反序）。
- 网格按项数自动扩展行或列（ts-layout-wpf autoExpandDirection）、内容溢出时整体缩放（overflowScaleBox）。
- 按可用高度选用不同图片（旧编辑器"自适应标语"）。
