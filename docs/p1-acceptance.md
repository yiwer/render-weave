## 后续

按影响排序；都不挡本阶段的验收。

1. **`npm test` 全并行不稳定**（A12）。引擎组的 `agent-*` 重型用例抢 `fixtures/resources` 的写锁、争 CPU：16 个逻辑核的 Windows 上不限 worker 58–62 条失败，4 个 worker 6 条，串行 1 条。现在靠 `--maxWorkers=4` 加串行复核。做法二选一：让 vitest 配置把这些文件放进串行的一组（全量约慢一倍），或者让它们不再共用样例目录的写锁。
2. **`agent-candidate-freeze` 在没开开发者模式的 Windows 上失败**：建符号链接报 `EPERM`。用例可以在建不了链接时跳过，或者文档要求开发者模式；Linux 上通过。
3. **状态栏的"进行中的批次"只数本标签页提交的**（M359）。要显示全租户的，先给开放 API 加列批次的端点。
4. ~~数据定义详情页离开时不提示~~（票据 06）：票据 14 重做编辑页时解决了，换页与关窗口都先问（M360）。
