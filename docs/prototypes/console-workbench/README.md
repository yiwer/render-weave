# 出图控制台整体改版原型「经纬 · 工作台」

回答一个问题：出图控制台的**布局、页面数据呈现与交互**整体重做，应该长什么样。视觉沿用 M398 的「经纬」色板，这里改的是骨架。起因是用户 2026-11-12 的要求「布局、页面数据呈现、交互都需要进行整体性改动……有一种设计过的美感」，以及随后的基调「灵动，但举重若轻。一切整整有序」。第二轮按「整体风格没有问题，局部细节不足」逐项打磨：列表行减字、动态 SVG、组件的质感与形状、总览重排、左栏可收起。第三轮（「再打磨一轮」）没有新的指示，是自己逐张走查后收的尾：数据集账页降噪、问题清单重画、速览里的字段列表、编辑页的站名小牌、发布抽屉的提示。

原型只作讨论，不作实现基础。它是纯静态页面，数据写死在 `data.js`，不连服务；还没有据它定下任何 M 编号的决定。

只做了一个方向，没有并排几个变体：基调已经给得很具体，几个差异很大的变体里多数会直接违背它。要比较别的方向，在这个目录旁边另起。

## 方案要点

**一条流水摆在左边。** 左栏 224 px、浅色，不是一块深色。四个工位「数据定义 → 模板 → 数据集 → 出图」是串在一根经线上的四颗图标珠子，当前工位的珠子是靛蓝；有批次在出图时，「出图」那颗外面多一圈转着的橙色弧线，它上方那段经线变成流动的虚线。下面是支撑的三项（资源、用量、管理），栏底是本月额度的小环、当前用户与连接状态。

**左栏可以收起。** 点品牌右边的按钮或按 `[`，左栏收成 56 px 的一窄条：只剩图标，四颗珠子仍串在经线上，悬停出名字，待处理的数量缩成角标；选择记在浏览器里，下次打开还是这样（`18-左栏收起.png`）。原来的标题栏模块下拉与底部状态栏都收进这一栏，顶上只剩 46 px 的一条：面包屑、进行中的批次、快捷键。

**所有列表页一副骨架。** 页头（标题、数量、主动作）→ 筛选行 → 账页（行高 44 px）→ 右侧 436 px 的速览。选中一行不换页，只有速览重画，靛蓝的选中条滑到新的一行；回车才进编辑页。数据定义、模板、数据集、批次、资源五个模块都是这一副，对齐线相同。

**一行只说一件事。** 每行由一个带形状的引子起头（数据定义与批次是所属数据定义的图标块，模板与数据集是最近一张图的小样，成员是首字母），后面是名字，再后面只留会影响下一步的两三项，版本、数量、日期用等宽字。状态只在出事时出声：通过校验是一个淡淡的勾，有问题才是一枚红色的小牌；不再每行重复写「已发布」「正常」。数据集有 200 行，按同一条规则再收一遍：版本只在落后时出现（`v1 ↑`），今天出的图只写时刻，勾选框平时不显示——悬停或选中的一行才有，勾了任何一行后整列亮出来。行首的小样裁成满格的一小块，靠顶上那条色带认模板。

**问题清单的一条。** 白底、左边一道颜色（红是严重，橙是提示），第一行是级别和说明，第二行是字段的路径和元素路径；元素路径只留末三段，全文在悬停提示里。数据集的速览和批次的速览用同一种卡片。

**改动的记号。** 原来的橙色十字去掉了。新增是一枚实心的橙色小菱形，改动是空心的；列表里草稿写成一枚小牌「3 处改动」或「待批准」，字段行尾是「新增」「改动」。菱形只表示「相对已发布的版本有变化」，别处不用。

**数据怎么摆。**

| 位置 | 做法 |
|---|---|
| 总览 | 上面一排两块：左边「等你处理」（待批准的发布、有严重问题的数据集、有失败项的批次，各一行），右边是正在出图的批次——一台织机，每个渲染项一根纬线，织好的是灰蓝、失败的是红、正在织的那根有梭子来回走。中间是「流水」：每个数据定义一行，往右依次是它的模板（带小样）、数据集（数量加一根通过／有问题／可迁移的分布条）和本月出的图（数量加近 12 天的小柱）；四格之间有小箭头，正在出图的那一格箭头是流动的橙色虚线。最后是最近出图 |
| 数据定义 | 静态数据定义并进来，作为版本的一面，不再单独一个模块；速览里是字段（左边显示名称、右边字段名称，约束留给编辑页）、版本时间线、谁在用。编辑页是字段表加字段检查器，草稿相对已发布的改动用橙色记号标在行上，发布走右侧抽屉看差异与影响 |
| 模板 | 画廊按基准数据定义分组，卡片上是真渲染的图；可切到列表。速览里直接试对外参数 |
| 数据集 | 账页每行带最近一张图的小样；有问题的一份，速览最上面就是问题清单。编辑页左边表单与站点表，右边草稿预览，表里选一站，图上框出这一站，站名的小牌挂在图的上沿之外、一根细线引到框上，不盖住图 |
| 出图 | 批次的进度是一根纬线（完成、失败、正在出、排队四段）；速览里每个渲染项一格（完成是灰蓝，只有失败和正在出的带颜色），点一格看这一张的出图记录，可在抽屉里重放并逐字节比对。「出图记录」页签按天排成图墙 |
| 用量 | 一个大数字加额度条，每天一根柱，按模板与按来源各一组横条 |

**交互。** `↑↓` 或 `j k` 选行，`↵` 打开，`/` 筛选，`空格` 勾选（数据集可多选后合成一个批次），`Ctrl K` 搜索与跳转（搜得到具体对象，不只是模块），`← →` 在出图记录之间走，`Esc` 关，`?` 看全部快捷键。

**质感与形状。** 卡片、账页、抽屉用同一套圆角（控件 7 px、卡片 10 px、抽屉与搜索框 12–14 px）和两层很浅的投影；分段开关里只有一块白色的滑块在动；看图的地方都是一张点阵台面，图的四角有裁切线，图注在台面左下角。

**动效。** 都是 CSS 驱动的 SVG 与变换，没有脚本逐帧画的东西。一次性的动作：内容入场上移 5 px（180 ms）、选中条与分段滑块滑动（160 ms）、左栏收起（200 ms）、抽屉与搜索框进场（220 ms 与 120 ms），位移都不超过 6 px。不带位移的描线与生长可以稍长：柱子和分布条长出来（约 0.5 s）、提示条里的勾和重放结论的圆圈被画出来、重放时一道扫描线扫过图。持续在动的只有一类——正在出图的东西：左栏那颗珠子外的弧线、顶栏批次的进度环、织机上的梭子、进度里正在出的那一段。截图里和系统设了「减少动态」时全部停住（`style.css:471`–`474`），停住的那一帧本身是完整的画面。

## 和现在的控制台不一样的地方

落地前这几处要先拍板，它们改的是已经定下的东西：

- **框架**：现在是标题栏模块下拉加状态栏（`.scratch/authoring-api-and-pages/spec.md:197`–`198`），原型换成左栏导航。
- **左栏原本留给 Agent**：M342 定了每个模块页的左栏是以当前对象为上下文的 Agent 对话，P2 接入前不显示（同一份规格的第 199 行）；模板设计页的 Agent 已由 M396 改进它自己的左面板，其余模块页仍按 M342。原型把左栏给了导航，也没有画 Agent 对话。建议：对话挪到右侧，和速览共用那 436 px，作第二个页签——两者说的都是「当前选中的这个对象」，接入前照旧不显示。这要修订 M342。切换条件：对话需要和速览同时看，就把左栏收起（已经做了这个状态），对话回到左边。
- **页面结构**：M398 只换了样式，「各页路由与页面结构都不动」；原型动的正是这两样。新增总览页；静态数据定义并入数据定义；出图记录与批次合成一个模块的两个页签。
- **一页一事**（同一份规格的第 200 行）：总览与速览都是在一页里并排放了几样东西。原型的取舍是列表页「一页一类对象」，总览是唯一的例外。
- **`Ctrl K`**：现在只开模块与常用动作、不搜对象（同上第 197 行），原型里能搜到数据集、模板、批次与资源。

## 哪些只是示意

- 只有 M402 这一份数据集的编辑页和「线路牌（单线路单方向）」的发布差异是做出来的；点别的对象进编辑，落到的还是这两页。
- 提示条里带「（示意）」的动作都没有做：新建、导入、迁移、上传、下载等。
- 线路牌与胸牌的图是引擎真渲染的（`imgs/`）；商品价签是手画的 SVG。数量、日期、人名全是编的，彼此对得上（各模板本月出图之和等于 12,480）。
- 进行中的批次每 4 秒走一格，走完会提示；这是页面里的定时器。截图是停住的一帧，梭子、弧线这些要在浏览器里打开才看得到在动。
- 模板设计页不在范围内，它有自己的方案（[template-design-v3](../template-design-v3/README.md)）。
- 窄于 1280 px 的窗口没有处理。

## 未定事项

以下是推断，没有对着服务端代码核过：

- 总览的「等你处理」与「流水总表」、左栏的数量，需要按租户聚合的只读数据；进行中的批次现在只数本标签页提交的（`CONTEXT.md:60`），要租户范围得加只读的批次列表端点。
- 数据集账页里的最近出图小样、出图记录图墙，需要能按出图记录取缩略图。
- `Ctrl K` 搜对象需要一个跨模块的查找接口，或者前端拉全量后本地筛。
