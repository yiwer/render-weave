# RenderWeave 桌面工作台原型（阶段 5 设计稿）

阶段 5 的界面方向：SaaS 桌面端从登录、Agent 任务到出图与管理的整套页面。设计稿在 claude.ai 的设计画布上做，本目录是 2026-10-28 从画布导出的副本：画布当时的版本号是 1793238138-b283，画板文件与第 36 版逐字节相同。

原型只作讨论，不作实现基础。据它定下的决定是 M341（桌面薄壳）、M342（模块上下文对话）与 P1 的 M343–M348，见[需求探索记录](../../discovery/requirements.md)与[路线图](../../roadmap.md#阶段-5-的分段2026-10-27)；P1 的票据按画板编号引用这里（[P1 索引](../../../.scratch/authoring-api-and-pages/README.md)）。分支 `prototype/desktop-workbench` 保留第 24–36 版的存档历史。

## 看稿

三种方式，按方便程度排：

1. **截图**：`screenshots/` 里每张画板一张 PNG，按画布尺寸（1440 宽，故事地图 1920×1800）、"减少动态"下截取，动画停在终态、登录视频停在封面帧。不需要任何运行时。
2. **本地离线渲染**（可交互）：画板要靠画布运行时 `canvas/project/support.js` 渲染。它是 Claude Design 平台的代码（画布类型的 `artifact-type/dc-runtime.js`），不入库，见 `.gitignore`。有画布访问权限时，用 Claude Code 的 Artifact 工具读这个路径存成 `canvas/project/support.js`，然后：

   ```bash
   python -m http.server 8766 --bind 127.0.0.1 --directory docs/prototypes/desktop-workbench/canvas
   ```

   打开 <http://127.0.0.1:8766/index.html>。`frame.html?p=project/Workbench.dc.html&w=1440&h=900` 把一张画板按窗口缩放显示，适合小窗口。
3. **画布原件**：<https://claude.ai/artifact/5RVeWVCUD3yuaxwSVBXXkM>（私有，需要所有者分享）。

画布改了之后重新导出：用 Artifact 工具读 `project/*.dc.html` 与 `project/canvas.json` 覆盖 `canvas/project/`，再跑 `node docs/prototypes/desktop-workbench/screenshots.mjs` 重截截图（要 `support.js`、`service/` 的依赖与环境变量 `RW_BROWSER` 指向 Edge 或 Chrome，同控制台的浏览器用例）。

## 外壳

除登录页和故事地图外，每张画板都内联同一套外壳，没有侧边导航：

- **标题栏**（吸顶）：应用菜单（点标志展开：新建任务 Ctrl+N、打开本地工作区、新窗口、导出到文件夹、设置、退出）、"搜索或执行命令"框（Ctrl K，窗口窄于 1180px 时隐藏）、**模块下拉**、租户切换、通知、窗口按钮。
- **模块下拉**（标题栏右上角）：按设计（工作台、数据定义、模板）、出图（数据集、出图）、租户（资源、用量、管理）分组，Ctrl+1…8，带待处理角标。平台管理换成租户、套餐、代建令牌、服务状态、跨租户审计五个分区。
- **左栏 Agent**（380px，吸顶，滚动页面时不动）：
  - 顶部是 Agent 与当前上下文，可看任务历史、开新对话；
  - 中间是这一页的对话，Agent 的回复里可带工具调用和跳转；
  - 下面是两条建议操作，底部输入框能拖入文件、@ 元素、选模型、Ctrl Enter 发送。
  - 工作台本身就是左对话、右预览，不再另加左栏。
- **右侧模块**：页面内容。同一模块内用下划线页签切换，比如数据定义 ↔ 发布记录、批次 ↔ 出图记录。
- **窄窗口**（小于 1000px）：左栏变成抽屉，左下角有"Agent"浮动按钮，点开从左侧滑出，抽屉里有"收起"。
- **状态栏**（吸底）：连接状态、本地工作区同步状态，后台的 Agent 轮次与批次进度，点击可跳转。
- **桌面特性**：从桌面拖入文件、系统文件对话框、系统通知、右键菜单、在新窗口中预览、快捷键提示。哪些由桌面薄壳承担、哪些网页就能做，见 M341。

应用菜单、模块下拉、任务切换、新建下拉用的是 `<details>`，窄窗口抽屉用一个隐藏的复选框加 `:has()`，都不需要脚本。

## 视觉

咖啡色调，第 29 版按用户意见拉高对比度：深色往咖啡红靠，浅色往米纸靠并更白一些，另加一个调和色。卡片与输入框保持纯白，在米纸底上边缘更清楚。控制台的新框架（P1 票据 01）用的就是这套色板。

| 用途 | 颜色 |
|---|---|
| 正文 | `#22150F` |
| 次要文字 | `#5B4334`（对页面底 8.84） |
| 更弱的说明 | `#7F6A59`（4.94） |
| 强调：主按钮、链接、选中 | 咖啡红 `#8E3B24`，按下 / 悬停 `#722B18` |
| 调和色：标志、执行中织梭、进度条、滑块与复选框、选中页签下划线、画布选中框、通知红点、审核来源框 | `#F17D13`，即 rgb(241, 125, 19) |
| 页面底色 | 近白米纸 `#FDFBF6` |
| 标题栏、左栏、状态栏 | `#F5EFE4` |
| 浅底：选中行、分段控件 / 缩略图台面 | `#F6EDDF` / `#F3ECE0` |
| 细线 / 输入框边框 | `#D9C8B0`（1.58）/ `#BFAA8E`（2.17） |
| 状态 | 成功 `#2E7D4F`、提示 `#B45309`、严重 `#C62A1E` |

括号里是对页面底色的对比度。调和橙配白字只有 2.73，达不到正文要求的 4.5，所以只放在不承载文字的位置；画布选中框上的元素标签用深色字（6.5）。客户产品本身的颜色不跟着改：线路牌仍是蓝色，价签仍是黑字配红色促销价。

简洁的做法：

- 一页只做一件事。不拼"表格加右侧预览""主区加右侧卡片栏""一排统计卡片"；选中某一行时，细节在这一行下面原地展开。模板设计右侧的检查器是编辑工具，保留。
- 不用框，用细分隔线分组；状态用圆点加文字，不用彩色胶囊。
- 实心主按钮只给这一页最要紧的动作；次要操作用描边按钮或纯文字链接。
- 说明性的长句收成页尾一行浅色小字。
- 预览类内容（线路牌、价签、资源图标）放在暖灰台面上，给一点投影，让它成为这一页的主体。

## 做原型时发现的事

- **运行时怎么读标记**：画布运行时先用 HTML 解析器读标记，再交给 React。`muted`、`loop` 会变成布尔属性；`autoplay`、`playsinline` 原样作为属性落到 DOM。静音自动播放能用。
- **事件名靠映射表**：运行时把小写的 `onclick`、`oncontextmenu`、`ondragenter`、`ondragover`、`ondragleave` 等映射成 React 事件；不在表里的按首字母大写处理，`ondrop` 正好得到 `onDrop`。拖放、右键、双击都能在画板里真实使用。
- **只能用 CSS 动画**：SMIL 的 `<animate>`、`<set>` 会被运行时过滤掉。
- **`stroke-dashoffset` 两端单位要一致**：从 `6` 到 `calc(var(--len) * -1)` 不会插值，只在半程跳变；写成 `6px` 到 `calc(var(--len) * -1px)` 才连续。
- **固定宽度的栏要锁住最大宽度**：左栏只写 `flex:0 0 380px` 时，里面不换行的内容会把它撑到 396–429px；要同时写 `width` 与 `max-width`。
- **弹性容器里的"文字加变量"会被拆开**：运行时把 `{{…}}` 前后的文字拆成独立的文本节点。放进带 `gap` 的 `display:flex` 容器时，每段文字都成了单独的弹性项，中间多出间距。整句要再包一层 `<span>`。
- **SVG 几何属性里不能放变量**：`<path d="{{t.icon}}">` 能画出图标，但浏览器在运行时填值之前先解析一遍标记，会在控制台报 `Expected moveto path command`。图标要写成固定路径，按类型用 `<sc-if>` 选一个。
- **循环里能读到外层的值**：`<sc-for>` 里写 `{{mini}}` 这类外层字段也能取到，不必每项都带一份。
- **在小面板里看 1440 宽的画板**：内置浏览器面板的截图最大只有面板大小，模拟 1440 视口也只截到左上角；CSS `zoom` 也不行，因为 `vh` 不跟着缩放。办法是 `canvas/frame.html`：放一个 1440×900 的 iframe，再按窗口宽度 `transform: scale` 缩小。
- **后台面板会冻住动画**：内置浏览器面板在后台时，动画与过渡的时钟几乎不走，截图可能是旧帧，真实右键也可能落不到元素上。核对动画要用 Web Animations 接口暂停动画、拨到指定时刻再读计算样式；核对右键、拖放就直接派发事件。`screenshots.mjs` 用无头浏览器加"减少动态"截图，不受这一条影响。
- **画板高度要跟内容**：页面根节点是 `min-height:100vh`，内容比画板高时会在画布上被截断；各画板高度按 1440 宽实测的内容高度设。
- **窄屏核对要加 viewport meta**：画板没有 viewport meta，窄屏由画布自己处理。本地按手机宽度核对时，要临时加上。
