## Standards

初审 2 项，复核均已解决。

1. **P2，判断性异味 Duplicated Code**：固定值与参数重复实现日期检查，前者仅检查正则，导致 `2026-02-31` 在派生变量中无问题出图。`src/template/check.ts` 现共用 `checkParameterValue`，公开渲染入口回归验证非法 date/datetime 均拒绝。
2. **P3，硬性违反测试接缝**：`test/svg.test.ts` 直接断言内部 `sanitizeSvg(...).xml`，违反规格“不测试内部函数、中间数据结构或私有模块”。现从渲染入口验证图片、问题清单、局部引用和嵌套 SVG 的实际行为；CSS 与局部引用使用不重叠画面区域。

## Spec

初审 3 项，复核均已解决；没有把未计划能力列为首期缺陷。

1. **P1，非法枚举导致异常退出**：`in` 误接收 `constructor` 等原型属性。运算及元素类型改为自有属性检查；同类必填参数也使用自有属性判断，避免空请求被误认为已传参。草稿、正式均返回问题清单。
2. **P1，加减运算溢出或丢失精度**：原实现将 `1e308 + 1e308` 转为 Infinity 后静默输出空文字，连续运算抛 BigInt 异常。现检查输入及十进制原文结果；不可表示时返回 `template.evaluationInvalid` 并按缺值处理。链式运算安全终止，草稿显示占位；子模板错误附实际调用路径。
3. **P2，动态网格越界产生 NaN**：行列或跨行列越界后仍索引轨道。现拒绝该位置、隐藏异常元素，保留元素问题；摘要不再产生 NaN/null，其他元素继续排版。

## 补充检测与修复

| 发现 | 修复及验证 |
|---|---|
| 发布忽略工作区读取、JSON 损坏或重复记录问题，误报成功 | 分离文档读取与资源加载；发布检查工作区问题，历史不完整则停止；空目录首版发布仍可用 |
| 发布直接覆盖已有定义或编译产物；并发写同路径均成功 | `wx` 排他创建两个目标，可捕获失败撤回本次创建的文件；分别测试两个文件冲突及并发胜者唯一 |
| 发布用普通 JSON.parse，原始超过 15 位的数值可被舍入后误收 | 复用保留数字原文的解析入口，在失真前拒绝 |
| 输出 I/O 错误抛未处理异常 | CLI 返回失败码与中文原因；原有文件保留 |
| 请求文件损坏时留下上次图片与摘要 | 调用开始即清除四个固定成果文件；坏请求返回 2，不留下旧成果 |
| `MakeSurface` 的像素缓冲区持续泄漏 | 绘制 finally 使用 `surface.dispose()`，同步修正 golden 辅助画板的释放 |

内存问题已从实测定位到依赖实现：CanvasKit 0.42.0 的 `bin/full/canvaskit.js:9–11` 为软件画板额外 malloc，`dispose()` 释放该缓冲区再 `delete()`；其 `types/index.d.ts:3022–3026` 明确说明释放额外内存。

修复前，5 次预热后至 30 次串行结束 RSS 从 **267 增至 703 MiB**；同场景修复后为 **249 → 333 MiB**，Linux 为 **228 → 247 MiB**。图片及摘要哈希未改变。稳定性脚本设预热后串行 RSS 增长小于 256 MiB 的回归门槛，用于捕获本次每图约 10.4 MiB 的泄漏；这是短程回归门槛，不是长期内存上限。

进一步运行 `node scripts/accept-stage1.mjs out/stage1/windows-100 100`：5 次预热、100 次串行及 4 次并发全部通过，串行 RSS **255 → 352 MiB**，并发后 386 MiB；串行中位数 449 ms、P95 572 ms。未重现原先随图片数量持续增长的像素缓冲泄漏。

## DSL 当前可承载的能力

| 领域 | 已实现 | 当前边界 |
|---|---|---|
| 数据 | 文本、数值、日期、时刻、时间、布尔、图片、列表、数据定义引用；约束、静态版本、JSON Schema 编译与校验 | 引用必须确切版本，列表项不能直接为列表；数值限 15 位有效数字 |
| 元素 | 画板、容器、循环容器、子模板调用、文本、图片及矩形/椭圆/线条/多边形/路径 | 共 11 类（含画板）；二维码、条形码尚未实现 |
| 布局 | 自由、横纵堆叠、网格；固定/随内容/填满、比例分配、边距、跨格、裁剪、旋转、透明度 | 循环容器当前只横向排列；不是任意约束求解器 |
| 变量与规则 | 对外/内部参数、绑定、条件显示、状态样式、检查项；分支、取项、长度、加减；独立调用作用域 | 单步运算按名称组合，无文本表达式、脚本、动态模板或任意函数 |
| 循环与道路 | 等分/按内容/固定宽，序号与首末信息，相邻同值合并、按组内项数跨原始列 | 不支持过滤、反序、前后附加项；按原始列跨宽需等分列 |
| 文本 | 横排/竖排、片段与格式、倾斜描边、两端/同间隔分布、压缩、缩字组、按字重逐字替代 | 单行；无段落换行、复杂文字塑形或完整双向排版；竖排片段样式受限，倾斜用于横排 |
| 图片与字体 | PNG/JPEG/WebP/SVG 输入，contain/cover/fill；显式 TTF/OTF 资源、后备字体、SVG 字体 | 模板图片使用 res 引用；URL 图片出图、系统字体、SVG 脚本及外部依赖不支持 |
| 渲染与诊断 | PNG/JPEG、DPI 元数据、草稿占位/问题框、正式阻断、布局摘要、稳定问题码与位置 | 输出单边 20,000 px、总数 1 亿像素上限；上限并非建议负载 |

可执行语法以 [共享 M402 DSL](examples/m402-dsl/README.md)、解析器和入口测试为准；[模板元素模型](model/template-elements.md) 包含未来能力，不能整体当作当前支持清单。
