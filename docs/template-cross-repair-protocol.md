# 跨模板区域反馈：事前登记

本轮修正正在用于反馈与停止的实验测量器，再做两个新模板的真实 Haiku 5.5 对照。template-design 已有显式逐片段的产品样式核查；上一轮探针所测 64d7bae 的 style-verification 属另一检出，本轮不把旧实现或正在修改的主检出整体移入。没有改动生产 MCP/默认资料。

## 修正口径

从受控正例真实布局建立非空、唯一的文本/图片元素清单。路径稳定作为局部修复约束，两臂均要求保留元素名称。逐元素匹配内容/资源；逐字符对齐片段后比较字号与颜色，不用父字号或角色平均掩盖异常；每个元素比较布局框中心与尺寸。缺项、歧义、未知、无布局均不能停止；不从框高推字号，墨迹框不与布局框混比，不根据参数或空画板推断业务状态覆盖。

参考来自维护中的模板，范围明确为布局证据，不是任意 PNG 自动真值。位置阈值为单元素归一化中心距离≤0.005，字号及尺寸逐项对数误差≤ln1.1，文字/图片引用/颜色一致；新指标比上一轮更细，不能把跨批次分数变化解释为模型进步。绘制层次、遮挡、裁切、透明度、装饰容器和最终墨迹仍不由这些检查证明。

各模板×role/region×2次重复，共8单元16轮。每单元固定两轮，每轮 maxTurns=20，主/小模型 claude-haiku-5-5；串行、交叉顺序，计时期间不跑测试/编译/其他模型。使用用户级 OPEN_CODE_API_KEY，仅传环境。

role 每角色选一条，重复实例共享去掉序号的路径角色；region 另按事前命名区域去重。价签区域：抬头、价格、页脚、卖点行；胸牌区域：页眉、信息、场次列、标签行，其他角色独立。两臂文案、排序一致：内容→字号→位置→尺寸→颜色，再按严重程度/ID；最多两条、1200字符。区域表示参考分组，不声称证明候选错误根因。

## 停止、复跑与接入条件

首轮后先持久化停止决定，绑定候选与评分哈希及时间；要求技术 qualified、固定预期 ID 集完整、全部检查通过且无 unknown/missing。第二轮仍真实执行为影子续跑；停止策略只取实际调用前缀，单列它与固定预算的覆盖率/分母。这不是独立随机停止臂。

不按模型效果更换坏例或重试质量失败；额度/基础设施错误停止派发。全样本与成对可测样本分别汇总，未知不记零缺陷。原始目标、新增失败（相对初始）、回退（首轮到次轮）、全检查、上下文峰值、wallMs 分开报告；像素指标仅附件。
