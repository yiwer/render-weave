# 跨模板反馈与停止策略实测

建议正式接入“有核准参考时的区域去重短反馈 + 完整检查通过后停止自动续修”，作为可选策略；不把区域去重单独设为默认，也不把像素分数设为验收门槛。跨模板实测支持更早覆盖两个受损区域，但固定两轮的平均峰值和耗时反而增加。事前登记见 [协议](template-cross-repair-protocol.md)，冻结输入为 `d7ae834`、`out/cross-repair-live`；2026-10-22 23:31 PDT 开始、10-23 00:11 PDT 完成，使用 User 环境的 OPEN_CODE_API_KEY，主/小模型均 claude-haiku-5-5。

## 测量语义

上一轮发现的旧 style-verification 问题属于固定主检出 64d7bae。template-design 现有生产核查已逐片段检查显式字号，没有从参考框高推字号；本轮不合并活动主检出，修正的是实际用于实验反馈和停止的评分器。

| 判据 | 本轮采用的语义 | 反例验证 |
|---|---|---|
| 覆盖 | 非空参考清单，逐路径匹配文本/图片，缺项、额外项、歧义均不通过 | 空画板、无布局、重复路径、额外文字 |
| 字号与颜色 | 对齐实际文字后逐字符比较片段值，不用父字号或角色均值 | 父8 mm、一个片段5 mm检出；改变DPI不改毫米结论 |
| 位置与尺寸 | 每个元素的布局框中心及宽高分别比较 | 单个元素偏移检出；墨迹框标为未知 |
| 未核准信息 | 未知不能通过，不从含留白的标注框推字号 | 50×20 mm框不推19 mm字号；unknown即使误带pass=true仍不能停 |
| 停止 | 技术交回有效、预期检查集完整、候选及评分绑定、全部通过 | 首轮先持久化决定，再执行固定第二轮 |

这些检查只覆盖登记的文本/图片布局证据。装饰容器、遮挡、裁切、透明度、最终墨迹和人工偏好仍需单独审核；本轮使用维护模板的受控参考，不声称从任意 PNG 自动得到真值。检查粒度改变，不能将本批分数与旧批分数直接解释为模型进步。

## 实验设计

商品价签与会议胸牌各设置两个区域位置退化；每模板×两臂×两次重复，共8单元，每单元固定两轮、每轮maxTurns=20。role按角色选择，region按事前登记区域去重；反馈排序、最多两条、1200字符上限一致。串行交叉顺序执行，计时期间不运行测试、构建或其他模型；不因质量失败重试或换样。

价签原请求107项检查，胸牌187项；每种模板还包含一个改数据变体和一个状态/参数变体。变体检查内容、片段字号、颜色与出图，不检查变体几何。正确DSL只留在宿主评分目录，Agent收到相同坏模板、StaticSchema、数据集、参考图与有界差异。两条反馈来自原请求；改数据与状态/参数变体只作独立回归，没有把变体正确答案交给Agent。

峰值按每请求有效输入（input + cache read + cache creation）取最大值，再按单元汇总；wallMs为模型运行时间，两轮相加，不含宿主离线评分。全样本保留未知，成对可测集合要求双方同模板同重复的质量/成本均可测。

## 真实结果

证据：[交互对照](agent-eval/figures/template-cross-repair/index.html)、[逐轮报告](agent-eval/figures/template-cross-repair/report.json)、[独立审计](agent-eval/figures/template-cross-repair/audit.json)。8单元16轮全部完成，169次模型请求；无额度/基础设施中断、无未知结果，全样本与成对可测分母一致。实际执行总模型耗时2366.292秒（39.44分钟），包括全部影子续跑。

| 相同固定两轮预算 | 角色反馈（改前） | 区域去重（改后） |
|---|---:|---:|
| 首轮目标修复 | 5/8（62.5%） | 8/8（100%） |
| 首轮全检查通过单元 | 1/4 | 4/4 |
| 两轮后目标修复 | 8/8 | 8/8 |
| 两轮后全检查通过单元 | 4/4 | 4/4 |
| 新增失败项 / 轮间回退项 | 0 / 0 | 0 / 0 |
| 单元平均上下文峰值 | 33,272.25 tokens | 42,641.75 tokens（+28.2%） |
| 最大上下文峰值 | 35,104 tokens | 56,588 tokens |
| 单元平均模型耗时 | 265.864秒（4.43分钟） | 325.709秒（5.43分钟，+22.5%） |

区域反馈提升的是本批首轮覆盖效率，最终效果在两轮预算内被角色反馈追平。两次价签角色组首轮都只修价格区；第一次胸牌角色组首轮只修信息区；第二次胸牌角色组自行发现标签区并一次修好，是不能把区域去重说成必要条件的反例。

| 分模板 | 首轮角色 / 区域修复 | 固定两轮平均秒数：角色 / 区域 | 各自按停止决定的平均秒数：角色 / 区域 |

耗时收益方向在固定两轮中并不一致；价签角色组两次总耗时112.888与420.923秒，波动很大。每模板每臂只有两次，不作统计显著性或稳定线上延迟的结论。峰值也不能跨本批与旧M402批次解释为harness进步，因为模板复杂度、评分粒度均不同。

### 停止决定与影子续跑

四个区域组和一个角色组首轮登记stop=true，均早于第二轮启动并绑定实际候选/评分哈希。五次影子续跑没有增加登记范围内的修复收益，也没有回退；额外模型耗时937.402秒。所有第二轮均实际执行，没有中途调整修改预算。

## 接入判断

1. **接入有条件的区域去重短反馈。** 有核准区域、至少两个区域受损时，最多两条优先覆盖不同区域；排序和完整证据仍由宿主保存。两种模板首轮修复率均改善且未新增缺陷，支持此范围的可选策略。不要因为平均分好看就无条件开启。
2. **同时接入完整检查后的宿主停止。** 本批冗余续跑是更确定的成本来源；缺项/unknown/技术交回失败/候选变化均不能满足停止。停止表示已登记范围无需自动续修，保留人工审核。
3. **保留本轮逐元素/片段测量与追溯。** 非空参考清单、实际请求和数据变体、候选及评分指纹、事先登记决定、全样本未知和成对可测分母，作为接入前的回归合同。
4. **暂不引入新MCP、OCR、LPIPS/FLIP默认调用或更大的核心上下文。** 本批未验证这些新增成本的收益，也未验证遮挡、裁切、装饰和任意PNG参考清单自动生成。

落点是现有check_outcome的可选核查摘要/按区域详情和宿主续修控制，复用工具，不扩充常驻核心。本轮提交只修改实验测量、报告和证据；生产MCP、默认上下文及其他检出的ticket33–35保持原有状态。

接入边界：核准区域和参考清单属于宿主输入，短反馈仍按需提供，完整证据留在宿主/按区域读取。自动停止只结束同一目标的自动续修，不替代人的视觉审核；用户新增目标、改变参考或数据时必须重新核查。无核准参考、未匹配项或未知状态时不启用成功停止。
