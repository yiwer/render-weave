## 哪些行为真正发生了

- 四个任务的六次启动都读取纠偏指导，个人 skills 均为 `[]`，13 个工具、仅 rw MCP 连接；未注入个人编码 skills。
- 两个无阈值任务各有 4 个有效检查点。第 1 次仅一次按 `designTarget=service` 读取完整区域证据；完整候选第一次核查到最终核查没有变化。第 2 次实际把服务主行字号从 8 改为 10 mm，SSIM 从 0.55739 降至 0.55660，另扩被调模板尺寸范围处理边界。
- 交接 1：停止轮 299,153 ms / 峰值 60,068，没有检查点；恢复轮 126,308 ms / 峰值 65,457。接续时将服务主行 8→10 mm、框高 9→11 mm，随后恢复原候选，SSIM 0.56608→0.56163→0.56608。详细自述提到像素及自行看图判断；哈希证实改动与回退，但自述不能代替人类视觉验收。
- 交接 2：停止轮 172,483 ms / 峰值 67,355，触发观测值 65,315；恢复轮 281,604 ms / 峰值 91,444。`docs/handoff.md` 确实恢复了与骨架候选绑定的进度、剩余内容及下一步。停止时没有详细视觉记录，因此没有可恢复的详细记录；其恢复路径由自动化测试验证，不能算作真实模型已覆盖。
- 四个最终模板均有有效检查点，只有交接 1 最终写了详细视觉记录；两次纠偏上限属于指导，宿主没有强制计数。DSL 虽按需提供，第 1 次仍把九章全部读入，说明渐进式披露不能保证模型选择性阅读。

五区均值也有得失：无阈值的 header / next-stop SSIM 从 0.57753 / 0.66536 升至 0.65599 / 0.74894；service 从 0.55627 降至 0.47358。交接 service 从 0.51402 降至 0.47755。所有区域均保留在原始对照中。

离线元素补测给出更具体的变化：四个新候选都匹配 35 站、17 时刻、9 个站点地标；三份匹配下一站地标，交接 1 未匹配。旧 P1 四份均未匹配下一站地标。这个结果只覆盖独立显示契约和布局证据，不证明最终像素可见或整体还原通过，详见[新评判实验](template-fidelity-experiment-results.md)。

## 已确认的测量边界

- 像素分数不能替代内容完整性。新无阈值第 1 次的占位骨架 SSIM 为 0.6901，填完信息后为 0.5544；空白接近背景即可获得高分，不能把骨架与完整模板的变化解释成视觉退步。真正局部纠偏前后的比较须在同等内容完成度上进行。
- 检查点是自述与候选的绑定，不是语义证据。该次骨架摘要声称“30 站”，输入数据集实际为 35 站；交接应继续读取原数据与要求。
- 指导不等于执行。该次读取了全部九个 DSL 章节，调用一次 service 命名区域诊断；从完整候选首个核查到最终核查，候选指纹与分数没有变化，也没有写视觉详细记录。有效进度保存和真正视觉纠偏须分开计数。
- 五个区域目标全部为 proposed，styles 仍为空；此次没有新增已经人工核准的字号/颜色硬门槛。个人 skills 仍禁用，真实启动日志为 `skills: []`。
- 耗时不能全归因于新指导。第 1 次 M402 数据定义输出从旧 P1 的 37,330 降至 30,123 tokens，耗时却从 228,199 升至 424,239 ms；366 定义也从 55,402 降至 36,119 tokens，耗时从 428,777 升至 691,702 ms。这些提取任务没有注入模板纠偏指导；推断本批服务速度/请求等待有变化，但不是同时随机对照，无法分离其贡献。

## 可复现路径

完整门槛使用 Haiku 5.5 主/小模型、`jobs=1`、`--repeat 2` 与 `scripts/agent-eval/scenarios/m402/design-targets.json`，原始目录为 `out/refinement-live`。每个启动子进程显式从 Windows User 读取 OPEN_CODE_API_KEY，密钥不落盘。所有候选按 `scripts/verify-template-design.mjs` 重放，同一 SSIM/RGB 算法、采样和边界案例；两次交接使用 `scripts/agent-handoff-eval.mjs`，各自新建任务到 60,000 后仅接续一次。

已执行命令：

```powershell
npx tsx scripts/agent-eval/run.ts --repeat 2 --jobs 1 --model claude-haiku-5-5 --small-model claude-haiku-5-5 --key-env OPEN_CODE_API_KEY --design-checks scripts/agent-eval/scenarios/m402/design-targets.json --label template-design-refinement --out out/refinement-live --reports out/reports
node scripts/agent-handoff-eval.mjs --baseline out/refinement-live/run-1/m402-template/template --limit 60000 --out out/refinement-handoff-1
node scripts/agent-handoff-eval.mjs --baseline out/refinement-live/run-2/m402-template/template --limit 60000 --out out/refinement-handoff-2
```

报告中的 trace 是真实工具日志的提炼，未保存凭据。可视化页在 1440 / 390 宽度验证 8 个候选和 80 次区域选择，无脚本或图片错误。离线重放和测试在真实计时之外完成。
