# 模板还原质量评判：从像素均值转向内容与结构

2026-10-22。下文保留完整架构方向；内容匹配、受控布局/字号偏差、跨输入回归与 FLIP 局部诊断已完成离线试验，见[实测结果](template-fidelity-experiment-results.md)。生产门槛、遮挡/墨迹证据与人类盲评尚未实现；本试验没有改变 `2d8d7d0` 真实批次的运行语义或登记口径。

## 判断与证据

用“内容正确门槛 + 分维度还原证据 + 盲测成对偏好”作为主评判，SSIM/RGB 保留为定位差异的辅助指标。目前不设任意加权总分，不把 SSIM 换成另一个单一相似度就宣称解决问题。

本项目反例：本批无阈值第 1 次只有五个区域占位矩形时 SSIM 为 0.6901，完整模板为 0.5544。背景相似可以掩盖信息缺失；而当前技术 qualified / 八个边界通过也没有完整信息覆盖的保证。原始证据在 `out/refinement-live/run-1/m402-template/template/logs/stream.jsonl`、`logs/tools.jsonl`。提炼记录见[本批结果](template-design-refinement-results.md)。

相关研究支持拆维度的思路，而不直接给本项目验收线：

- [SSIM 原论文](https://www.cns.nyu.edu/pub/eero/wang03-reprint.pdf)评估参考图像的结构退化，实验包含 JPEG/JPEG2000 压缩失真；没有验证它可代表模板内容完整性。
- [Design2Code](https://arxiv.org/html/2403.03163v2#S2.SS3)分别测视觉块匹配、文本、位置、颜色和高层视觉特征，并用人工成对比较核对自动指标。它还区分“更像原稿”和“设计更好”，二者不能混成一个目标。
- [LPIPS](https://richzhang.github.io/PerceptualSimilarity/)在其人类感知数据集上优于传统指标。这是可试验的区域感知指标，不是中文站牌文字、布局与可读性的已验证裁判。

## 四层评判

| 层 | 核查对象 | 证据与结果 | 防止的误判 |
|---|---|---|---|
| 1 内容与可用性门槛 | 本次应显示的站点、顺序、状态、线路号、下一站、时间、必要图标；溢出和不可读 | 从提供的数据集、参数和显示契约得到预期；与实际渲染内容、数量、顺序、可见性比较，报告缺失/重复/错误 | 空骨架、漏字、把字缩得极小、被遮挡也拿高分 |
| 2 结构与文字还原 | 五大区域位置/尺寸、边距/对齐/间隔、站名密度、主次字号比例、文字方向、基线、图标占比 | 参考图的核准视觉标注，对照候选实际布局与墨迹；按语义角色匹配，记录归一化位置误差、尺寸比例误差和违规项 | 元素都在，但挤错区域、层级颠倒、底栏像脚注 |
| 3 局部外观诊断 | 颜色、线条、圆角、字形密度、边缘、局部形状 | 命名区域与内容区域分别比较；保留 SSIM/RGB、前景/边缘诊断；有校准集后再试 LPIPS | 大背景按面积淹没关键文字，小的字体替代造成整图分数误导 |
| 4 整体感知排序 | 在内容达标前提下，哪张更像参考、主要差异是什么 | 参考图 + 匿名 A/B，同尺度整图与局部；独立会话盲评 win/tie/lose，要求坐标和具体差异；抽样由人复核 | 用一个未经校准的模型自评分替代视觉验收 |

内容门槛优先于排序。未通过或证据不足的候选分别标记失败/待核查，不让空白候选靠其他分数补偿；这些状态也须在结果中保留，不能因不参加通过组排名而消失。

“还原度”和“设计质量”分列。原稿的字体拥挤等问题若被主动改善，可能提高可读性却降低还原度；须依据项目允许的改动目标判断，不能由评审模型自行换目标。

## 利用本平台已有的信息

业务内容继续来自已有 StaticSchema、示例数据集和请求参数，不从参考图重提一份业务数据。显示契约声明哪些字段在什么状态必须出现；不是要求把 Schema 所有字段都画出来。参考图仅提供视觉角色、区域与层级；参考图和示例数据不同的项目，内容按数据集核查，结构按归一化布局与关系核查，不惩罚合法的文本长度变化。

候选侧优先读引擎证据。`src/layout/types.ts` 已暴露实际布局框、文本片段、字号、颜色与可见标记；`src/agent/design-verification.ts` 已能核查声明的框和字号范围。这比对渲染图再次 OCR 更直接。需要补的内容是独立的显示契约、语义角色匹配，以及可见文本与数据来源的对应关系。

当前 layout.visible 不足以证明没有遮挡、裁切或几乎不可见；尺寸框也不是文字墨迹框，尤其竖排、旋转及字体替代时。相关检查应明确“已测/未覆盖”，不能把源字符串出现当成已正确显示。文字基线和墨迹目标须按统一尺度比较；原图像素高度不可直接作为 fontSize。

参考侧先对 M402 的五个区域做一次少量标注，记录区域、视觉角色、相对位置、层级和允许偏差，保持 proposed/approved。不能让生成模板的 Agent 自己声明缺失元素“不需要显示”，也不能让它根据当前候选反向修改验收线。不同模板的节点名称可能不同，匹配不能只依赖作者起的路径名。

## 先校准裁判，再用它优化 Agent

先用已保存候选和受控坏例离线验证，不新增一整批生成任务：

1. 留下完整原候选，另外制作空骨架、少一个站、遗漏时刻、颠倒站序、主标题过小、底栏挤出、合法字体替代、整体平移等对照。坏例由脚本变更 DSL 并经现有引擎渲染，保持数据与请求可追溯。另以同一候选改站名、顺序、currentIndex 和可选徽标，验证跨数据行为，识别把示例值写死的模板。
2. 先验证少内容、重复内容、错误状态不能通过门槛；再验证对齐/层级恶化时相应维度单调变差。分离内容缺失和视觉轻微差异的影响。
3. 用一小组成对样本做人类校准；盲评隐藏版本、耗时和 token 标签，A/B 换序复测，允许平局与证据不足。独立评审同时拿到显示契约与允许变化清单，避免把合法的数据差异重新当成还原错误。自动评审在独立上下文里运行，不能读生成过程的自我解释。模型评分暂不充当硬审批；若仍使用同一模型家族，也要承认共同盲点。
4. 把未参与校准的候选作为留出集，检查排序是否与人一致。通过后才决定是否引入 LPIPS、区域权重或综合分；样本不足时继续报告分维度结果，不输出貌似精确的“还原度 92%”。

区域权重若需要，应由业务重要性和显著程度确定，而非简单按像素面积。线路号、站名、下一站等小而关键的信息不能被背景补偿；权重、阈值和评估版本须固定并留痕。

## 与 harness 的衔接

生成和评判分开：生成器拿当前阶段需要的资料，评判器返回最多两项高优先级差异，包含“区域/角色、参考与当前证据、误差、影响、候选路径”。详情继续按需取，不能把全套评审说明塞进任务核心。

停止条件按阶段区分：骨架只检查结构可运行；完整候选先过内容门槛，再进入视觉纠偏；纠偏预算内保留对照并复核内容没有退步。是否真的改了候选、是否复查及记录进度，由宿主比较候选指纹和工具证据，不能只靠 state 自述。

推荐实施顺序：先补内容门槛与坏例校准，再补结构/文字指标和独立盲评；最后评估深度感知指标是否还有增益。当前真实批次继续按原协议归档，新增指标另起版本，对同一批历史候选补测，避免改标尺后制造“优化成功”。
