# 对外部视觉评判调研的取舍与实验

2026-10-22。结论：采用元素级证据与宿主核查闭环；把 FLIP 放在可选的区域定位层。绘制掩码、OCR、LPIPS 由已知盲点驱动，不同时堆进业务 Agent 上下文。

用户提供的报告是 `F:/GenCode/render-weave/docs/research/2026-10-22-template-visual-fidelity-harness.md`，其源码基线为 `33305e5`。本批运行分支是 `template-design`，实现冻结在 `2d8d7d0`。两者的当前能力不同：本分支已经有 SSIM/RGB、五个命名区域、按 `designTarget` 查询、候选绑定检查点与恢复交接；报告中“只有 437×98 RGB”描述的是旧评估入口，不能代表本分支全部能力。

## 采用顺序

| 建议 | 判断 | 本地验证与接入条件 |
|---|---|---|
| 固定参考清单 + 元素级评价 | 优先采用 | 数据集决定业务预期，参考图决定视觉角色；本次实测内容/数量/顺序、字号和位置。先分维度报告，五区目标继续是 proposed，不冒充人工核准。 |
| 复用布局摘要 | 优先采用 | 候选已有路径、实际文字、字号、框与资源 ID。未知的遮挡/墨迹单列。粗分区不能成为缺内容的硬条件；实测已用跨区正例纠正这类误报。 |
| 无错误框的诊断图 | 立即采用已有能力 | 对能正式出图的样本用 `render(..., mode: 'final')`，获得无草稿标记的图；严重问题无图就记 unavailable。暂不改引擎来强行输出受阻样本的干净图。 |
| 哈希绑定、复核修复和回退 | 优先采用 | 当前检查点已绑定候选。本批另核对实际编辑与前后 fingerprint，区分“读了指导”和“确实修改”。后续反馈要给出旧问题、已修复、新问题及仍未知。 |
| FLIP 局部误差热图 | 值得保留作实验附件 | 中文受控正例的 7 个局部变体均在预期区域得到最大均值，自身误差为零；不等于原图比较的根因定位或 Agent 修复率已提高。 |
| 新增 compare_reference 工具 | 暂不新增 | 复用 `check_outcome` 的设计诊断与按需详情入口，避免重复工具和上下文。先在离线报告校准输出，再讨论正式契约。 |
| DrawOp 来源与覆盖掩码 | 有明确失败案例再做 | 先用旋转、裁切、遮挡、透明混合构造测试，证明布局框无法定位；再补 instancePath 到绘制范围映射。它能解释已画出的内容，缺失元素仍依赖参考清单。 |
| OCR、LPIPS、视觉模型裁判 | 后置的独立实验 | OCR用于核对实际可见文字及参考位置，不重提已有业务数据；LPIPS与FLIP比较增量定位收益；视觉盲评须有人工校准与左右换序。当前尚无这三项的本地收益证据。 |

## 研究中值得借鉴的具体方法

[CANVAS](https://arxiv.org/html/2511.20737v2)先做一对一组件匹配，再看覆盖、位置、文本和颜色。借鉴的是匹配与分维度证据；其参考侧有设计结构，只有 PNG 的任务仍需建立参考清单。当前离线匹配使用内容与位置提示，没有实现论文的全局 Hungarian 匹配，重复内容跨角色仍是需要扩大校准的边界。

[Design2Code](https://arxiv.org/html/2403.03163v2#S2.SS3)把细粒度指标与整体外观、人类比较分开，适合本项目的验证层次；网页参考结构不能自动成为本项目图片的真值。

[Skia Debugger](https://skia.org/docs/dev/tools/debugger/)提供逐绘制命令、clip/matrix 和像素变化断点。它适合查绘制归因，并不提供“这个差异应该改哪条 DSL”的现成答案。对半透明覆盖也不能把最终像素简单归给最后画的节点。

[FLIP 官方实现](https://github.com/NVlabs/flip)可作为独立 Python/C++ 组件输出误差图。本次固定版本、67 PPD、白底合成与统一尺寸，依赖留在实验 venv；核心绘制与业务 Claude Code 不增加 Python 或模型裁判资料。

## 试验目前回答了什么

已验证的新指标能揭示漏站、倒序、少时刻、少地标、陌生文本，以及相同示例图下无法通过像素检查发现的硬编码。字号 10→5 mm 可由文字证据直接定位；位置偏差与内容匹配分开。

FLIP 在本次中文样本上将正例排在空骨架前面，但仍把空骨架排在若干已填充站名、时刻等主要内容的历史生成候选前面。这支持“局部诊断附件”的定位，不能据此升级为总质量门槛。另一个 Agent 的阿拉伯文实验含错误框与塑形问题，作为集成探针有用，不能代替这次中文、无草稿标记的校准。

下一项有价值的模型实验是固定坏例、相同 Haiku 模型和两次修订预算，对照“只看图”与“最多两项带角色/路径/差值的反馈”，测缺陷修复率、新增缺陷率、上下文峰值与时间。它需要独立登记；本批真实生成和交接结果不能冒充这一因果实验。

实测数值与复现入口见[离线试验报告](template-fidelity-experiment-results.md)；当前 harness 的真实对照见[区域纠偏结果](template-design-refinement-results.md)。
