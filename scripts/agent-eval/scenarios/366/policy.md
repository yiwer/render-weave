|---|---|
| `names` | 完全同名的出现至少 57/59 |
| `landmarks` | 地标命中至少 14/15 |
| `facilities` | 完整设施组命中至少 17/18 |

| `facilityExtra` | 最多 0 项设施误报 |

任何对齐歧义都要求复核，不能通过提高上限消除。评分器 `renderweave-transcription/3`、匹配政策 `ordered-occurrences/1` 的详细口径和报告字段见 [Agent 评估](../../../../docs/agent-eval.md#评分)。

命中容错允许少量错字、漏项、地标/设施漏报；不允许用插入、重复、反序或误报抵消。同名项按各自出现位置核对附属信息：A→B→A→C 合法，交换两个 A 的地标或设施仍是错误。每个候选出现及每个真值出现至多使用一次。

通过现有 CLI 的离线检查涵盖真值原序、反序、相邻交换、插入、超额重复、单字替换、单次漏项、同名项附属信息串位、额外信息、对齐歧义，以及缺少核准真值/政策的拒绝。此处是判据验收；固定候选下真实模型四场景观测归原票据 38，不能以受控候选替代。

同站出现正确地标后再带另一个地标或重复同值，仍逐项计入地标误报；图片列表中的全部地标引用也参与核对。评分器 /3 在匹配政策中记录 `landmarkReferences: all-occurrences-multiset`，站名对齐政策与既定门槛不变。旧报告保留，新判据另存评分结果。
