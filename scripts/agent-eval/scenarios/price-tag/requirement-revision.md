# 修改要求：价签首批交付后的两处调整

首批三张价签（饮用水、30 字品名、无会员价的咖啡豆）交付后发现两处问题，其余保持不变。

1. **无会员价时整格留空**：没有会员价的商品，现在会员价格里仍印着"会员价:"标签，只是没有数字，顾客会以为漏印了价格。没有会员价时，`商品价签/会员价标签` 也不显示，会员价格只留黄底。
2. **价格离右边线太近**：`商品价签/会员价` 印 ¥118.00 时，最后一个 0 几乎贴着会员价格的右边线；`商品价签/零售价` 同理。两个价格的文字离各自格子的右边线至少留 1 mm；四位整数的价格（如 ¥1288.00）也要放得下，放不下时先压缩字形，仍放不下再提示。
