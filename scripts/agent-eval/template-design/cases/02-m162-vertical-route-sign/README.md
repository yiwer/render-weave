## 考察点

竖排列表用纵向循环（M236），不要把横向循环旋转 90°；每行中英双语、站名带括号道路；本站整行高亮并标"本站"；设施图标 0–2 个右对齐；顶栏方向与底栏"下一站"由站点列表派生。

它与第三阶段真人走查用的 M162（`scripts/agent-eval/scenarios/m162/`，350 × 950 mm，21 站，示例图不进版本库）是同一条线路的另一版设计稿：版式相近，站数、尺寸与图标不同，所以另写专家数据定义，不复用那份材料。

## 专家数据定义

- `竖版线路牌 v1`：线路号、运营方标识（图片）、首末班、票制、最低与最高票价、监督电话、站点列表（2–20 站）。
- `竖版站点 v1`：站名、所在道路、英文站名、英文道路名、设施（文本枚举列表：地铁、医院、体育馆、火车站，最多 2 个）。
- 不存：方向（末站中英文）、下一站、本站（出图参数）。"分段收费 2-6元"拆成票制与两个票价数值。

## 数据集

`dataset-m162.json`：15 站逐行转录。顶栏写"High-Speed"、末站写"High-speed"，数据集按站点行的写法记一份，顶栏由末站派生，所以大小写与样图顶栏不同。

## 压测（草稿 30 DPI）

| 压测 | 为什么 |
|---|---|
| 15 站本站 2 | 示例请求本身 |
| 本站 0、本站 1、本站 15 | 不标本站、首站、末站时隐藏"下一站" |
| 2 站、20 站 | 目标范围的两端；20 站时行高最紧 |
| 长站名与长道路名、长英文名 | 一行放不下时压缩或缩字，不撑破行高 |
| 多站两个图标 | 图标区宽度随个数变化 |
| 没有英文与道路 | 可选字段为空时括号与英文行不残留 |

## 版面检查

16 项：顶栏线路号、方向（中英文，派生）、运营方标识、服务时间、票制；正文"本站"标记、英文站名、括号道路、体育馆与火车站图标在右侧；底栏下一站（中英文，派生）与监督电话；本站 0 时正文没有"本站"，本站 15 时没有"下一站"。

## 已知差异与取舍

- 样图本站行黄底，检查只看"本站"字样，不检查底色。
- 示例图上没有出现火车站以外的第四种设施，枚举值按项目说明给出。

## 通过线（tds-baseline-1 定稿，M337）

压测 10/10；版面检查至少 14/16。
