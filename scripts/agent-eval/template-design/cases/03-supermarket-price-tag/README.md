## 考察点

小尺寸标签的格线分区；价格是最醒目的元素且固定两位小数（约定第 8 条）；可选会员价为空时的处理（第 9 条）；长品名的适配与画板缩字下限（第 10 条）；卖点标签个数变化；EAN-13 条码的模块像素与留白。

## 专家数据定义

`超市商品价签 v1`：门店名称、店标、品名、规格、计价单位、产地、货号、卖点（≤3）、零售价、会员价、商品条码（EAN-13 完整编号）、物价员、监督电话。与 `fixtures/workspaces/price-tag` 的"商品价签 v1"不同：那份是 Excel 导入的测试夹具，没有门店、条码与物价员，不复用。

## 数据集

`dataset-water.json`：按样图转录。条码 6901234567892 的校验位已核对正确。

13 项：零售价是字号最大的文字（`largest`）、价格区里有"50"（两位小数）、会员价、品名、规格、产地、货号、卖点、顶栏门店名称、店标在左上、EAN-13 条码在左下、物价员与监督电话在底部。

## 已知差异与取舍

- 样图价格区右上方有一个空格子，项目说明写明是印章位、保持空白。
- 检查"零售价两位小数"只要价格区出现"50"，会员价"1.98"不会误中。
