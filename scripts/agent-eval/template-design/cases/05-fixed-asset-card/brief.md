# 项目说明：星云科技固定资产标识卡

- 业务：企业固定资产标识卡（领域约定见 domain-asset-tag.md）。
- 示例图：实际尺寸 90 × 50 mm（深蓝圆角外框以内），是"图形渲染工作站"这件资产的标识卡设计稿。
- 目标范围：尺寸固定 90 × 50 mm；资产名称、存放地点最长 16 个汉字；使用部门、保管人、启用日期可能为空。
- 命名：主模板名"资产标识卡"，没有对外参数；被调模板自行命名。
- 客户说明：二维码内容用数据集的资产详情链接；条码用 CODE128，内容是资产编号，条码下方印编号。左上角单位标识在数据集里（res:logo-nebula-tech）。
