# 项目说明：第一人民医院诊室电子门牌模板

- 业务：门诊诊室门口的电子门牌（领域约定见 domain-clinic-doorplate.md）。
- 示例图：实际尺寸 300 × 400 mm（宽 × 高），是消化内科门诊 3 诊室上午出诊时的门牌画面。
- 主模板："诊室门牌"，没有对外参数；被调模板自行命名。
- 目标范围：尺寸固定 300 × 400 mm；候诊队列 0–6 人；擅长 0–3 项；正在就诊可能为空（开诊前）；医生照片可能没有。
- 客户说明：顶栏左侧的白色十字用 res:icon-medical-cross-white；"等候就诊"标题前的图标用 res:icon-queue-list；底部温馨提示前的三角感叹号用 res:icon-warning-amber。医生照片在数据集里（res:avatar-doctor-zhou）。候诊状态的标签底色：候诊中蓝色、准备橙色、过号灰色。
