# 用例 09：生鲜促销价签

| 项 | 内容 |
|---|---|
| 样图 | `sample.jpg`，素材包 `samples/09-fresh-produce-promo-tag.jpg`，1376 × 768，SHA-256 `86b8aab11a859cf9dfc2e0960d2507799e840fade57daa9b455db2b2a3cfadca` |

| 主模板 | `促销价签`，无参数；示例请求 300 DPI |
| 资源 | `icon-promo-clock`、`icon-fresh-leaf` |

## 考察点

同领域的第二种版式：促销价拆整数与小数（`splitPart`，M251）、原价划线（文本没有删除线，用线条元素）、卖点标签按序号配色、三种价格都可能为空、EAN-13 店内码与溯源二维码同在底部。

## 专家数据定义

`生鲜促销价签 v1`：门店名称、品名、卖点、产地、等级、规格、编码、计价单位、原价、促销价（必填）、会员专享价、店内码、溯源二维码内容、物价员、监督电话。"限时特惠 PROMOTION"是固定标题，不建字段。

## 数据集

`dataset-apple.json`：按样图转录。**店内码改了校验位**：样图印的 2104891009804 按 EAN-13 算校验位应为 2，数据集用 2104891009802；用原值时引擎会因校验位不对报严重问题，与模板无关。

## 压测（草稿，300 DPI）

品名 30 字、没有原价、没有会员专享价、没有卖点、卖点 1 个、促销价四位整数、计价单位千克且没有溯源码、没有等级与规格，加示例共 9 项。

## 版面检查

15 项：促销价整数部分最大（`largest`）、价格区的小数与计价单位、原价、会员价、品名、卖点、编码；门店名称、闹钟与绿叶的位置；EAN-13 与二维码在底部；物价员；没有原价时找不到"15.80"。

## 已知差异与取舍

- "价格区的小数""计价单位"两项会被会员价"¥8.80/500g"同时满足，检查偏宽；促销价是否醒目由 `largest` 把关。

## 通过线（tds-baseline-1 定稿，M337）

压测 9/9；版面检查至少 13/15。
