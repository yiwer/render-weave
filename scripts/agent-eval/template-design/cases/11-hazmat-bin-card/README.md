## 考察点

枚举列表驱动的图片循环（类别 → 象形图，1–4 枚）；信号词派生英文（`branch`）；装饰边框；两列格线信息表；多行段落。

## 专家数据定义

`危化品库位卡 v1`：中英文品名、信号词（枚举）、库位、危险性类别（枚举列表 1–4）、CAS 号、UN 编号、批次号、净含量、入库日期、有效期、安全措施、应急电话、库位条码。象形图不建图片字段，英文信号词不存。

## 数据集

`dataset-ethanol.json`：按样图转录。样图品名写的是繁体"工業級"，数据集用简体"工业级"。样图把应急电话写在安全措施段落里，数据集拆成两个字段。

## 压测（草稿，150 DPI）

危险性 1 项与 4 项、信号词警告、中文品名 16 字、英文品名 40 字符、安全措施 60 字、没有 CAS 与 UN 编号，加示例共 8 项。

## 版面检查

15 项：中英文品名、信号词与 DANGER 在右上、库位；易燃与健康危害象形图、类别名称；CAS 号、有效期、应急电话；CODE128 在右下；类别只剩易燃时不再有健康危害象形图、4 类时出现腐蚀性象形图、信号词改为警告时出现 WARNING。

## 通过线（tds-baseline-1 定稿，M337）

压测 8/8；版面检查至少 13/15。
