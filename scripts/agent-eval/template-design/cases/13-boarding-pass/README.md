| 主模板 | `登机牌`，无参数；示例请求 300 DPI |
| 资源 | `icon-airplane-navy`、`badge-business-gold`、`icon-scissors-black` |

## 考察点

同一字段在主副券两处引用（约定第 2 条）；按舱位与布尔字段显示或隐藏（舱位徽章、优先登机）；英文舱位名派生；虚线分隔与裁切标记；CODE128 与二维码。

## 专家数据定义

`登机牌 v1`：航空公司（中英文）、拼音与中文姓名、副券缩写姓名、常旅客号、出发与到达城市及三字码、航班号、航班日期、登机时间、舱位代码与名称（枚举）、登机口、座位、登机序号、优先登机（布尔）、电子客票号、副券二维码内容。副券信息不另建字段；"LIN Z.Y."无法从全名推出，单建一个字段。

## 数据集

`dataset-sa8502.json`：按样图转录；副券二维码内容为自拟。

## 压测（草稿，300 DPI）

经济舱、头等舱、不优先且没有常旅客号、城市名 8 字、拼音姓名 28 字符、没有登机口与序号、四位航班号与三位排号，加示例共 8 项。

## 版面检查

18 项：顶栏航空公司；主券的出发三字码、到达城市、飞机图标、航班号、登机口、座位、登机时间；舱位徽章与 BUSINESS CLASS 在顶栏；优先登机在左下；剪刀在主副券之间；副券缩写姓名与重复的航班号；副券二维码在右下、主券 CODE128；经济舱时没有舱位徽章、不优先时没有优先登机。

## 通过线（tds-baseline-1 定稿，M337）

压测 8/8；版面检查至少 16/18。
