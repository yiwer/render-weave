# 项目说明：星海航空登机牌模板

- 业务：航空公司柜台打印的登机牌，左边主券、右边副券（领域约定见 domain-boarding-pass.md）。
- 示例图：实际尺寸 203 × 86 mm，是 SA8502 航班旅客林致远的公务舱登机牌。
- 主模板："登机牌"，没有对外参数；被调模板自行命名。
- 目标范围：尺寸固定 203 × 86 mm；舱位三种（头等舱、公务舱、经济舱）；常旅客号可以没有；不是每位旅客都优先登机；城市名最长 8 字，拼音姓名最长 28 个字符。
- 客户说明：
  1. 航线中间的飞机图标用 res:icon-airplane-navy；主副券之间的虚线上放剪刀 res:icon-scissors-black。
  2. 顶栏右侧的舱位徽章用金色底 res:badge-business-gold，上面写中文舱位名与英文（公务舱 BUSINESS CLASS、头等舱 FIRST CLASS）；经济舱不显示徽章。
  3. 优先登机时左下角显示红底"优先登机 PRIORITY BOARDING"标签。
  4. 主券条码用 CODE128，内容是电子客票号，条码下方印"ETKT 客票号"。
