工作目录中的 sample.png 是客户提供的公交线路牌设计稿（示例图）。你的任务：为这类线路牌设计数据定义，并按示例图做一份数据集候选，供后续做模板与批量出图。

要求：
1. 先读 docs/dsl-reference.md 了解数据定义 DSL 与数据集格式。
2. 仔细查看 sample.png。数据定义应覆盖牌面上随线路、方向而变化的业务信息；固定装饰、颜色、版式不进数据定义。同一套数据定义要能服务其他线路（站数、班次数不同等），约束要合理。
3. 数据集候选按示例图逐项转录。图片类信息先用 list_resources 查看资源仓库，用 res: 引用。
4. 把文件写到 candidates/ 目录：每份数据定义一个文件，数据集一个文件。
5. 用 check_definitions 与 check_dataset 校验，有问题就修改，直到没有问题。
6. 最后输出：字段清单（名称、类型、对应牌面哪一部分）、关键建模理由、你不确定或需要业务确认的地方。
