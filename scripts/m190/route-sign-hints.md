# 公交线路牌领域约定

以下约定来自既往线路牌项目与业务确认，做数据定义与数据集时遵守。

1. 一份数据集对应一条线路的一个行驶方向。出哪一站的牌、高亮哪一站，由出图请求的参数决定，不写进数据集。
2. 能由其他数据推出的信息不进数据定义，由模板计算：例如终点站是站点列表的最后一项，下一站是本站的后一项，站点是否已过站由本站序号比较得出。
3. 站名下方的带圈数字（①②③…）是地标图片，是停靠站点的可选图片属性：既不是站名的一部分，也不是数字。数据集里引用资源仓库中对应的地标图片。
4. 站名上方的小图标（如地铁、医院）表示站点设施类别：用文本枚举列表记录类别（如"地铁""医院"），模板按取值选图；一站可以有多个，没有就省略。
5. 金额类信息拆开记录：票制（如"一票制"）是文本，票价是数值，展示时由模板拼接单位。
6. 线路号用文本字段记录；如果牌面使用艺术字图片，另设一个图片字段引用资源。

客户对本次设计稿的说明：站名上方蓝色圆形内带数字的标记是早期错误设计，忽略，不进数据。
