# 验证工作簿

`route-table.xlsx` 是人工构造数据，不含客户信息。使用 `@oai/artifact-tool` 创建并导出，构造逻辑见 [build.mjs](build.mjs)。上行与下行采用不同宽度的班时列组；刻意保留同名停靠项、田贝②、重复班时、空单元格和编码前导零。说明表另含公式缓存样例。

导出后使用独立的 openpyxl 3.1.5 只读核对了工作表、合并范围、时间、站名与编码。Artifact Tool 的本机渲染子进程退出码为 1，未得到图片预览，因此不声称已做视觉验收；这份夹具用于数据读取与转换验证。

运行验收只需要已经提交的 xlsx；不依赖 Artifact Tool 或 openpyxl。重建时，在安装了 `@oai/artifact-tool` 的 Node 环境运行 `node build.mjs <新输出目录>`，重新核对内容并更新固定文件哈希。ZIP 元数据可能使重建字节不同，不要求重建哈希天然一致。

隐藏数据、缺失公式缓存、异常 XML 和 ZIP 等故障版本由 `accept.py` 从固定原件生成并留在验收输出中，不覆盖此原件。独立期望值在验收代码中人工列出，不从被测转换结果反推。
